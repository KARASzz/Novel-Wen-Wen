# 第72章 血炉旧账

姬刹那回魔宗的第五天，血炉殿的钟没响过一次。

没响，比响更难受。她住在火种旧居里，掌心贴着心口那道旧裂，等它跳——它跳得很稳，稳得像被人按住调过。

赤婆娑没来收她的火籍。夜烬也没来。整座血炉殿安静得像一口扣着的锅，锅底压着火，谁都不敢掀。

她自己去翻账。

血炉殿的账房在钟楼底下，一进门就是那面挂着旧钟的空梁。钟没了，梁上留着一道磨痕，磨痕里有灰。她路过时抬手在灰上划了一下，灰底下露出两道刻痕，一青一红，和废庙石座下那两道，一个走法。

她把手收回来，没碰第二下。

账册按火种编号排，从第一号排到今天的第九十七号。她从中间抽出一册，翻开——每一页记一个火种，记的不是名字，是火候曲线，哪一年稳，哪一年躁，哪一年“归炉”。

又是归炉。

她一页页翻。那些曲线她看得懂——血炉教火种读数，先读自己的火，再读别人的。曲线往上一挑，是心火躁；往下沉半寸，是压住了；一路平着走到底，人就没了。

第一册里，归炉的火种有十一个。十一个人的曲线，末尾都是平的，平得一模一样，像被人拿尺子抹过。

她数了数那些平台的长度。每一段平的，都恰好三寸——不是火自己熄的，是有人记到这儿，就没再记了。

第二册，十四个。

第三册翻到一半，她停了。

这一页的火候曲线断了。

断得很奇怪——曲线走到某一年，突然齐刷刷收成一道直线，直线尽头画着一个记号：一只半开的眼睛，眼缝里一道横。

和太素那页残纸上的记号，一样。

她盯着那道记号，心口旧裂跳了一下。

后面的页被撕了。撕口很毛，不像裁的，是匆忙扯走的。她把撕口对着光看，纸背透出压痕——是下一页记的字被人用力写在撕掉的那面上，压出了印子。

她取出一片薄炭，在纸背的压痕上轻轻拓。

字浮出来。

“……三日后，交暗阁，换炉引。”

交暗阁。

她把那册账合上，又抽了后面几册，一册册翻。每一册里都有那么一两页，火候曲线走到某一年就断，断口后面跟着那只半眼的记号。最早的一册里，记号旁边写着一行小字：宁。

她认得那半个字。不是“宁霜照”的完整名字，只一个姓，被记在火候曲线的尽头，像记一件货。

姬刹那把那册账放回原处，放得很轻。

放回去之前，她又翻了一遍那页被撕的账。撕口毛糙，旁边却有一道极浅的压痕，是有人在同一页上写过字、又擦掉留下的。她把炭纸贴上去，用指腹慢慢拓。

拓出来的不是字，是半个记号——一只眼睛的上半边。

和血炉钟内壁那道刻痕一样。她上次磨钟壁时见过，记录层里藏着同样的眼。

她把炭纸收好。

账房顶上那根空梁忽然响了一声。

不是钟。是梁上挂过钟的那道铁钩，被风撞得晃了一下，铁钩磕在梁上，闷闷一声——和血炉钟差了八度，尾音却一模一样。

姬刹那的心口跟着那声响跳了一下。她按住，按到那跳停了才松手。

有人在血炉殿里把钟摘走了。摘钟那天，账上正好断了九笔。

她走出账房时，天已经黑了。血炉殿的火把一路烧到台阶尽头，火光把她的影子拉得很长。

夜烬在台阶下等她。

“火种查账。”他说，“赤长老知道吗？”

姬刹那没停步：“你猜。”

“我猜你不想让她知道。”

她走到台阶最后一级，停住，偏过头。火光映着她赤金的眼，眼里没有笑。

“少主，我给你一次机会，把今天看见的咽回去。”她说，“咽回去，你还是少主。不咽——”

她抬手，把裂魂刃的刀背在台阶扶手上磕了一下。火星溅起来，烫得夜烬脚边的火把杆烧出一道黑印。

“不咽，我先把你这条查账的手，钉在这根扶手上。”

夜烬看着那道黑印，喉结动了一下。

“我没看见。”

“聪明。”

她从他身边走过去，肩头擦过他的刀鞘，没停。

走出三步，夜烬的声音又追上来：“姬刹那。”

她停了。

“账上那九笔，你拓了几笔？”

姬刹那没回头：“你数得倒清。”

“血炉殿的账，少一页我都能数出来。”夜烬道，“你拓了，就还是火种该做的事——查火候。你没拓，就是查别的。”

“你想说什么？”

“我想说，赤长老要是知道你拓了那半只眼，不会只让你回炉复核。”

姬刹那偏过头，火光里她的脸只露出半边。

“少主，我再说一次，你不会喜欢听。”

她抬手，把裂魂刃从肩上取下来，刀尖点在台阶上。刀尖一点，石阶上炸开一道细细的焦痕，焦痕直直地朝夜烬的靴尖爬过去，停在半寸外。

“你再数第三遍，我就把你数的东西，连你这条手一起，钉回账房去。”

夜烬看着那道焦痕，退了半步。

“我不数了。”

“乖。”

她收刀，走进夜色里。

回到火种旧居，她把那片拓了字的炭纸摊在灯下，又摸出一枚从账房顺来的火漆——暗阁的记号，她在魔宗的黑市单据上见过，凭它能进一次暗阁，不问来路。

她把火漆按在掌心的旧疤上。

烙印烫进肉里，滋地一声，冒起一缕白烟。她没吭声，只把袖口拉下来盖住。

掌心的旧疤被这新印压着，两道印叠在一处，一道是血炉的，一道是暗阁的。她攥了攥拳，指节发白，那两道印在掌心里顶着，像两只眼，一只是魔宗的，一只谁都不是。

灯芯爆了一声。她抬手把灯捻灭，屋子里只剩她心口那道裂，跳得很稳。

稳得像有人替她数着拍子。

天亮前，她换上魔宗商队的灰袍，混在一支往中立仙市送货的车队里，出了山门。

车队走的是官道，十几辆货车，车上盖着油布，油布底下是魔宗往外运的火器。押车的管事看了她一眼，见她掌心那道半眼烙印，脸上皱了皱，没多问——暗阁的印在魔宗商队里也认，凭它上车的，都是替宗门跑暗线的自己人。

她挑了最后一辆车，坐在车辕边上。

风卷着雪往回吹，吹得她睁不开眼。她把领口竖起来，掌心那道烙印被衣料磨着，火辣辣地疼。她没管。

车过第一道山口时，她回头看了一眼。

魔宗的山门在雪里立着，火把一排排往下排，像一条烧着的线。线的尽头，血炉殿的钟楼空着——那根挂钟的梁，远远看去，只剩一道黑。

她把手从领口里伸出来，掌心那道半眼印朝山门的方向按了一下。

不是告别。是记个数。

她要记清楚，自己是从哪口炉里出来的。

车队滚动，碾过一片结冰的水洼。她的靴子冻得发硬，脚趾没知觉了，她把脚在车板上跺了两下，跺出一点疼，才继续坐好。

她没带火籍，没带令牌。

只带了那片拓字和掌心那道新烙的印。
