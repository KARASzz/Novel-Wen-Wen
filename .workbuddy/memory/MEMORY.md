## 关键项目惯例
- **平台校准**:番茄小说连载;资料中"起点"字样按番茄理解,不改资料原文。
- **映射表**:声纹锁非换脸器——只取表演能量/台词节奏,禁真人经历、原句、名场面;第一卷仅两个政客锚点(哈特→特朗普、庞永和→奥巴马),马斯克只用于钉子。
- **保真**:修订须见原文,续写须见承接正文;不用摘要/记忆代替正文。
- **章数**:第一/二卷各40章,第三至八卷各45章。
- **五拍**:每章 2800—3300 汉字,五拍结构。
- **资源优先级**:资料冲突按"序号小者优先"裁决;作者已确认事项不重复确认;草稿默认未确认。
- **引号体例(全书基准,2026-09-23 实测确立)**:①**对白=弯引号 `“”`**;②**公文/报告/系统记录/商品标签/词条提及=直角 `「」`**;③**英文直引号 `"` 应为 0**。铁证:第一卷 40 章(直角 0、弯 1906、英文直引号 1092)、第二卷 46/49 章(对白弯引号,系统记录与词条用直角)。**并行写作必须在任务卡里写死引号规则**,否则一组用英文直引号、一组用弯引号、一组用直角,合稿时得逐处人工判。

## 字数口径与统计(2026-09-18 已统一)
**正文汉字数,不含章标题、标点、数字字母、空白、Markdown 标记、状态账本与修订记录**。区间 2800—3300。

**统计算法**(已验证):先截掉第一个 `##` 起的内容(状态账本+修订记录)→ 按 `# 第N章` 切分 → 去章标题行 → 数 `[\u4e00-\u9fff]`。

**两个陷阱**:①不先截修订记录,末章区间会吞掉修订记录导致虚高(第 3 章曾误得 3591);②不截状态账本,每章虚高 50—130 字。

**AI字数估算系统性偏高30—35%**。每章写完立即统计,不要等一批写完再统一核。

## AI写稿自检五条(每章交付前必跑)
①**章号泄漏**——起草时极易把"第3章""第7章"当临时指代写进正文,必须改成场内说法("前几天""靠港那天")。检查法:截掉修订记录/状态账本段后 grep `第\s*\d+\s*章`——**必须带 `\s*`**,模型常写"第 30 章"这种带空格形式,旧正则漏检(2026-09-23 已在第51、52章各查出一处)。同时扫目录用语 `第一卷|第二卷|本卷|上一卷|分卷大纲|章纲|清单`。 ②**补写前必先回读目标位置前后原文**,确认要补的内容尚未存在——第15、18、19章各因此产生一次整句重复。 ③**「不是…是…」句式**:初稿常达7—10处,须削到每章1—2处,保留刻意对照句。 ④**半角标点**:写稿时易混入半角逗号,须全量改全角。 ⑤**字数不足先查是否漏拍**,用补拍次+补质感解决,不用形容词注水。
