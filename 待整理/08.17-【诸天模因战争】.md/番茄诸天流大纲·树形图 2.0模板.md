## 03 · 黄金三章 · 诸天重构版

> 普通爽文：困境→金手指→反杀  
> **诸天流：困境→能力+副本预告→首副本开门红**  
> 节奏必须更快。

```
ROOT
│
├── 第一章：钩子+困境+副本预告（3000字内）
│   ├── 前300字  → 强画面钩子·绝对不能慢热铺垫
│   ├── 800字内  → 主角身份+处境够惨
│   ├── 1500字   → 能力到账·规则说清楚
│   ├── 2500字⭐ → 副本世界名称首次出现（读者认识的热门IP）
│   └── 章末     → 踏入副本瞬间·不写副本内容·纯吊胃口
│               ↓ 进副本
├── 第二章：进副本+首个碰撞爽点（3000-4000字）
│   ├── 进副本即画面冲击  → 你的描写要超越读者对原著的想象
│   ├── 切入角度确立      → 信息差建立·为什么他的视角和原著主角不同
│   └── ⭐首个碰撞爽点    → 做一件原著里没人做过的事
│                           用主界能力产生化学反应
│               ↓ 首副本首胜
└── 第三章：首胜+规则提炼+暗线钩子（3000-4000字）
    ├── 首副本首胜    → 漂亮反杀·确立扮猪吃虎人设
    ├── ⭐规则提炼场景 → 读者第一次看到"跨世界携带"如何运作
    │                    这是全书最重要的能力展示时刻
    └── 章末：全书最大悬念
              → 贯穿全书的暗线钩子·主线反派的影子首次出现
```

## 04 · 副本矩阵 · 全书地图

> ⚠️ **这是诸天流和普通爽文最大的结构差异**  
> 不是在设计一个世界观——是在设计一张副本地图

```
ROOT
│
├── 副本选择三维度（大纲期必锁定）
│   ├── 维度① 读者基数      → 首副本必须极高·热门IP优先
│   ├── 维度② 切入角度独特性 → 主角视角已写烂·找边缘视角制造信息差
│   └── 维度③ 规则可掠夺性  → 底层逻辑能被提炼吗·和已有能力的化学反应
│
├── 副本序列规划表（因果链）
│   ├── #1 首副本   → 信息差博弈型 | 10-25万字 | 字数天花板必锁定
│   ├── #2 第二副本 → 战力展示型   | 20-30万字 | 两晶体融合·暗线反派首现
│   ├── #3 第三副本 → 智斗反转型   | 25-35万字 | 世界观第一次翻转
│   ├── #N 高潮副本 → 终极博弈型   | 30-40万字 | 代价机制全面爆发
│   └── 终局本部    → 收束回响型   | 10-20万字 | 主角最终选择
│   ✗ 副本类型重复（连续3个战斗碾压）= 审美疲劳·留存崩
│     解法：智斗→战力→运营→反转·强制轮换
│
└── ⭐本部主界经营线（情感锚点）
    ├── 为什么必须有 → 纯副本堆叠=快穿文·本部线是区分关键
    ├── 内容要求     → 主角回归的现实处境·势力格局（≥2个）·情感锚点人物
    └── 节奏要求     → 每个副本开始前和结束后必须有本部戏份
```

## 06 · 三线冲突 · 全书血管

> 三线缺一不可。缺了哪条，全书就在那条线上漏血。

```
ROOT
├── 明线：主角 vs 各副本挑战
│   └── 诸天特殊要求 → 每个副本明线类型必须不同
│                       智斗/战力/运营/信息战 轮换
│                       是每章推进的直接动力
│
├── 暗线：主角 vs 跨副本主线反派
│   └── 铁律 → 线索必须在前三个副本就开始投放
│               不能第五副本才出现
│               这是全书完成度的核心
│
└── 内线：主角 vs 代价累积下的自我
    └── 铁律 → 代价每3章必须出现一次具体场景表现
                光靠文字描述无效
                必须和主角人格演变轴绑定
```

## 09 · 致命错误清单

### 通用5条

```
✗ 科技/规则无代价     → 悬念归零·读者弃书
  解法：每项能力绑定等价牺牲

✗ 伏笔烂尾           → 口碑崩塌
  解法：大纲期锁定所有伏笔兑现节点

✗ 主角是剧情容器      → 读者无共情
  解法：每章问：是主角推动的吗？

✗ 世界观百科化        → 阅读窒息
  解法：每章专有名词≤3个

✗ 开局爽点太迟        → 前三章掉读
  解法：10章内必须第一次反杀
```

### ⭐ 诸天流专属7条

```
✗ 副本之间没有因果链
  后果：读者看完一个副本直接弃书
  解法：大纲期锁定每个副本的携带物和后续影响

✗ 原著人物沦为工具人
  后果：原著粉愤怒弃书
  解法：保留原著人物性格核心·主角胜利要"打得有理"

✗ 副本字数失控（单副本>40万字）
  后果：完读率崩
  解法：每副本设字数上限·到点强制转场

✗ 跨世界携带无上限
  后果：主角后期无敌无悬念
  解法：每副本设"携带上限"和"损耗规则"

✗ 代价只在开头提·后面忘记
  后果：主角弧线断裂·读者不信任
  解法：每三章出现一次代价的具体场景

✗ 副本类型重复（连续3个战斗碾压）
  后果：审美疲劳·留存崩
  解法：智斗→战力→运营→反转·强制轮换

✗ 本部现实线太薄
  后果：副本爽完读者没有情感锚点
  解法：每个副本开始前和结束后必须有本部戏份
```
