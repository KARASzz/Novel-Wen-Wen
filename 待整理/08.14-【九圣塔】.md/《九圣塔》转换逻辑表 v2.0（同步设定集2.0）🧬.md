## 0）2.0硬约束（写转折前先把脚钉进地板）🧱

- **不控体铁律**：塔不碰肌肉，只卡流程（门禁/配额/可见性/联验）。
- **入塔三件套**​：访问碎片 + 窗口期 + 前序钥匙（声部输入）\= 才有资格进同一座塔。
- **不可跳塔**：失败会被“吐出”（DI↑、θ↓、难度升），但只能重试同塔。
- **联验三件套**：主体字段 + 关系字段 + 事件回执（高级服务的硬口径）。
- **三签名骨架**​：S主体签 / E事件签 / P参数签；高权限读写\= N-of-9声部门票。
- **两类窗口期**：
  - 预清洗：阈值更低，处置升级更快（更像“免疫态”）。
  - 慢波：联验变慢、补洞滞后（真相短暂露缝）。

## 4）块/元素怎么“回声2.0”（只写服务摩擦，不写超能力打架）🧊

### 4.1 元素转三态（破节拍器）

- **标准L转**：第3元素出现“结果变形”。
- **空转**：第3元素只增压（提示语增多/队列变长/字幕闪烁）。
- **延迟转**：爆转挪到下一章开头（门禁突然联验失败/配额突然清零）。

### 4.2 四种L表达模板（对应T1–T4回声）

- **T1回声**：门槛更窄、流程多一层、需要额外签/配额、门禁联验失败。
- **T2回声**：回放被补洞、口径变更、材料退回、事件签空洞。
- **T3回声**：字幕降级、担保链裂口、互认失败、关系字段被重写。
- **T4回声**：成功但触发DI升级/断供/连坐，胜利变成下一轮更严的处置。

## 5）写细纲时的“硬审计清单”（每个S/M节点都要过）✅

1. 这次转折 ​**卡谁**：FAA / SRB / CNA / DGU / TAC（至少一个）。
2. 这次转折 ​**卡哪签**：S / E / P（至少一个）。
3. 这次转折 ​**卡哪栏**：主体/关系/回执/配额/可见性（至少一个）。
4. 这次转折 ​**在哪个节拍**：预清洗 or 慢波 or 常态（写出来）。
5. 失败后果有没有写：吐出 / DI↑ / θ↓ / 断供 / 静音（至少一个）。
6. 下层回声是否一致：块/元素只加压，不抵消上层转。
