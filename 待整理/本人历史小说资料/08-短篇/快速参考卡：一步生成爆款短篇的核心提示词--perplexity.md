# 快速参考卡：一步生成爆款短篇的核心提示词--perplexity

## 🚀 快速使用流程（3步）

### 步骤1：输入脑洞模板

复制完整的脑洞模板（见《爆款短篇提示词工程.md》第一部分），填写6个核心设定，输入到你的AI对话框。

**示例格式**：

```
题材: 都市逆袭
主角: 被豪门抛弃的私生子
金手指: 可以掠夺别人天赋的系统
…（继续填写其他项）
```

---

### 步骤2：生成大纲

**在AI中输入以下提示词**：

```
你是一位网络爽文大师。根据我提供的脑洞设定和【脑洞模板】结构，为我生成一份完整的【三幕式大纲】。

要求：
1. 第一幕（3000字左右）：快速交代背景、激活金手指、制造期待感
2. 第二幕（8000字左右）：冲突升级、真相反转、多次爽点
3. 第三幕（4000字左右）：最终对决、胜利展现、情感升华

每幕都要有明确的转折点和爽点设置。
```

**AI输出**：你会得到一份完整的3幕式大纲

---

### 步骤3：生成节拍表

**在AI中输入以下提示词**：

```
根据这份大纲，为我生成一份【15000字精准节拍表】。

参考密度标准：
- 冲突密度：每200字至少1个
- 悬念密度：每300字至少1个  
- 转折密度：每500字至少1个
- 情感密度：每100字至少1个

要求每个节拍包含：
1. 情节目标
2. 细节规划
3. 推荐字数
4. 输出效果

用【节拍表模板】的格式生成完整的22个节拍。
```

**AI输出**：你会得到22个精准的节拍

---

### 步骤4：生成正文

**在AI中输入以下提示词**：

```
根据这份节拍表，为我生成一篇【15000字的爆款短篇爽文】。

核心要求：
1. 每个节拍严格按照规划的字数执行
2. 冲突密集，爽点频繁，打脸详尽
3. 3秒入坑：开篇必须是冲突或奇景
4. 10秒上瘾：第200字内必须出现第一个爽点
5. 一口气读完：平均每500字一个新的期待点

重点：
- 反派的恐惧与绝望要详细写（这是爽感核心）
- 配角们的震惊/赞叹反应要充分（没人赞叹就不爽）
- 打脸场景要拉长，要有仪式感
- 用对话代替心理描写，保持节奏快
- 每个转折都要有信息量，不要重复

开始生成！
```

**AI输出**：你会得到一篇15000字的完整爽文正文

## 💡 关键提示词模板库

### 模板A：快速激活爽点

```
【快速激活第一个爽点】
要求：
- 用不超过600字，激活主角的金手指/能力
- 包含系统面板或能力展现的视觉盛宴描写
- 制造"主角要逆袭"的确切感
- 让读者在此刻"入坑"

用这个模板对节拍4进行优化...
```

### 模板B：打脸场景增强

```
【增强打脸爽感】
当前打脸场景字数不足。请扩展【节拍17】的打脸过程，使其达到1200字，并增加：
1. 反派的逐步绝望反应（从嚣张→惊讶→恐惧→认输）
2. 每一次被击中时的具体描写
3. 旁观者的沸腾反应
4. 主角每一次攻击的威力展现

要求：每个细节都能让读者产生"爽"的快感。
```

### 模板C：配角反应补充

```
【补充配角反应】
检查全文的配角反应是否充分。对以下场景进行补充：
- 打脸时周围人的表情和对话（至少3人不同反应）
- 胜利时的全景描写（掌声、欢呼、泪水、震惊）
- 重要转折时配角们的议论（用弹幕或旁白形式）

确保每个爽点都有充足的"陪衬"。
```

### 模板D：三秒入坑优化

```
【优化开篇吸引力】
检查前500字是否符合"3秒入坑"标准：
1. 第一句话是否是冲突或奇景？
2. 第100字内是否出现过反差？
3. 第200字内是否有主角被压制的画面？
4. 第300字内是否开始暗示主角会反击？

如果不符合，请重写开篇部分，确保用短句、用对话、用行动，快速制造冲突。
```

### 模板E：字数控制优化

```
【字数精准控制】
用【情节】控制字数，而非"心理描写"或"环境描写"填充。检查以下问题：
1. 是否有超过100字的心理独白？（删除或转换为对话）
2. 是否有超过200字的环境描写？（压缩到50字以内）
3. 是否每500字都有转折或升级？（补充缺失的节点）
4. 是否每个冲突都推进情节？（删除无关细节）

请按照字数目标进行调整...
```

### 模板F：情感线补充

```
【情感线补充与深化】
当前情感线过弱。请补充以下环节：
1. 感情对象在关键时刻的出现（至少3次）
2. 配角对主角转变的惊讶反应
3. 一个"温暖时刻"用来缓冲高潮
4. 胜利后的情感兑现场景

确保情感线与主线并行，而非割裂。
```

在生成后，用这份清单检查你的短篇是否达标：

|检查项|标准|检查方法|
| ----------| --------------------| ------------------------------------------|
|冲突密度|每200字至少1个|把文章分成75段（15000÷200），数冲突点数|
|悬念密度|每300字至少1个|把文章分成50段（15000÷300），数悬念点数|
|转折密度|每500字至少1个|把文章分成30段（15000÷500），标记转折点|

|开篇入坑|第一句是冲突|第一句话是否引入冲突或奇景？|
|爽点分布|均匀分布|画出爽点分布图，应无死角|

## 🎯 常见问题快速解决

### Q1：AI生成的大纲过于简洁？

**解决方案**：用这个提示词扩展：

```
请将【节拍8-15】的情节目标和细节规划再详细展开50%，增加更多的转折点和伏笔设置。每个节拍的细节规划应该至少有5-7个具体步骤。
```

### Q2：打脸场景不够爽？

**解决方案**：用这个提示词强化：

```
【节拍17的打脸过程】现在只有900字。请扩展到1200字，并在反派被击中的每一刻都详细描写：
1. 反派的表情变化（从什么表情变成什么表情）
2. 周围人的实时反应（至少5个不同的人）
3. 反派的内心活动被推断（他在想什么，他有多恐惧）
4. 主角每一击的威力展现（用具体数字、物理效应、光影效果）
```

### Q3：节奏感不够快？

**解决方案**：用这个提示词优化：

```
检查全文是否有超过100字的心理独白或超过200字的环境描写。
- 所有心理独白改为对话或行动
- 所有环境描写压缩到一句话
- 所有解释性文字改为谜团或悬念

重点：用短句、用对话、用动作、快速推进。
```

### Q4：配角反应不够充分？

**解决方案**：用这个提示词补充：

```
在以下关键时刻补充配角反应：
1. 每个打脸时刻：新增"周围人的对话"（至少3人，观点不同）
2. 每个胜利时刻：新增"观众的反应"（掌声、欢呼、泪水等）
3. 每个转折时刻：新增"配角的议论"（用弹幕或群众声音）

格式示例：
"全球直播间沸腾了，弹幕像瀑布一样刷屏：'卧槽''妈呀''绝了''他赢了''这怎么可能'"
```

### Q5：15000字差一点没到？

**解决方案**：用这个提示词精准补充：

```
当前文字数为14500字，差500字。请在以下位置精确补充：
1. 节拍17（打脸场景）增加200字
2. 节拍20（利益获得）增加150字
3. 节拍21（情感线）增加150字

补充的内容必须是"情节内容"而非"填充"。每个补充都要有信息量。
```

## 🔥 三个爽文流量密码

### 密码1：【压—爽—压—爽】的节奏

- 前200字：压制主角（让读者同情他）
- 接下来300字：爽一把（让读者期待他）
- 再压制200字（反派升级）
- 再爽一把（主角反击）
- **反复循环直到最后**

### 密码2：【没人赞叹就不爽】

- 打脸不能只写"主角赢了"
- 必须写"对手被打得多惨"+"周围人多么震惊"+"观众多么沸腾"
- 配角的反应≥正文的30%
- 这才叫"爽"

### 密码3：【3秒→10秒→3分钟→15分钟】

- 3秒：入坑（第一句是冲突）
- 10秒：上瘾（200字内的第一个爽点）
- 3分钟：继续看（每500字一个新期待）
- 15分钟：一口气读完（无逻辑漏洞，节奏不断）

## 🎁 终极秘诀

**最重要的三件事**：

1. **在脑洞模板上花时间**
   - 模板越具体，AI输出越精准
   - 每一项都要填详细，不要偷懒
2. **相信节拍表的力量**
   - 节拍表是故事的骨架
   - 严格按照节拍表的字数和情节生成
   - 不要让AI"自由创作"
3. **优化打脸和配角反应**
   - 这是爽感的关键
   - 每个爽点都要有"陪衬"
   - 让读者通过别人的反应来感受主角的强大
