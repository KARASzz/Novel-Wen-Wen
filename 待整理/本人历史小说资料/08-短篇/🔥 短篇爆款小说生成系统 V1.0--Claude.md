# 🔥 短篇爆款小说生成系统 V1.0--Claude

## 适用平台：番茄小说 / 知乎盐选 / 短剧改编

## 目标字数：15000字 | 阅读时间：30-40分钟

---

# 📌 使用说明

将本提示词发送给AI，填写第一部分【脑洞模板】，即可一键生成完整大纲和详细节拍表。

**核心设计理念：**

- 三秒入坑：开篇50字必见冲突
- 爽点密集：每500字一个情绪爆点
- 反转不断：每1500字一次剧情翻转
- 读完即爽：结局必须给足满足感

# 🎯 第一部分：脑洞模板（用户填写）

```
【核心脑洞】
一句话故事：___________________________

【题材类型】（单选）
□ 都市逆袭（赘婿/战神/神医/首富）
□ 玄幻爽文（觉醒/重生/系统/穿越）
□ 悬疑反转（复仇/真相/身份揭秘）
□ 情感虐爽（追妻火葬场/真假千金/婚后甜宠）
□ 其他：___________

【主角设定】
姓名：___________

隐藏身份：___________（越牛逼越好，如：神级战神/隐世首富/上古传人）

【情绪基调】（可多选）
□ 爽（打脸/逆袭/碾压）

【核心爽点】（必填3个）
```

```markdown
**核心内容**（中间400字）：
- 场景1（150字）：___________
- 场景2（150字）：___________

**结尾钩子**（后50字）：
- 必须留悬念或反转
- 让读者想立刻看下一节
- 示例："可他不知道的是，门外站着一个人……"

**本节拍检查清单**：
□ 有没有废话/描写过多？
□ 情绪有没有推进？
□ 有没有设置下一节的期待？
□ 对话是否简短有力？（每句不超过15字）
```
