# 网络爽文爆款短篇创作系统--perplexity

## 项目说明

这是一套为番茄小说等平台设计的**AI驱动型爽文创作工程**。通过结构化的提示词设计，你可以用一个简短脑洞描述，一键生成包含**精简大纲+详细节拍表**的完整创作方案，用于直接输入AI生成15000字短篇正文。

**核心流量密码**：三秒入坑 → 三分钟读完 → 情节密集 → 爽点爆表

## 第二部分：精简大纲模板

### 使用说明

AI会根据脑洞模板自动生成如下结构。这个大纲将**指导整个创作方向**。

### 📋 大纲框架（自动生成样例）

```
【故事三幕式大纲】

【第一幕·设定与激活】(约3000字)
━━━━━━━━━━━━━━━━━━━━━━

序幕交代：
- 主角身份背景交代（300字内速冻，直入人设）
- 当前困境描写（必须显得"很惨"）
- 世界观/规则简述（一句话够）

引发事件（打开故事的钥匙）：
- 主角获得金手指/机遇的具体时刻
- 第一次能力展现，读者产生期待感
- 最后留下：主角即将参与关键事件

核心转折点1【脱轨点】：
- 主角第一次受辱/被看不起
- 但同时暗示主角会反击（给读者安全感）

【第二幕·冲突与对抗】(约8000字)
━━━━━━━━━━━━━━━━━━━━━━

第一场冲突：
- 设置反派的绝对优势（让主角看起来很渺小）
- 主角初次交手失利或被压制
- 读者对主角的同情值上升

升级段-1（高潮预热）：
- 主角的第一次小胜利
- 但反派立刻升级对抗
- 悬念加剧：还有更强的对手吗？

核心转折点2【中点反转】：
- 故事的真相部分揭示
- 反派的真实目的显露
- 主角的能力再次升级

第二场对抗（高潮积累）：
- 多个配角出场，见证主角的成长
- 打脸、装逼、虐反派开始密集出现
- 每个冲突都比上一个更激烈

不可返回点【不归点】：
- 主角做出了无法后悔的决定
- 双方关系走到了必须决出胜负的地步
- 读者期待值被拉到最高

【第三幕·高潮与解决】(约4000字)
━━━━━━━━━━━━━━━━━━━━━━

最终对决：
- 主角的爽点爆发时刻
- 反派的绝望与恐惧详细展现
- 打脸要拉长，要让其他人物疯狂反应

胜利时刻与报酬：
- 主角获得的实质收获（力量/地位/认可）
- 所有配角的反应汇总
- 情感线的最后一波满足

尾声与启示：
- 新的挑战暗示（为可能的续集埋伏笔）
- 主角此刻的心态变化
- 情感升华或"发疯文学"的最后金句
```

## 第三部分：节拍表与字数规划

### 📊 节拍表设计原理

**15000字短篇节拍密度标准**（根据网文研究）：

- 冲突密度：每200字至少1个冲突点
- 悬念密度：每300字至少1个悬念点
- 转折密度：每500字至少1个转折点
- 情感密度：每100字至少1个情感点

**关键：用情节控制字数，而非字数堆砌**

### 🎬 完整节拍表（15000字版本）

```
【15000字爽文节拍精准规划】

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第一幕·序幕与激活(字数范围：2800-3200字)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【节拍1】开篇吸引钩 (推荐字数：200-300字)
情节目标：
- 一个"惨"的画面直接轰入读者视野
- 冲突立刻出现
- 用对话而非心理描写

细节规划：
→ 主角被人群嘲笑的具体场景
→ 其中一个反派的刺激性台词
→ 主角的隐忍反应

输出效果：读者在30秒内产生"想看这货翻盘"的心理

---

【节拍2】身份与背景速冻 (推荐字数：400-600字)
情节目标：
- 快速交代主角的身份、出身、现状
- 不能啰嗦，每句都要有信息量
- 为後续逆袭做"高度落差"的铺垫

细节规划：
→ 一句话说清主角身份（"他曾是…"）
→ 一段对话展现他被家族/圈子轻视的事实
→ 一个具体的"惨"的细节（例：被分配最差房间）
→ 一句内心独白透露他的野心或倔强

细节控制：避免过多心理描写，用行动说话

---

【节拍3】规则与世界观 (推荐字数：300-400字)
情节目标：
- 一句话说明这个世界为什么这样
- 说明即将发生的"大赛/大事件"
- 说明胜负判定标准

细节规划：
→ 背景人物的一个解释性对话
→ 一两个世界规则的关键词
→ 这个事件为什么对主角至关重要

细节控制：绝不超过5句话的解释，用画面代替说教

---

【节拍4】金手指激活 (推荐字数：500-700字) ⭐爽点1
情节目标：
- 主角第一次获得"超越常理"的力量/机遇
- 读者在这一刻"入坑"，确信主角要逆袭了
- 这是全文最重要的激活点

细节规划：
→ 激活的具体触发：走进一个地方/做一个决定/遭遇一个事件
→ 力量显现的视觉盛宴：系统面板/异象/声音
→ 主角的惊喜反应（不要压抑，要爽）
→ 一个小的试验：主角尝试用新力量做某件事
→ 结果超乎想象的绝妙

细节控制：这段要用大量感官细节，让读者"感受到"超能力

---

【节拍5】小规模试验与期待 (推荐字数：400-600字)
情节目标：
- 主角初次展现能力
- 制造出"这哥们要起飞"的感觉
- 为即将到来的冲突埋下伏笔

细节规划：
→ 一个日常场景中的小对峙
→ 主角用新能力解决一个小问题
→ 旁人的震惊反应（这很关键）
→ 一句反派的不屑评论作为对照

细节控制：保持这段的"轻快"节奏，不要陷入冗长战斗

---

【节拍6】反派出场与压制 (推荐字数：600-800字)
情节目标：
- 反派正式登场，展现绝对优势
- 制造"主角可能不敌"的假象
- 为後续打脸做最大的反差

细节规划：
→ 反派的第一次出场要气势磅礴
→ 他/她压制主角的一个具体行为
→ 其他人物对反派的恐惧/尊敬反应
→ 主角此刻的"弱小"感，但眼中有不服

细节控制：这段要写得"压抑"，让读者跟着主角生气

---

【节拍7】新的敌手与斗争启始 (推荐字数：300-400字)
情节目标：
- 确认对抗的关键事件即将开始
- 最后的"暴风前的宁静"
- 为下一幕做心理准备

细节规划：
→ 大赛/比试/决战的正式开始通知
→ 主角的决心表现（可以是一句台词）
→ 配角们的分化反应
→ 反派的冷笑与挑衅

细节控制：简洁有力，不要过长

【第一幕结束】转折点确立：主角已获得力量，反派已现身，战争即将打响
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第二幕·冲突激化与转折(字数范围：7500-8500字)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【节拍8】首场对决·初次交手 (推荐字数：700-900字)
情节目标：
- 主角与反派第一次正式对抗
- 反派展现真实实力，压制主角
- 读者的期待感达到第一个高点

细节规划：
→ 对决的具体规则和环境描写
→ 反派的进攻方式（多个细节）
→ 主角的被动应对
→ 一个"主角要被击败"的危险时刻
→ 但主角用新能力避过，展现反击可能性

细节控制：战斗节奏要快，用短句营造紧张感，避免冗长招式描写

---

【节拍9】观众的震惊与反应 (推荐字数：300-500字)
情节目标：
- 侧面展现主角能力的不凡
- 配角们的持续反应很重要（"没人赞叹就不爽"）
- 制造出"事态正在升级"的感觉

细节规划：
→ 旁观者的对话："这怎么可能…"
→ 其中一个美女/重要人物的注目
→ 反派的第一次表情变化
→ 评委/旁人的议论纷纷

细节控制：用对话代替旁白，让读者通过别人的反应来理解主角的强大

---

【节拍10】反派的升级与新威胁 (推荐字数：500-700字) ⭐爽点2
情节目标：
- 反派不再轻视，使用真实手段
- 冲突升级，危险程度上升
- 暗示故事还有更大的秘密

细节规划：
→ 反派改变战术，展现新的能力
→ 一个让主角"真的有点被压制"的时刻
→ 但同时主角也在调整策略
→ 关键：这时要么主角有机遇升级，要么暗示主角有后招

细节控制：这是"高潮的前奏"，要制造出"风暴要来"的感觉

---

【节拍11】配角助力与情感线 (推荐字数：400-600字)
情节目标：
- 一个重要配角的出场或发声
- 加强情感线，制造情感冲击
- 为主角的逆袭做"有人相信"的铺垫

细节规划：
→ 某个配角对主角的支持/告白/激励
→ 这个配角曾经被主角帮过或看不起过
→ 此刻他/她的改变态度
→ 主角因此获得精神上的鼓舞

细节控制：情感线要简洁有力，一两个简短对话足矣，不要长篇叙述

---

【节拍12】中点转折·真相大白 (推荐字数：600-800字) ⭐核心转折
情节目标：
- 故事的核心秘密部分揭示
- 可能是反派的真实身份/目的
- 或主角能力的真实来源
- 或隐藏的更大敌人出现

细节规划：
→ 一个"冲击性"的信息被披露
→ 可以是通过配角的惊人说出，可以是主角突然领悟
→ 这个信息改变了主角对局面的理解
→ 也可能改变读者的理解

细节控制：设计一个"哇"的时刻，这将成为故事的转折点

---

【节拍13】再度对决·主角优势初现 (推荐字数：600-800字)
情节目标：
- 因为真相的了解，主角改变策略
- 此次对决，主角占据心理优势
- 反派第一次感到不安

细节规划：
→ 主角主动出击（姿态改变很重要）
→ 反派的应对变得更被动
→ 主角的招式更加有针对性
→ 一个"主角终于扳回一城"的爽快时刻

细节控制：这段要写得"舒气"，让读者的压抑感开始释放

---

【节拍14】更大的敌人暗示 (推荐字数：400-500字)
情节目标：
- 暗示还有更强的敌手
- 拉长故事的悬念
- 为最终高潮做铺垫

细节规划：
→ 一个神秘人物的现身或消息传来
→ 反派对这个人物的恐惧反应
→ 主角和配角们的惊讶
→ 一句威胁性的宣言或传言

细节控制：留悬念，不要说得太详细，制造"还有更大的大BOSS"的感觉

---

【节拍15】主角的能力再升级 (推荐字数：500-700字)
情节目标：
- 主角因为新的理解/经历，力量有新的突破
- 这是第二次的"爽感激活"
- 为最终对决做准备

细节规划：
→ 升级的触发（可能是某个领悟/某个物品/某个事件）
→ 力量的表现（感官盛宴）
→ 主角对自己新实力的初步测试
→ 一句"我现在有信心了"的自信台词

细节控制：这段可以多一些感官细节，但不要过长

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第三幕·高潮与解决(字数范围：4000-4500字)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【节拍16】最终对决的开局 (推荐字数：700-900字) ⭐最终爽点激活
情节目标：
- 主角与所有敌手的最终对决开始
- 打破之前"被压制"的局面
- 让读者真正感受到"逆袭"

细节规划：
→ 对决地点的壮阔描写（一两句）
→ 主角的最后姿态：自信、从容
→ 对手们的最终阵容
→ 主角的第一击：出人意料的强大

细节控制：开局要有"剧院感"，所有人都在看这场对决

---

【节拍17】反派们的崩溃过程 (推荐字数：900-1200字) ⭐打脸与虐反派
情节目标：
- 这是"打脸"最密集的段落
- 反派从嚣张到绝望的全过程
- 每一个对手都有各自的崩溃线

细节规划：
→ 第一个对手的意外被击败
→ 第二个对手试图联手，但依旧不敌
→ 反派的嚣张言论被现实打脸
→ 反派的表情从自信→惊讶→恐惧的过程
→ 最关键：写反派的"恐惧与绝望"（这是爽感的核心）
→ 其他对手试图逃跑或求饶

细节控制：这段是全文最"爽"的部分，可以多一些细节和对话，充分让读者过足打脸瘾

---

【节拍18】最强敌手的最终对决 (推荐字数：600-800字)
情节目标：
- 与最终BOSS的决出胜负
- 这不仅是力量的对抗，也是"道"的对抗
- 主角的胜利要体现"境界"的提升

细节规划：
→ 最强敌手的绝招/底牌展现
→ 主角同样用绝招对抗
→ 一个"势均力敌"的时刻
→ 主角最后时刻的顿悟或爆发
→ 最强敌手的最终一击失败，意识到败局已定

细节控制：这段不要过长，精短有力即可，关键是"主角赢了"这个结果

- 主角正式战胜所有敌手
```

## 使用指南

### 👉 如何一步生成完整创作方案

**推荐流程**：

1. **填写脑洞模板** → 收集你的核心设定（5-10分钟）
2. **输入到AI** → 用提示词："`请根据我的脑洞设定，参考【脑洞模板】第一部分，生成一份【第二部分：精简大纲模板】的完整版本`"
3. **获得大纲** → AI输出结构化大纲
4. **生成节拍表** → 继续用提示词："`请根据生成的大纲，参考【第三部分：节拍表】，生成一份完整的15000字节拍表，包含每个节拍的情节目标、细节规划、字数范围和输出效果`"
5. **获得节拍表** → 复制完整节拍表
6. **生成正文** → 最后用提示词："`请根据这份节拍表，每个节拍一段，生成一篇完整的15000字短篇爽文。要求每个节拍都符合规划的字数和情节，确保爽点密集、情节紧凑、读者3秒入坑`"

### 💡 提示词工程核心技巧

**关键技巧1：情节密度控制**

- 每200字必须出现一个冲突点
- 每300字必须出现一个悬念点
- 每500字必须有一个转折或升级
- 用"冲突"控制字数，而非"心理描写"或"环境描写"

**关键技巧2：爽感激活**

- 不要让主角"一直被压制"，要在序幕就给予一次"小爽"（金手指激活）
- 打脸时写反派的"恐惧与绝望"，而非只写反派的败北
- 让配角们的反应充分表现，"没人赞叹就不爽"
- 胜利场景要拉长，要有"仪式感"

**关键技巧3：三秒入坑的秘密**

- 开篇第一句必须是冲突或奇景
- 不要开篇就解释背景
- 用对话代替旁白
- 用短句制造紧张感

**关键技巧4：角色化而非单向**

- 每个配角出场时要有明确的作用
- 美女角色要多次出现反应，强化情感线
- 反派不是平面的坏蛋，要有逻辑和恐惧过程

## 常见优化方向

### ❌ 常见错误与修正

|错误做法|正确做法|原因|
| --------------| -----------------------------| --------------------|
|前期铺垫过长|前200字内必须出现冲突|三秒入坑的底线|
|只写主角胜利|详写反派的恐惧过程|打脸的本质是"对照"|
|配角无声|配角要有充分的震惊/赞叹反应|没有观众的胜利不爽|
|心理描写过多|用对话和行动代替内心戏|网文节奏要快|
|升级线断层|每500字一个升级/转折|维持读者期待感|
|情感线生硬|让情感在冲突中自然流露|别生硬的情感描写|
|结局仓促|胜利场景要拉长至少500字|读者要充分过爽瘾|
