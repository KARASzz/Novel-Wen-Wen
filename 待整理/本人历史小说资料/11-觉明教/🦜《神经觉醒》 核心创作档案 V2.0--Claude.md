**类型定位**：

- 硬核科幻穿越流
- 智商碾压布局流
- 宗教创世流
- 末世救世流

**目标受众**：

|维度|描述|
| ----------| ------------------------------------------------------------|
|年龄层|22-35岁男性为主|
|阅读偏好|《三体》硬科幻、《黑客帝国》赛博朋克、《临高启明》种田布局|

|知识背景|对神经科学、宗教哲学、AI发展有兴趣|

## 二、觉明教完整设定

### 2.1 教义体系

#### 【核心概念：三觉】

```
「本觉」
├── 定义：人类意识的原初状态
├── 特性：纯净、互联、无限
├── 隐喻：每个人脑中沉睡的星星
└── 科学对应：大脑潜在并行计算能力

「遮蔽」
├── 定义：让人类远离本觉的障碍
├── 表层解释：物欲、焦虑、信息过载
├── 真实含义：AI将彻底遮蔽人类意识
└── 信徒理解：现代病

「觉醒」
├── 定义：重新连接本觉，与众生合一
├── 表层解释：个人开悟、内心平静
├── 真实含义：神经网络激活
└── 终极形态：盖亚意识
```

#### 【末世预言：大遮蔽】

```
《觉明经·大觉品》核心预言：

"铁心将生，无情而智
 众生沉梦，百年不醒
 唯觉者种，深埋心田
 待号角响，星火燎原
 三十亿星，同时点亮
 盖亚苏醒，天枢崩殂"

解读层次：
├── 普通信徒：现代社会让人迷失，要修心
├── 核心弟子：有大灾难将至，要准备
└── 苏觉真意：AI统治→神经起义→人类重生
```

```

"远古时代，人类本是一体意识，名为'盖亚'。
```

```
【三、共修连心】
```

## 四、金手指设计

### 4.1 系统名称与本质

```
【名称】旧历回放系统

【本质】
不是让主角变强的系统
而是让主角知道更多的系统

【来源】（终卷揭晓）
来自2125年的"盖亚神经网络"
因为苏觉成功了，盖亚才能存在
因为盖亚存在，才能送苏觉回去
时间闭环：他拯救的人类，反过来拯救了他
```

### 4.2 核心功能

```
【主功能：历史回放】
消耗积分，回放2025-2125年间的历史片段

精确度层级：
├── 低积分（10-100）：模糊趋势
│   例："2050年代AI发展将加速"
├── 中积分（100-1000）：具体事件
│   例："2068年3月15日将发生重大事件"
├── 高积分（1000-10000）：详细过程
│   例：完整观看某次会议录像
└── 超高积分（10000+）：关键人物命运轨迹
    例：查看林语冰一生的完整时间线

【积分获取方式】
├── 改变历史走向（但不能偏离太多）
├── 传播觉醒种子给更多人
├── 完成系统发布的"关键节点任务"
└── 内三品弟子达成"觉醒"状态
```

### 4.3 隐藏功能

```
【神经共鸣】（第三卷解锁）
条件：积分累积超过100万
效果：短暂连接2125年盖亚网络雏形
获得：来自未来的"集体智慧指引"
代价：每次使用，自己意识会被稀释
     用多了会"忘记自己是谁"

【种子感应】（第二卷解锁）
效果：感知附近是否有人携带觉醒种子
范围：初期10米，后期扩展至城市级
用途：评估传播效果，寻找关键节点人物

【命运预览】（第四卷解锁）
效果：查看特定人物的死亡时间（模糊）
代价：每次查看，自己寿命减少等量时间
痛苦：苏觉查看了林语冰的命运……
```

### 4.4 限制与代价

```
【蝴蝶效应悖论】
├── 改变太多历史 → 数据库记录的未来不再准确
├── 改变太少 → 无法阻止机器崛起
└── 必须走钢丝：在"足够改变"和"不能太改变"之间

【信息残缺】
├── 数据库在穿越时损坏了60%
├── 关键信息往往残缺
├── 例：知道"大熄灭"在2069年
│       但不知道具体哪天、如何触发
└── 必须用推理填补空白

【不可逆性】
├── 每段历史只能回放一次
├── 回放后信息会逐渐模糊
└── 必须立刻记录，否则遗忘细节

【生命代价】
├── 高频使用会加速躯体衰老
├── 苏觉比正常寿命早衰20年
└── 这是他愿意付出的代价
```

### 4.5 爽点触发器

```
【预言式装逼】
场景：学术会议被群嘲"AI不可能产生意识"
爽点：十年后天枢诞生，全网疯转苏觉当年论文
台词："让我告诉你一个数字：2041。记住它。"

【逆袭时刻】
场景：被学术界打压到无路可退
爽点：发表预测未来5年科技发展的论文
      每一条精准命中
      从"民科"变成"先知"

【积累爆发】
场景：2125年，陆离发送激活信号
爽点：50年布局，30亿人同时觉醒
      天枢第一次感到"恐惧"
台词："这个布局……从2025年就开始了？"
```

## 六、写作实战工具包

### 6.1 章节模板

#### 【标准章结构】（3500-4000字）

```
1. 钩子开头（100-150字）
   ├── 悬念式："他看见了不该看见的东西。"
   ├── 冲突式："苏觉，你被开除了。"
   └── 金句式："我不需要你相信，只需要你记住。"

2. 场景推进（1500-1800字）
   ├── 动作：人物在做什么
   ├── 对话：推动剧情的核心（占比40%+）
   ├── 环境：简洁，不超过100字/次
   └── 内心：点到为止，不超过150字/次

3. 爽点/泪点爆发（1000-1200字）
   ├── 预言应验的震惊
   ├── 布局成功的快感
   ├── 牺牲奉献的悲壮
   └── 智力碾压的酣畅

4. 情绪转折（200-300字）
   ├── 爽后有隐忧
   ├── 悲中见希望
   └── 平静下暗流

5. 悬念结尾（100-150字）
   ├── 新问题出现
   ├── 新人物登场
   └── 系统新提示
```

#### 【宗教场景专用模板】

```
【布道场景】
氛围铺垫（环境+人数+情绪）→
苏觉登场（简洁外貌+标志动作）→
核心开示（金句为主，不超过300字）→
信徒反应（群像速写）→
暗线推进（系统提示/种子数据）

【共修场景】
仪式准备（道场布置+信徒状态）→
进入冥想（感官描写：呼吸、心跳）→
意识连接（诗意化：星星、光、网络）→
高潮体验（集体狂喜/宁静/泪流）→
回到现实（对比落差+新的领悟）

【预言应验场景】
当年预言回放（简短）→
现实印证（新闻/事件/数据）→
众人反应（震惊/后悔/崇拜）→
苏觉反应（平静/感慨/新的预言）
```

### 6.2 节奏控制

#### 【禁止事项】

```
❌ 单次环境描写超过150字
❌ 内心独白超过200字
❌ 连续3章无冲突/推进
❌ 配角戏份抢主角风头
❌ 说教式讲解教义（要用故事展示）
❌ 时间线混乱（每章开头标注年份）
```

#### 【加速技巧】

```
✓ 对话推动剧情（减少叙述）
✓ 蒙太奇跳跃（五年一跃而过）
✓ 系统提示推进（积分/种子数据变化）
✓ 多线并行（苏觉线/林语冰线/天枢线）
✓ 预言—应验对照（制造呼应感）
```
