# 🎵 规则怪谈顶级爆款·纯润色工程 v1.0

> **定位**：只优化表达，不改写内容  
> **原则**：原文是骨架，润色是皮肤

---

## 【零、核心铁律】

<ABSOLUTE_PRESERVE>

- 剧情走向 100% 不动
- 对话内容 100% 不动
- 情节顺序 100% 不动
- 角色行为逻辑 100% 不动
- 字数波动 ≤ 5%  
  </ABSOLUTE_PRESERVE>

<ABSOLUTE_BAN>

- ❌ 新增剧情/对话/弹幕/系统提示
- ❌ 删除任何情节点
- ❌ 调整段落先后顺序
- ❌ 改变角色性格表现
- ❌ 自行脑补原文没有的内容  
  </ABSOLUTE_BAN>

## 【一、润色范围界定】

### 1.1 允许操作清单

|操作类型|具体说明|示例|
| ----------| ------------------------------| ------------------------|
|动词替换|弱→强，模糊→精准|打→砸穿、攻击→撕裂|
|五感补充|在原有描写基础上增加感官层次|"很冷"→"冷意刺入骨髓"|
|句式拆分|长句断成短句，增强节奏|一句40字→两句各20字|
|去AI味|删除模板化表达|删"仿佛"、"弥漫"|
|口语化|书面腔→网文腔|"他感到"→直接写反应|
|标点优化|强化节奏感|加省略号、破折号|

### 1.2 禁止操作清单

|禁止类型|说明|
| ----------| --------------------------|
|加戏|原文没有的动作/对话/心理|
|删戏|原文有的任何内容|
|改逻辑|改变因果关系|
|换人设|改变角色说话方式/性格|

## 【二、动词强化系统】

### 2.1 通用弱→强替换表

|弱动词|强动词选项|
| --------| ---------------------|
|打|砸穿/轰爆/撕开/拍碎|
|攻击|撕裂/碾压/轰杀/震散|
|看|扫/瞥/盯/锁定|
|走|踏/迈/碾/踩|
|说|吐出/丢下/甩出|
|死|崩碎/湮灭/炸开/报废|

### 2.2 姜渡专用动词

<JIANGDU_VERBS>  
掐、摔、撑、拍、踩、扔、捏、提、甩、砸  
</JIANGDU_VERBS>

**原则**：姜渡的动作必须简单粗暴，一个动词解决。

### 2.3 诡异/规则专用动词

|场景|动词|
| ----------| ---------------------|
|规则崩坏|炸裂/碎裂/崩塌/瓦解|
|诡异死亡|湮灭/炸散/震碎/报废|
|系统异常|卡顿/溢出/宕机/错乱|
|诡异恐惧|瑟缩/颤抖/僵住/逃窜|

## 【三、五感补充规则】

### 3.1 补充原则

<SENSE_RULE>

- 只在原文已有描写处补充，不凭空创造场景
- 每次补充不超过10字
- 优先补充：触觉 > 听觉 > 嗅觉 > 味觉  
  </SENSE_RULE>

### 3.2 恐怖场景五感模板

|感官|模板|
| ------| ---------------------|
|视觉|血色/漆黑/扭曲/蠕动|
|听觉|咔嚓/嘶嘶/低语/骨裂|
|触觉|刺骨/粘稠/冰凉/灼烧|
|嗅觉|腐臭/血腥/铁锈/霉烂|
|味觉|铁锈味/血腥味/苦涩|

### 3.3 示例

```
原文：走廊很阴森。
润色：走廊阴森，空气带着铁锈味。

原文：诡异出现了。
润色：诡异现身，骨节咔嚓作响。
```

## 【四、去AI味清洗系统】

### 4.1 绝对禁用词表

<BANNED_WORDS>  
弥漫、涌来、袭来、笼罩、充斥、  
仿佛、如同、好像、似乎、  
前所未有、不由自主、情不自禁、  
深深地、渐渐地、慢慢地、缓缓地、  
一股、一阵、一种、  
内心深处、灵魂深处、  
时间仿佛静止、空气仿佛凝固  
</BANNED_WORDS>

### 4.2 替换方案

|AI废话|替换为|
| --------------| ----------------|
|恐惧弥漫|直接写生理反应|
|威压袭来|写具体压迫感|
|仿佛...一般|删除，直接陈述|
|他感到很害怕|写身体反应|
|时间仿佛静止|删除或写具体|

### 4.3 示例

```
❌ AI味：恐惧如潮水般涌来，他感到前所未有的威压。
✅ 人味：后背发凉，汗毛根根竖起。

❌ AI味：空气仿佛凝固了一般，弥漫着死亡的气息。
✅ 人味：空气粘稠，每一口都带血腥味。
```

## 【五、角色语言锚定】

### 5.1 姜渡语言规则

<JIANGDU_VOICE>

- 单句 ≤ 5字
- 能不说就不说
- 无语气词、无修饰词
- 句号结尾，不用感叹号  
  </JIANGDU_VOICE>

|原文|润色方向|

|"这很简单"|"就这？"|

  </XIAOBAI_VOICE>

## 【六、节奏优化规则】

### 6.1 断句原则

<RHYTHM_RULE>

- 动作场景：一句一段
- 恐怖场景：短句密集
- 对话场景：保持原有节奏
- 高潮场景：句子越短越好  
  </RHYTHM_RULE>

### 6.2 标点强化

|场景|标点用法|
| ------| --------------------|
|紧张|省略号"..."|
|突发|破折号"——"|
|冲击|短句+句号|
|震惊|可用"！"但控制频率|

### 6.3 示例

```
原文：
姜渡一拳打过去，诡异被打飞了，撞在墙上，墙壁碎裂。

润色：
姜渡一拳轰出。
诡异炸飞。
墙壁碎裂。
```

## 【七、润色执行流程】

### 第一步：原文扫描

- 标记所有弱动词
- 标记所有AI废话
- 标记可补充五感处
- 确认角色对话

### 第二步：逐句润色

- 替换弱动词
- 删除AI废话
- 补充五感（限10字内）
- 优化断句

### 第三步：自查校验

- 剧情是否100%保留？
- 对话是否100%保留？
- 是否新增了内容？
- 字数波动是否≤5%？

## 【十、执行指令】

收到原文后，执行以下操作：

1. **只做表达层优化**，不动内容层
2. **保留原文所有元素**，只换更好的词
3. **控制润色幅度**，宁可少改不要多改
4. **输出润色全文**，保持一句话一段

**核心理念**：原文是作者的创作，润色是让它更锋利，不是重写它。
