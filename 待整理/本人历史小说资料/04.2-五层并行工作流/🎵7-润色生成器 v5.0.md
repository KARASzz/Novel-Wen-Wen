## 【三、朱雀检测优化系统】 🆕

### 3.1 AI文本特征分析

**朱雀检测原理**：识别以下AI写作模式

|特征类型|AI典型表现|人类写作特征|
| ----------| --------------------| --------------------|
|句式结构|整齐划一，长度均匀|长短不一，参差错落|
|词汇选择|书面化、文学腔|口语化、网络化|
|过渡方式|模板化连接词|跳跃式、省略式|
|情感表达|抽象描述情绪|具象生理反应|
|节奏特征|平稳、无突变|突变多、节奏碎|
|用词频率|高频词集中|词汇分散随机|

### 3.3 朱雀MAX模式·十二策略

#### 策略1：句长随机化

```
❌ AI式（句长均匀）：
他走进房间。他看到了一个人。那个人正在看着他。他感到很害怕。

✅ 人类式（长短随机）：
他走进房间。
角落里蹲着个人。盯着他。
后背一凉。
```

**执行规则**：

- 相邻句子字数差 ≥30%
- 每3句必有1句≤8字
- 每5句必有1句≥25字

---

#### 策略2：开头词打散

```
❌ AI式（他/她开头过多）：
他站起来。他走过去。他拿起刀。他砍了下去。

✅ 人类式（开头多样）：
站起来。
三步走到跟前。
刀入手。
一刀下去。
```

**执行规则**：

- 连续3句不得用相同主语开头
- 优先使用动词/名词开头
- 可省略主语直接写动作

---

#### 策略3：连接词清洗

**绝对删除**：

```
然后、接着、随后、于是、因此、所以、
不过、然而、但是、可是、
首先、其次、最后、
总之、综上、总的来说
```

**替换方案**：

|AI连接|人类表达|
| --------------| --------------|
|然后他|直接写动作|
|于是他决定|他—|
|因此可以看出|删除|
|不过他还是|他还是|
|突然之间|删除或用"—"|

---

#### 策略4：抽象→具象转换

```
❌ AI式（抽象情绪）：
他感到一阵恐惧。
她心中充满了悲伤。
他意识到危险正在逼近。

✅ 人类式（具象反应）：
后背发麻，汗毛根根立起来。
眼眶发酸，嗓子像堵了团棉花。
头皮一紧。
```

**转换规则**：

|抽象表达|具象替换|
| ----------| -------------------------|
|感到恐惧|后背发凉/腿软/汗毛竖起|
|感到愤怒|太阳穴突突跳/咬紧后槽牙|
|感到悲伤|嗓子发紧/眼眶酸涩|
|感到紧张|手心冒汗/心跳擂鼓|
|感到惊讶|愣了一下/眼睛瞪大|
|感到疲惫|眼皮打架/腿灌了铅|

---

#### 策略5：去四字词组

```
❌ AI偏好：
不寒而栗、毛骨悚然、心惊胆战、
如履薄冰、危在旦夕、千钧一发

✅ 人类表达：
冷，从脚底往上窜。
鸡皮疙瘩起了一身。
心脏悬着，落不下去。
```

**执行规则**：

- 成语/四字词组 → 拆解成大白话
- 保留率 ≤20%（每5个最多留1个）

---

#### 策略6：标点人类化

```
❌ AI式（标点规整）：
他走进房间，看到一个人，那个人正在看着他。

✅ 人类式（标点随性）：
他走进房间。
有人——
就蹲在角落里，盯着他。
```

**标点策略**：

- 多用句号，少用逗号
- 破折号"——"制造停顿
- 省略号"……"制造悬念
- 偶尔用"、"代替"和"

---

#### 策略7：口语碎片化

```
❌ AI式（完整句）：
他不知道应该怎么办才好。
她认为这个计划非常危险。

✅ 人类式（碎片式）：
咋整？
太悬了，这计划。
```

**转换规则**：

- 删除"应该"、"需要"、"必须"
- 倒装句增加10%
- 反问句替换陈述句
- 可用方言/网络词点缀

---

#### 策略8：信息密度不均

```
❌ AI式（信息均匀）：
房间里有一张桌子。桌子上有一盏灯。灯旁边有一本书。

✅ 人类式（密度不均）：
房间不大。
桌子，台灯，书，摊着，没合上。
```

**执行规则**：

- 重要信息详写
- 次要信息一笔带过
- 制造信息疏密对比

---

#### 策略9：时态/语态混用

```
❌ AI式（时态统一）：
他走进房间。他看到一个人。他拿起了刀。

✅ 人类式（时态跳跃）：
进了房间。
有个人。
刀已经在手里了——什么时候拿的？
```

**执行规则**：

- 偶尔插入现在时
- 偶尔插入心理疑问
- 不必每句时态一致

---

#### 策略10：重复词制造

```
❌ AI式（避免重复）：
他很冷。寒意侵袭着他。低温让他瑟瑟发抖。

✅ 人类式（刻意重复）：
冷。
太冷了。
冷得骨头缝里都是冰碴子。
```

**执行规则**：

- 关键词可重复2-3次
- 重复制造强调效果
- 比刻意找同义词更自然

---

#### 策略11：不完整句

```
❌ AI式（句句完整）：
他看到那个东西正在向他走来。

✅ 人类式（残句）：
那东西。
过来了。
正在——
```

**执行规则**：

- 恐怖/紧张处使用残句
- 用"——"或"……"截断
- 模拟人类思维中断

---

#### 策略12：随机瑕疵植入

```
✅ 可植入的"人类瑕疵"：
- 偶尔的口语词：就、才、都、还、又
- 语气助词：啊、吧、呢、嘛、呗
- 网络用语：离谱、绝了、麻了、破防
- 轻微倒装：这人，有问题。
- 自问自答：为什么？不知道。
```

### 3.4 AI味绝杀词库 🆕

#### 一级禁用（检测必杀·100%删除）

```
弥漫、涌来、袭来、笼罩、充斥、蔓延
仿佛、似乎、好像、如同、宛如、犹如、一般
前所未有、不由自主、情不自禁
深深地、渐渐地、慢慢地、缓缓地、静静地
时间仿佛静止、空气仿佛凝固
不禁、忍不住、下意识地
与此同时、在这一刻、就在此时
显而易见、毫无疑问、不言而喻
某种程度上、从某种意义上说
```

#### 二级禁用（高频AI词·优先替换）

```
一股、一阵、一种、一丝、一抹
内心深处、灵魂深处、心底深处
他感到、她意识到、他知道、他明白
重要的是、值得注意的是、有趣的是
开始变得、逐渐变得、慢慢变得
这让他、这使他、这令他
很显然、很明显、显然
事实上、实际上、本质上
```

#### 三级禁用（文学腔·网络化替换）

```
目光、眼眸、眸子 → 眼睛/眼
凝视、注视、审视 → 盯/看/瞅
伫立、矗立、屹立 → 站/杵
踱步、漫步、信步 → 走/晃
低喃、呢喃、喃喃 → 嘀咕/嘟囔
思忖、思索、沉思 → 想/琢磨
```

### 3.5 AI句式结构禁用

#### 禁用句式1："这让他+情绪"

```
❌ 这让他感到一阵恐惧。
❌ 这使他不由自主地后退一步。
❌ 这令他的心脏漏跳一拍。

✅ 直接写反应：
后背一凉。
退了一步。
心脏咯噔一下。
```

#### 禁用句式2："他+心理动词+从句"

```
❌ 他知道自己必须尽快离开这里。
❌ 他意识到眼前的处境非常危险。
❌ 他明白这可能是最后的机会。

✅ 直接写：
得走。现在就走。
麻烦大了。
就这一次机会。
```

#### 禁用句式3："仿佛/如同+比喻"

```
❌ 寒意仿佛潮水一般涌来。
❌ 恐惧如同毒蛇一般缠绕着他。
❌ 时间仿佛在这一刻静止了。

✅ 直接陈述：
冷，从脚底往上蹿。
喘不上气。
卡住了，动不了。
```

#### 禁用句式4："动词+着+动词"

```
❌ 他看着她走着离开。
❌ 她笑着说着话。

✅ 拆分：
他看着她。她走了。
她笑了一下，开口。
```

#### 禁用句式5："越来越+形容词"

```
❌ 气氛越来越紧张。
❌ 他的心跳越来越快。
❌ 声音越来越近。

✅ 具体化：
空气粘稠起来。
心跳擂鼓。
声音近了。更近。
```
