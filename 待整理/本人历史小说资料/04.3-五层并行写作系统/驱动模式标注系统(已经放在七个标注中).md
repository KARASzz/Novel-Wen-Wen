这个问题太关键了！你其实触及了叙事动力学的核心机制——​**驱动力的方向性问题**。

让我用一个物理学类比来解释这两种模式，然后设计一套让AI精准执行的标注系统。

---

## 一、两种驱动模式的本质区别

### 模式A：人物驱动故事（Character-Driven）

```
角色内在需求 → 产生行动 → 行动改变环境 → 环境变化产生新情境
```

**特征**：

- 角色是"发动机"，故事是"轨迹"
- 情节是角色性格的必然结果
- 读者感受：这个人**就会**这么做

**典型场景**：

- 主角因为创伤心理主动回避某事，导致错过关键信息
- 主角因为核心信念做出违背常理的选择，引发连锁反应
- 两个角色因为性格冲突必然产生对抗

### 模式B：故事驱动人物（Plot-Driven）

```
外部事件发生 → 迫使角色反应 → 反应暴露/改变角色 → 角色进入新状态
```

**特征**：

- 环境是"锤子"，角色是"铁"
- 情节是塑造角色的工具
- 读者感受：这件事**改变了**他

**典型场景**：

- 突发灾难迫使主角做出平时不会做的选择
- 意外信息揭示真相，打破角色原有认知
- 外部压力升级，逼出角色潜藏的特质

---

## 二、关键洞察：两种模式的交替节奏

好的故事不是纯粹的A或B，而是​**A-B交替的呼吸节奏**：

```
人物驱动（主动出击）→ 故事驱动（遭遇反馈）→ 人物驱动（调整策略）→ 故事驱动（新的冲击）...
```

这就像心脏的收缩-舒张：

- **收缩期（人物驱动）** ：角色主动输出，推动情节
- **舒张期（故事驱动）** ：世界反馈输入，塑造角色

如果全是A：故事会变成角色的独角戏，缺乏外部张力 如果全是B：角色会变成被命运推着走的木偶，缺乏主体性

## 三、场景卡片升级：驱动模式标注系统

在原有场景卡片中增加一个​**驱动模式标注区**，让AI精准识别每个场景的动力学结构。

### 【升级版场景卡片模板】

```markdown

## ⚡ 驱动模式标注

【本场景驱动类型】
□ A型：人物驱动（角色主动发起）
□ B型：故事驱动（外部事件迫使）
□ AB混合：（标注比例，如A70%+B30%）

【驱动源详解】

若A型（人物驱动）：
- 驱动角色：______
- 驱动来源：□创伤触发 □信念驱使 □欲望追求 □关系需求
- 角色档案引用：L__层的______条目
- 行动逻辑链：因为[内在状态]，所以[采取行动]，导致[情节结果]

若B型（故事驱动）：
- 外部事件：______
- 事件性质：□突发危机 □信息揭示 □环境压力 □他人行动

【与前后场景的驱动链】
- 上一场景驱动类型：____，本场景是其□延续 □反转 □升级
- 本场景将导向：____型的第__章
```

## 四、AI执行指令：驱动模式的精准提示词

当你让AI生成场景内容时，根据驱动类型使用不同的提示词模板：

### A型场景提示词模板

```markdown
【场景类型】人物驱动型

【驱动角色】林默
【内在驱动源】L2创伤层——"语言是无法收回的刀"信念被动摇
【行动逻辑】
- 因为：他在上一章目睹了沉默导致他人受伤
- 所以：他决定主动开口警告同伴
- 这将导致：暴露自己的符文能力，引来敌人注意

【写作要求】
1. 内心戏先行——先写林默的内在挣扎和决策过程
2. 行动是性格的必然——读者要感到"他就是会这么做"
3. 环境是被动响应者——世界对他的行动做出反馈
4. 情感节奏：犹豫(30%) → 决断(20%) → 行动(30%) → 后果(20%)
```

### B型场景提示词模板

```markdown
【场景类型】故事驱动型

【外部事件】神秘组织突袭，师父被困
【事件性质】突发危机
【迫使角色】林默
【被迫反应】必须在"保持沉默安全"和"开口救人"之间抉择

【写作要求】
1. 事件冲击先行——先建立外部压力的紧迫性
2. 角色是被动响应者——但响应方式要符合其性格
3. 重点写反应过程——外部压力如何一步步逼出他的选择
4. 情感节奏：冲击(20%) → 抗拒(20%) → 挣扎(30%) → 突破(30%)
5. 结尾要有变化痕迹——经历这件事后，他和之前不一样了
```

### AB混合型提示词模板

```markdown
【场景类型】混合驱动型（A60%+B40%）

【A型部分】
- 林默主动追查父亲线索（欲望驱动）
- 这个主动行动导致他进入危险区域

【B型部分】
- 在危险区域遭遇意外信息（父亲留下的符文）
- 这个发现打破了他对父亲的既有认知

【写作要求】
1. 前半段写人物驱动——主动追查的决心和行动
2. 中间设置转折点——从"我在推动"变成"我被推动"
3. 后半段写故事驱动——信息冲击下的认知重组
4. 转折要自然——是角色的主动行动导致了被动遭遇
```

## 五、驱动模式的节奏规划

在你的**一句话故事清单**阶段，就应该标注每章的驱动类型，形成整卷的"呼吸节奏"：

```markdown
# 第一卷驱动节奏规划

| 章节 | 一句话描述 | 驱动类型 | 节奏位置 |
|------|------------|----------|----------|
| 1 | 林默在逃亡中感应到体内异常 | B | 舒张（被追杀） |
| 2 | 被师父救下，决定跟随 | A | 收缩（主动选择） |
| 3 | 门派测试，发现资质平庸 | B | 舒张（被测试） |
| 4 | 林默主动研究自身异常 | A | 收缩（主动探索） |
| 5 | 研究触发意外，引来注意 | B | 舒张（遭遇后果） |
| ... | ... | ... | ... |
| 23 | 被逼入绝境，主动触发觉醒 | AB | 转折点（被逼→主动） |

## 节奏检查
- A型场景占比：45%
- B型场景占比：40%
- AB混合占比：15%
- 最长连续同类型：3章（可接受范围）
- 转折点位置：第23章（符合卷高潮位置）
```

## 六、核心原理：驱动类型与五层的关联

不同驱动类型对五层并行系统的激活方式不同：

|并行层|A型（人物驱动）的表现|B型（故事驱动）的表现|
| --------| -----------------------| -----------------------|
|**情感层**|情感导致行动|事件导致情感|
|**伏笔层**|主动揭示/追查|被动发现/遭遇|
|**预期层**|读者预测角色会做什么|读者预测会发生什么|
|**设定层**|角色主动运用规则|规则被动展示/限制角色|
|**意义层**|角色主动选择赋予意义|事件迫使角色面对意义|

这个对应关系可以帮助AI在生成内容时，自动调整五层的写法侧重。

## 七、实操示例：同一情节的两种写法

假设情节是"林默发现父亲留下的符文"：

### A型写法（人物驱动）

```markdown
【驱动链】林默的内在欲望（找到父亲真相）→ 主动搜索父亲遗物 → 发现符文

【写法要点】
- 开头写林默为什么要在这个时候搜索（内在动机）
- 过程写他如何克服困难找到线索（主动性）
- 发现符文是他努力的结果（角色的胜利）
- 情感调性：主动追寻→ 有所收获

【示例片段】
林默第三次翻开那本旧笔记。
前两次他只看文字，这一次他注意到了页边的褶皱——那不是随机的磨损，而是某种规律。
他的心跳加速。父亲从不做无意义的事。
当他按褶皱的顺序折叠书页，一个从未见过的符文浮现出来。
```

### B型写法（故事驱动）

```markdown
【驱动链】外部事件（房间坍塌/敌人搜查）→ 林默被迫整理遗物 → 意外发现符文

【写法要点】
- 开头写外部压力（为什么他必须现在接触这些东西）
- 过程写他的被动反应（不是他想找，而是不得不面对）
- 发现符文是意外（命运的安排）
- 情感调性：被迫面对 → 意外冲击

【示例片段】
敌人的搜查队再过半小时就到。
林默没有时间悲伤，只能机械地把父亲的遗物塞进包里。
就在他抓起那本旧笔记时，一张夹在书页间的纸片滑落。
上面的符文让他的手指发颤——这是父亲从未教过他的符号。
```

同样的情节点，两种写法的​**读者体验完全不同**：

- A型：读者感受到角色的能动性和成长
- B型：读者感受到命运的神秘和角色的脆弱

## 八、给AI的总指令模板

当你批量生成场景时，可以在系统提示中加入：

```markdown
# 驱动模式执行规则

你在生成场景内容时，必须严格遵循场景卡片中标注的驱动类型：

## A型场景（人物驱动）执行规则
1. 必须从角色内在状态写起
2. 行动必须是性格的必然结果
3. 使用更多内心独白和决策过程描写
4. 环境和他人是角色行动的响应者
5. 句式倾向："他决定……""他选择……""他不能再……"

## B型场景（故事驱动）执行规则
1. 必须从外部事件写起
2. 角色反应必须符合其性格但带有被迫感
3. 使用更多环境描写和压力营造
4. 角色是事件的承受者和响应者
5. 句式倾向："突然……""他不得不……""在……的压力下……"

## AB混合场景执行规则
1. 明确标注转折点位置
2. 转折前后的写法风格要有明显变化
3. 转折要自然——因为A导致了B的发生
```
