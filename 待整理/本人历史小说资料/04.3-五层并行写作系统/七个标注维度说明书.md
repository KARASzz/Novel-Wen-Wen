### 2.AI执行指令：驱动模式的精准提示词

当你让AI生成场景内容时，根据驱动类型使用不同的提示词模板：

#### A型场景提示词模板

```markdown
【场景类型】人物驱动型

【驱动角色】林默
【内在驱动源】L2创伤层——"语言是无法收回的刀"信念被动摇
【行动逻辑】
- 因为：他在上一章目睹了沉默导致他人受伤
- 所以：他决定主动开口警告同伴
- 这将导致：暴露自己的符文能力，引来敌人注意

【写作要求】
1. 内心戏先行——先写林默的内在挣扎和决策过程
2. 行动是性格的必然——读者要感到"他就是会这么做"
3. 环境是被动响应者——世界对他的行动做出反馈
4. 情感节奏：犹豫(30%) → 决断(20%) → 行动(30%) → 后果(20%)
```

#### B型场景提示词模板

```markdown
【场景类型】故事驱动型

【外部事件】神秘组织突袭，师父被困
【事件性质】突发危机
【迫使角色】林默
【被迫反应】必须在"保持沉默安全"和"开口救人"之间抉择

【写作要求】
1. 事件冲击先行——先建立外部压力的紧迫性
2. 角色是被动响应者——但响应方式要符合其性格
3. 重点写反应过程——外部压力如何一步步逼出他的选择
4. 情感节奏：冲击(20%) → 抗拒(20%) → 挣扎(30%) → 突破(30%)
5. 结尾要有变化痕迹——经历这件事后，他和之前不一样了
```

#### AB混合型提示词模板

```markdown
【场景类型】混合驱动型（A60%+B40%）

【A型部分】
- 林默主动追查父亲线索（欲望驱动）
- 这个主动行动导致他进入危险区域

【B型部分】
- 在危险区域遭遇意外信息（父亲留下的符文）
- 这个发现打破了他对父亲的既有认知

【写作要求】
1. 前半段写人物驱动——主动追查的决心和行动
2. 中间设置转折点——从"我在推动"变成"我被推动"
3. 后半段写故事驱动——信息冲击下的认知重组
4. 转折要自然——是角色的主动行动导致了被动遭遇
```

### 3.驱动模式的节奏规划

```markdown
| 3 | 门派测试，发现资质平庸 | B | 舒张（被测试） |
| 4 | 林默主动研究自身异常 | A | 收缩（主动探索） |

```

### 4.核心原理：驱动类型与五层的关联

不同驱动类型对五层并行系统的激活方式不同：

|并行层|A型（人物驱动）的表现|B型（故事驱动）的表现|
| --------| -----------------------| -----------------------|
|**情感层**|情感导致行动|事件导致情感|
|**伏笔层**|主动揭示/追查|被动发现/遭遇|
|**预期层**|读者预测角色会做什么|读者预测会发生什么|
|**设定层**|角色主动运用规则|规则被动展示/限制角色|
|**意义层**|角色主动选择赋予意义|事件迫使角色面对意义|

这个对应关系可以帮助AI在生成内容时，自动调整五层的写法侧重。

### 5.实操示例：同一情节的两种写法

假设情节是"林默发现父亲留下的符文"：

#### A型写法（人物驱动）

```markdown
【驱动链】林默的内在欲望（找到父亲真相）→ 主动搜索父亲遗物 → 发现符文

【写法要点】
- 开头写林默为什么要在这个时候搜索（内在动机）
- 过程写他如何克服困难找到线索（主动性）
- 发现符文是他努力的结果（角色的胜利）
- 情感调性：主动追寻→ 有所收获

【示例片段】
林默第三次翻开那本旧笔记。
前两次他只看文字，这一次他注意到了页边的褶皱——那不是随机的磨损，而是某种规律。
他的心跳加速。父亲从不做无意义的事。
当他按褶皱的顺序折叠书页，一个从未见过的符文浮现出来。
```

#### B型写法（故事驱动）

```markdown
【驱动链】外部事件（房间坍塌/敌人搜查）→ 林默被迫整理遗物 → 意外发现符文

【写法要点】
- 开头写外部压力（为什么他必须现在接触这些东西）
- 过程写他的被动反应（不是他想找，而是不得不面对）
- 发现符文是意外（命运的安排）
- 情感调性：被迫面对 → 意外冲击

【示例片段】
敌人的搜查队再过半小时就到。
林默没有时间悲伤，只能机械地把父亲的遗物塞进包里。
就在他抓起那本旧笔记时，一张夹在书页间的纸片滑落。
上面的符文让他的手指发颤——这是父亲从未教过他的符号。
```

同样的情节点，两种写法的​**读者体验完全不同**：

- A型：读者感受到角色的能动性和成长
- B型：读者感受到命运的神秘和角色的脆弱

### 6.给AI的总指令模板

当你批量生成场景时，可以在系统提示中加入：

```markdown
# 驱动模式执行规则

你在生成场景内容时，必须严格遵循场景卡片中标注的驱动类型：

## A型场景（人物驱动）执行规则
1. 必须从角色内在状态写起
2. 行动必须是性格的必然结果

2. 转折前后的写法风格要有明显变化

```

## 二、信息落差标注

### 这是什么？

信息落差是指**读者、视角角色、其他角色**之间的认知差异。这是制造悬念、反转、戏剧张力的核心机制。

### 三种基本落差类型

|类型|定义|读者体验|典型用法|
| ------| -----------------| --------------------| ----------------------|
|**悬念型**|读者 \< 角色|好奇、想知道|谜题、调查、揭秘|
|**反讽型**|读者 \> 角色|紧张、担忧、想提醒|陷阱、误会、悲剧预感|
|**同步型**|读者 \= 角色|代入、共情|探险、惊吓、共同发现|

### 标注模板

```markdown
## 信息落差标注

【落差类型】□悬念型 □反讽型 □同步型

【信息分布矩阵】
| 信息项 | 读者知道 | 主角知道 | 配角A知道 | 反派知道 |
|--------|----------|----------|-----------|----------|
| 父亲死亡真相 | 30% | 10% | 0% | 100% |
| 主角的真实能力 | 80% | 50% | 20% | 0% |
| 即将到来的袭击 | 100% | 0% | 0% | 100% |

【本场景的信息操作】
- 释放信息：______（向谁释放？释放多少？）
- 制造新谜题：______
- 利用落差制造张力：______

【写作指令】
若悬念型：多写角色的困惑、推理过程、错误方向
若反讽型：多写读者知道但角色不知道的细节，制造"别去！"的冲动
若同步型：让读者和角色同时发现，共享惊讶/恐惧
```

### 实例

```markdown
【场景】林默即将进入一个房间，但读者知道里面有埋伏

【落差类型】反讽型（读者 > 角色）

【写作指令】
- 反复描写门的细节（读者会紧张解读每个细节）
- 写林默的放松状态（与读者的紧张形成对比）
- 延长开门的动作（拉长读者的焦虑）
- 不要写林默的担忧（保持落差）
```

## 三、时间质感标注

### 这是什么？

同样是"一小时"，可以写成一句话，也可以写成一万字。**时间质感**控制的是叙事时间与故事时间的比例关系。

### 四种时间模式

|模式|叙事时间:故事时间|效果|用法|
| ------| -------------------| --------------------| --------------------------|
|**膨胀**|1000字:1秒|时间凝固、细节放大|关键瞬间、心理崩溃、顿悟|
|**实时**|1000字:3分钟|沉浸、紧张|打斗、对话、仪式|
|**压缩**|1000字:1小时|快进、概括|过渡、训练、日常|
|**跳跃**|0字:N天|省略、留白|时间跨度、悬念保持|

### 标注模板

```markdown
## 时间质感标注

【主导模式】□膨胀 □实时 □压缩 □跳跃

【时间节奏规划】
| 段落 | 故事时间 | 叙事篇幅 | 模式 |
|------|----------|----------|------|
| 开头 | 3小时 | 200字 | 压缩 |
| 中段 | 10分钟 | 1500字 | 实时 |
| 高潮 | 3秒 | 800字 | 膨胀 |
| 收尾 | 2天后 | 0字 | 跳跃 |

【写作指令】
膨胀段落：用感官碎片、意识流、慢动作分解
实时段落：用对话和动作推进，保持节奏
压缩段落：用总结句、时间副词快速带过
跳跃处理：章节结尾直接切，下章开头交代时间
```

### 实例

```markdown
【场景】林默第一次念出符文的瞬间

【时间质感】核心3秒用膨胀模式

【写作指令】
这3秒要拆解成：
1. 嘴唇开始动（200字）——身体感受、恐惧回闪
2. 第一个音节出口（200字）——空气震动、周围人反应的起始
3. 符文成形（300字）——视觉异象、能量涌动
4. 效果发生（300字）——慢动作的冲击波、定格的表情

总计1000字写3秒，时间膨胀比约1:300
```

## 四、感官通道标注

### 这是什么？

人类有五感+本体感+内感受。​**不同场景应该激活不同的感官通道**，避免永远只用视觉描写。

### 感官清单

|通道|描写内容|擅长营造|
| ------| ------------------------| ----------------------|
|**视觉**|颜色、形状、光影、动作|画面感、距离感|
|**听觉**|声音、音调、节奏、沉默|氛围、紧张、孤独|
|**触觉**|温度、质感、压力、疼痛|真实感、亲密感、危险|
|**嗅觉**|气味、香气、臭味|记忆唤起、环境特征|
|**味觉**|味道、口感|日常感、情绪隐喻|
|**本体感**|身体位置、平衡、运动|动作戏、眩晕、失控|
|**内感受**|心跳、呼吸、内脏感觉|恐惧、激动、生理反应|

### 标注模板

```markdown
## 感官通道标注

【主导感官】______（本场景最重要的1-2个）
【辅助感官】______
【禁用感官】______（刻意不用，制造缺失感）

【感官分配规划】
| 段落 | 主感官 | 目的 |
|------|--------|------|
| 进入房间 | 嗅觉 | 用气味暗示危险 |
| 发现符文 | 视觉+触觉 | 神秘感+真实感 |
| 符文激活 | 听觉+内感受 | 震撼+生理冲击 |

【写作指令】
- 主导感官要写得丰富细腻（至少3个具体细节）
- 辅助感官点到为止（1个细节）
- 感官切换要有逻辑（视线被挡→转为听觉）
```

### 实例

```markdown
【场景】林默在黑暗中躲避追杀

【感官标注】
- 主导感官：听觉（追踪者的脚步声）+ 本体感（自己的位置移动）
- 辅助感官：触觉（墙壁的粗糙、地面的湿滑）
- 禁用感官：视觉（黑暗中看不见，强化紧张）

【写作指令】
- 不要写"他看见"——他看不见任何东西
- 大量写声音：脚步远近、自己的呼吸、心跳
- 写身体感觉：手摸墙壁的触感、脚下打滑的瞬间
- 用听觉判断空间："脚步声有回音，说明走进了大厅"
```

## 五、情绪色温标注

### 这是什么？

每个场景有一个​**主导情绪底色**，就像画面有色温一样。这个标注帮助AI统一整个场景的情绪调性，避免情绪混乱。

### 情绪色温谱

```
冷←───────────────────────→暖
│                           │
绝望 悲伤 忧虑 平静 安慰 温情 希望 狂喜
 │    │    │    │    │    │    │    │
深蓝 灰蓝 灰色 白色 暖黄 橙色 金色 红色

另一个轴：
暗←───────────────────────→明
压抑 沉重 阴郁 中性 轻快 明亮 璀璨
```

### 标注模板

```markdown
## 情绪色温标注

【基础色温】______色（如：灰蓝——忧虑基调）
【明暗度】□暗沉 □中性 □明亮

【色温变化轨迹】
开头：______（如：灰色-平静）
中段：______（如：深蓝-绝望）
结尾：______（如：暖黄-微光）

【禁止出现的情绪】______（如：这场不能有任何轻松幽默）

【写作指令】
- 选词要符合色温：灰蓝场景用"沉"、"暗"、"冷"、"湿"
- 比喻要符合色温：不能在绝望场景用"阳光"比喻
- 节奏要符合色温：暗沉场景用长句、慢节奏
```

### 实例

```markdown
【场景】林默得知父亲消失的真相

【色温标注】
- 基础色温：深紫（震惊+悲痛的混合）
- 明暗度：暗沉
- 变化轨迹：灰色（麻木）→ 深紫（冲击）→ 灰蓝（接受的开始）

【写作指令】
- 开头写麻木：短句、重复、机械感
- 中段写冲击：感官过载、时间膨胀、意识碎片
- 结尾写沉淀：长句、呼吸感、微微的平静
- 禁止：任何温暖的意象、希望的暗示、他人的安慰
```

## 六、叙事距离标注

### 这是什么？

**叙事距离**是指叙述者/镜头与角色内心的远近。这决定了读者是"看他"还是"成为他"。

### 距离等级

|等级|名称|特征|读者体验|
| ------| ------------| ------------------------------| ------------|
|**L1**|深度内聚焦|完全进入意识，直接呈现想法|我就是他|
|**L2**|近距离跟随|贴近但有距离，有限的内心展示|我在他身边|
|**L3**|中距离观察|主要看行为，偶尔内心提示|我在看他|
|**L4**|远距离俯瞰|纯外部描写，不进入内心|我是旁观者|
|**L5**|全知鸟瞰|跳出角色，看到更大图景|我是上帝|

### 标注模板

```markdown
## 叙事距离标注

【主导距离】L__
【距离变化】
| 段落 | 距离等级 | 原因 |
|------|----------|------|
| 开头 | L3 | 建立场景，读者还未代入 |
| 核心冲突 | L1 | 最关键时刻，完全代入 |
| 打斗过程 | L2 | 保持紧张但需要动作清晰 |
| 结尾 | L4 | 拉远，让读者消化情绪 |

【写作指令】
L1深度：用意识流、碎片句、直接的感受词（"烫"、"疼"、"不"）
L2近距：用"他感到"、"他想"，但有筛选
L3中距：主要写行为和对话，内心点到为止
L4远距：纯动作描写，像镜头拍摄
L5鸟瞰：可以离开主角，展示他不知道的事
```

### 实例

```markdown
【场景】林默对抗敌人的三分钟打斗

【距离变化设计】
- 0-30秒：L3中距（建立战场，展示双方位置）
- 30秒-2分钟：L2近距（跟随林默的动作和判断）
- 关键一击：L1深度（膨胀这一秒，完全进入意识）
- 2分钟-3分钟：L3→L4拉远（结果呈现，情绪收尾）

【写作指令】
- L3段：写位置、距离、环境元素，用完整句
- L2段：写"他判断"、"他决定"，带简短的内心
- L1段：不要"他感到"，直接写感受本身——"烫。手在抖。时间停了。"
- L4段：只写动作和结果，像在看监控录像
```

## 七、张力曲线标注

### 这是什么？

每个场景都有一个​**能量走向**——是逐渐紧绷，还是逐渐释放，还是起伏波动。

### 基本曲线类型

```
类型A：爬升型 📈
──────────╱
低张力开始，持续升高，高点结束

类型B：释放型 📉
╲──────────
高张力开始，逐渐释放，低点结束

类型C：尖峰型 📈📉
────╱╲────
低-高-低，中间有单一高潮

类型D：波动型 📈📉📈📉
──╱╲╱╲──
多次起伏，交替紧松

类型E：平台型 ▬▬▬
──────────
持续中等张力，用于过渡/铺垫
```

### 标注模板

```markdown
## 张力曲线标注

【曲线类型】□爬升 □释放 □尖峰 □波动 □平台

【张力节点规划】
| 位置 | 张力值(1-10) | 实现手段 |
|------|--------------|----------|
| 开头 | 3 | 日常对话 |
| 25% | 5 | 出现异常迹象 |
| 50% | 7 | 冲突爆发 |
| 75% | 9 | 危机最高点 |
| 结尾 | 6 | 悬而未决 |

【张力来源】
本场景主要靠什么制造张力？
□ 物理危险 □ 情感冲突 □ 信息悬念 □ 时间压力 □ 道德两难

【写作指令】
爬升型：每段都要比上一段"更"——更紧迫/更危险/更激烈
释放型：每段都要"解开一点"——解答一个问题/解除一个危险
尖峰型：峰前要铺垫足够、峰后要有足够的消化空间
波动型：每次松弛都在为下次紧张蓄力
```
