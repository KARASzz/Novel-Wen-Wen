## 一、生产流水线

```markdown
## 标准化生产流程

### 阶段0：预制准备（一次性）
1. 完成所有主要角色的【角色档案】
2. 填充【五层并行文档】
3. 写出全卷【一句话故事清单】

### 阶段1：每日启动（15分钟）
输入：今天要写的3章一句话描述
输出：3张完整场景卡片

### 阶段2：节拍展开（15分钟）
基于场景卡片生成详细节拍表

### 阶段3：正文生成（主要工作量）
基于节拍表生成正文，AI生成初稿 → 人工校对润色

### 阶段4：回写更新（10分钟）
将本章实际产出回写到五层文档
- 情感图谱：更新角色情感状态
- 伏笔账本：标记埋设/兑现状态
- 预期引擎：记录预期差效果
- 设定锚点：更新规则使用情况
- 意义织网：记录意象变奏
```

## 二、双向校验机制

这是系统最关键的部分——​**角色内核与场景并行层的双向校验**。

#### 正向校验：角色 → 场景

在写任何场景前问：

```
1. 这个情境会触发角色的哪个创伤点？（参照L2心理考古）
2. 角色在这个情境下的默认反应是什么？（参照L3行为模式库）
3. 这个场景在角色成长弧线的哪个位置？（参照L5成长轨迹）
4. 涉及的关系动力学是什么？（参照L4关系拓扑）
```

#### 逆向校验：场景 → 角色

写完场景后问：

```
1. 角色的反应是否符合他的信念系统？
2. 如果不符合，是成长导致的改变，还是写作失误？
3. 如果是成长，这个转变是否有足够的铺垫？
4. 需要回溯修改角色档案还是修改场景？
```

## 三、系统使用技巧

### 角色档案填写技巧

#### L2心理考古层的关键

```markdown
【错误示例】
原生创伤：童年被霸凌

【正确示例】
原生创伤：8岁时，他在全班面前念错了一个字，老师说"连这个都不会，你还能做什么？"全班哄笑。那一刻他决定：永远不要在不确定的时候开口。

核心：具体场景 + 形成的信念
```

#### L3行为模式库的应用

```markdown
行为模式不是性格描述，而是"如果...那么..."的条件反射：

面对权威：先观察对方期待什么，然后给出对方想要的答案
面对亲密：主动保持距离，用"为你好"的理由推开对方
面对威胁：优先收集信息，避免正面冲突

这些模式会在场景中自动激活，确保角色行为的一致性。
```

### 场景标注的优先级

#### 必填项（每个场景都要标注）

1. 驱动模式：决定场景的基本写法
2. 情绪色温：决定整体氛围
3. 张力曲线：决定节奏走向

#### 选填项（根据场景特点选择）

1. 时间质感：关键场景用膨胀，过渡场景用压缩
2. 感官通道：特殊环境或氛围场景重点标注
3. 叙事距离：情感高潮时调整距离

#### 高阶参数（精雕细琢时使用）

1. 语义密度：控制信息量
2. 句法节奏：控制呼吸感
3. 隐显控制：控制表达方式
4. 潜文本深度：控制对话层次

### 常见问题解答

#### Q1：角色档案太复杂，能简化吗？

A：可以分阶段填写。初期只填L1、L2、L3，写作过程中逐步完善L4、L5。但L2心理考古是核心，必须详细。

#### Q2：每个场景都要填完整卡片吗？

A：不需要。日常场景可以用简化版：

```markdown
驱动：A/B | 色温：暖黄 | 张力：平台 | 距离：L2
```

#### Q3：AI生成的内容不符合标注怎么办？

A：检查提示词是否包含了所有标注参数，必要时分段生成，每段单独给出标注要求。

#### Q4：五层并行文档太繁琐，能省略吗？

A：情感图谱和伏笔账本是核心，不能省略。其他三层可以简化，但不能完全省略。

### 进阶技巧

#### 参数联动效应

不同参数组合会产生特定的读者体验：

##### 恐怖场景组合

```markdown
驱动：B型 | 信息：反讽 | 时间：膨胀 | 感官：听觉+内感受
色温：深蓝+暗 | 距离：L1 | 张力：爬升
语义：稀疏 | 节奏：短促 | 隐显：9:1隐 | 潜文本：深
```

##### 温情场景组合

```markdown
驱动：A型 | 信息：同步 | 时间：实时 | 感官：触觉+视觉
色温：暖黄+明 | 距离：L2 | 张力：释放
语义：稀疏 | 节奏：绵延 | 隐显：7:3隐 | 潜文本：浅
```

#### 系统扩展

##### 添加新的标注维度

系统支持扩展，可以根据特定类型小说添加专门的标注维度：

- 悬疑小说：线索密度标注
- 言情小说：亲密度标注
- 科幻小说：设定复杂度标注

##### 自定义参数组合

可以为常用场景类型预设参数组合，形成"场景模板库"：

- 打斗场景模板
- 对话场景模板
- 心理描写模板
- 环境描写模板

## 四、系统优势总结

1. **精确控制**：13维标注确保AI输出的精准性
2. **一致性保证**：角色档案+双向校验确保逻辑一致
3. **全局管理**：五层并行文档确保整体协调
4. **标准化流程**：可复制的生产流水线
5. **可扩展性**：模块化设计支持个性化定制

这套系统将AI从"随机创作工具"升级为"精密创作仪器"，让你能够像导演一样精确控制每个场景的效果。
