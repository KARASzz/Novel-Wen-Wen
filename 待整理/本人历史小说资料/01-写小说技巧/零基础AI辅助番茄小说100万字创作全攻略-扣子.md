# 零基础AI辅助番茄小说100万字创作全攻略-扣子

## 一、创作前期准备：精准定位番茄热门赛道

### 1.1 2025年番茄小说爆款品类分析

根据平台数据，当前最具流量潜力的三大品类为：

- **都市脑洞文**（日均流量占比35%）：底层逆袭+系统/金手指，如《开局送外卖，被全网直播》通过"屌丝逆袭+打脸暴富"公式，每3章设置装逼情节
- **末世脑洞文**（暑期流量暴涨200%）：天灾囤货+反套路设定，参考《全球高温：我囤积百亿物资》，建议加入"丧尸跳广场舞"等沙雕元素
- **规则怪谈**（用户停留时长超普通小说3倍）：死亡规则+高智商博弈，如《十日终焉》采用章节末尾"选择题"互动设计

### 1.2 核心卖点设计公式

- **爽点密度**：每3章一个小爽点（打脸/逆袭），10章一个大高潮
- **金手指创新**：结合热点设计差异化系统，如"直播+环保打脸"、"外卖员差评系统"
- **人设反差**：女频流行"黑莲花事业脑女主"（占比61%），男频偏好"高智商反社会男主"（搜索量上涨139%）

## 三、创作流程搭建：AI辅助的工业化生产链

### 3.1 分阶段大纲生成模板

**总纲框架**（示例：末世囤货文）：

```markdown
1. 生存阶段（1-30章）：觉醒空间→首次危机→建立基地
2. 扩张阶段（31-80章）：遭遇其他幸存者→资源争夺→势力建立
3. 反攻阶段（81-150章）：揭秘灾难真相→联合人类→重建文明
```

**章纲Prompt示例**：

```
生成第15章大纲，要求：
- 场景：暴雨夜超市遭遇
- 冲突：主角与小偷团伙对峙
- 爽点：空间能力首次公开使用
- 伏笔：小偷提及"官方避难所"
```

### 3.2 黄金三章AI生成指南

**第一章Prompt**：

```
创作都市逆袭文第一章，要求：
- 300字内：主角被女友当众羞辱并分手
- 800字处：激活"差评逆袭系统"
- 结尾钩子：收到神秘外卖订单（实际是系统任务）
```

**AI输出优化技巧**：

- 保留AI生成的情节框架，重写所有对话
- 将AI的"他很愤怒"改为具象动作："攥碎的矿泉水瓶在掌心变形"

## 四、番茄平台适配：算法偏好与流量引爆

### 4.1 推荐算法核心指标

- **完读率**：10万字读完率需≥15%（进入下一轮推荐池关键）
- **追读率**：每章末尾设置选择题（如"是否相信小偷的避难所情报？"）
- **互动率**：段评区引导讨论，如"你觉得女主该原谅渣男吗？"

### 4.2 标题与标签优化公式

**爆款标题模板**：`数字+反差+悬念`  
示例：《结婚3年，总裁突然说要追我？》（点击率提升40%）

**黄金标签组合**：

- 主标签：#重生逆袭 #末世囤货
- 次标签：#空间 #系统流（算法识别关键词）

## 五、百万字创作规划：可持续的更新体系

### 5.1 时间管理方案

- **日更4000字拆解**：
  - 晨间（7:00-9:00）：AI生成2000字
  - 晚间（21:00-22:00）：人工润色+发布
- **存稿策略**：每周额外生成2万字存稿，应对突发情况

### 5.2 剧情保鲜技巧

- **支线剧情库**：建立10个备用支线（如主角身世之谜）
- **角色轮换**：每50章引入新反派，避免审美疲劳
- **AI反套路提示**："生成3个打破末世文常规的情节"

## 六、风险规避与质量把控：AI创作的平衡术

### 6.1 查重风险控制

- **安全阈值**：AI生成内容≤60%，人工原创≥40%
- **降重技巧**：
  1. 打乱AI生成的段落顺序
  2. 替换50%的形容词和动词
  3. 增加角色方言和口头禅

### 6.2 内容质量提升要点

- **人工润色重点**：
  - 对话个性化（如理工男说话带公式）
  - 情绪细节（如"她攥紧的衣角绞出了水痕"）
- **读者反馈迭代**：每周分析差评，用AI生成修改方案
