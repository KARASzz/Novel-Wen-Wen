# 扣子空间高级提示词工程指南2

## 一、全流程规划：四阶段创作法

### 1. 世界观构建阶段（1-2周）

**核心目标**：创建逻辑自洽的科幻设定体系，包含3大维度：

- **科技体系**：关键技术原理、应用场景及限制（如"曲率引擎需消耗暗物质，单次跃迁最大距离5光年"）
- **社会结构**：政治体制、文化习俗、阶级划分（如"星际议会由7个行星文明组成，按科技等级分配表决权"）
- **宇宙规则**：物理法则变异、时空特性、外星文明接触史（如"在黑洞附近时间流速为外界的1/100，已导致3次外交冲突"）

**输出物**：《世界观设定手册》（含5-8个核心设定文档）

### 2. 角色设计阶段（3-5天）

**核心目标**：塑造3类关键角色：

- **主角团**：包含1个核心主角（如"掌握时间回溯能力的前星际特工"）、2-3个功能性配角（技术专家/外交家/反派转化者）
- **反派势力**：具有合理动机的对立阵营（如"主张人类至上的地球孤立主义联盟"）
- **背景角色**：体现世界观多样性的次要人物（如"硅基生命外交官"）

**输出物**：《角色档案集》（每个角色含生理特征/心理画像/成长弧线）

### 3. 情节架构阶段（1周）

**核心目标**：搭建三幕式框架：

- **第一幕（引入）** ：日常打破+冒险召唤（如"主角在例行巡逻中发现史前文明信号"）
- **第二幕（冲突）** ：中点反转+最大危机（如"发现信号来自未来人类，而非外星文明"）
- **第三幕（解决）** ：最终对决+世界观影响（如"阻止时间悖论，代价是牺牲个人记忆"）

**输出物**：《分章节情节大纲》（含每章关键场景/伏笔设置/情绪曲线）

### 4. 章节创作与修订阶段（持续进行）

**核心目标**：实现"创作-反馈-优化"循环：

- **初稿生成**：按场景单元写作（每单元1500-2000字）
- **风格统一**：确保科技描述与人文情感的平衡（如"用诗意语言描写超新星爆发，同时解释其物理成因"）
- **逻辑校验**：检查设定一致性（如"避免前章已损坏的设备在后章无理由修复"）

**输出物**：章节初稿+修订笔记

## 二、分阶段提示词模板与优化案例

### 【阶段一：世界观构建】提示词优化

#### 基础版（低效）

```
帮我想一个科幻世界观，要有未来科技和外星人。
```

#### 优化版（高效）

```
设计硬科幻世界观，需满足：
1. 核心科技：量子意识上传技术（明确原理：通过脑机接口将神经元活动编码为量子比特）
2. 社会影响：
   - 仅20%人类通过"意识纯度测试"获得上传资格
   - 未通过者形成"肉身党"，建立地下反抗组织
3. 物理限制：上传意识需在绝对零度环境下进行，每次上传导致10%记忆永久丢失
4. 参考风格：《银翼杀手2049》的视觉美学 + 《攻壳机动队》的哲学深度
请用表格形式呈现3个核心冲突（技术/社会/伦理）及解决方案雏形。
```

#### 优化要点：

- **参数化设定**：将模糊概念转化为可量化规则（如"20%通过率"）
- **冲突预设**：主动设置矛盾点，避免世界观过于平淡
- **跨媒介参考**：同时指定文学/影视风格，强化画面感

### 【阶段二：角色设计】提示词优化

#### 基础版（低效）

```
写一个科幻小说主角，要厉害一点，有超能力。
```

#### 优化版（高效）

```
设计主角：
1. 身份：前"星际考古局"首席研究员，因发现"时间晶体"被指控叛国
2. 核心能力：能与史前文明遗物建立精神连接（限制：每次连接后会短暂失明）
3. 心理矛盾：
   - 坚信考古发现能拯救文明 vs 恐惧能力带来的副作用
   - 对指控者（昔日导师）既憎恨又依赖
4. 语言风格：混合专业术语（"这个星图符合托勒密坐标系"）与黑色幽默（"我的视网膜又在抗议了，老伙计"）
请提供3个关键记忆片段（童年/转折点/创伤事件），解释能力觉醒过程。
```

#### 优化要点：

- **能力代价绑定**：避免"无敌主角"，赋予能力合理限制
- **关系网络**：明确与其他角色的动态关系
- **记忆锚点**：用具体事件塑造角色深度，避免扁平化

### 【阶段三：情节设计】提示词优化

#### 基础版（低效）

```
写一个科幻故事，要有太空旅行和阴谋。
```

#### 优化版（高效）

```
设计第7章节情节（中点反转章节）：
1. 场景：主角团队在废弃空间站发现"未来人类留言"
2. 关键对话：
   - 技术专家："这段代码与我们的飞船系统完全兼容..."（暗示人类文明循环）
   - 反派："你们以为是发现，其实是回归..."（首次揭示动机）
3. 伏笔回收：
   - 呼应第2章出现的神秘符号（此处解密为时间坐标）
   - 主角头痛症状升级（为后续能力觉醒铺垫）
4. 情绪曲线：从"发现希望"（兴奋）→"真相冲击"（震惊）→"决心转变"（凝重）
请用三幕式结构呈现该章节，并标注每个场景的镜头感（如"全景：空间站残骸漂浮在紫色星云背景中"）。
```

#### 优化要点：

- **场景可视化**：加入镜头描述，增强画面感
- **伏笔管理**：明确前后文关联，避免情节断裂
- **情绪控制**：设计情绪波动曲线，避免平铺直叙

### 【阶段四：章节创作】提示词优化

#### 基础版（低效）

```
写一段主角在太空战斗的场景，要激烈一点。
```

#### 优化版（高效）

```
撰写第12章战斗场景：
1. 环境设定：小行星带内部，重力异常区域（每30秒重力方向反转一次）
2. 战斗双方：
   - 主角方：受损的侦查舰"星尘号"（仅剩2门离子炮）
   - 敌方：3架无人机（采用狼群战术，弱点在腹部散热口）
3. 技术描写要求：
   - 离子炮充能时驾驶舱蓝光脉动（视觉细节）
   - 重力反转时角色内脏位移的生理感受（触觉描写）
4. 叙事视角：第三人称限制视角（仅展现主角感知，保留敌方动机悬念）
5. 参考风格：《星际公民》太空战斗的物理真实感 + 《异形》的幽闭恐惧感
请控制在1800字左右，包含3次战术转折（佯攻→诱敌→绝杀）。
```

#### 优化要点：

- **感官细节**：调动视觉/触觉/听觉描写，避免纯动作堆砌
- **战术逻辑**：战斗需体现策略性，而非单纯力量对抗
- **视角控制**：通过限制视角制造悬念，符合长篇叙事需求

## 三、科幻写作专属提示词技巧

### 1. 科技设定的"三层解释法"

在提示词中明确科技描述的深度：

- **表层**：读者可直观理解的功能（如"这是能穿越墙壁的量子门"）
- **中层**：半专业解释（如"通过量子隧穿效应重构物质波函数"）
- **深层**：核心限制（如"每次使用会在空间留下0.1秒的时间空洞"）

### 2. 世界观"冲突检查表"

创作提示词时主动加入：

- □ 技术滥用导致的社会分化
- □ 不同文明间的价值观冲突
- □ 科学突破与伦理底线的博弈
- □ 个人自由与集体安全的平衡

### 3. 创意激发"反套路"提示

当情节卡顿，使用逆向思维提示词：

```
当前情节：主角团准备炸毁反派基地
请提供3个反套路发展方向，要求：
1. 方案1：技术反转（炸毁行为触发基地的自我进化程序）
2. 方案2：道德反转（基地内存在主角未曾谋面的亲人）
3. 方案3：规则反转（爆炸产生的能量恰好满足反派的终极实验）
每个方案需说明对后续剧情的3个影响点。
```

## 四、常见问题解决方案

### 1. 设定遗忘或矛盾

**解决提示词**：

```
基于《世界观设定手册》第3章，检查以下情节是否存在逻辑矛盾：
1. 主角使用"超光速通讯器"（设定中该设备需恒星能量驱动）
2. 场景发生在"无恒星的废弃星系"
请提出3种合理化修改方案（设备改装/环境伏笔/规则补充），保持原剧情核心不变。
```

### 2. 角色动机薄弱

**解决提示词**：

```
分析角色"伊芙"在第5章背叛行为的动机缺陷：
当前描述："她突然向敌人泄露了情报"
请补充：
1. 3个潜意识驱动因素（童年经历/未实现的愿望/隐秘创伤）
2. 2个矛盾行为细节（如"泄露情报前故意留下误导性线索"）
3. 1句体现内心挣扎的内心独白（符合其语言风格）
```

### 3. 科幻元素与人文脱节

**解决提示词**：

```
将以下科技描述转化为情感体验：
原句："量子跃迁导致飞船进入了更高维度"
优化要求：
1. 加入3个感官细节（视觉：仪表盘数字变成流动的光；听觉：船员的心跳声被放大；触觉：指尖感到时间纹理）
2. 体现主角的哲学思考（"在四维视角下，过去与未来的界限像水墨画一样晕开"）
3. 保持科学准确性（参考M理论的高维空间模型）
```

## 五、工具协同建议

1. **世界观可视化**：如需为关键场景生成概念图，可补充提示词：

```
基于《世界观设定手册》第2章，生成"水晶城市"概念图描述：
- 建筑特征：有机形态+几何晶体结构，表面覆盖光感材料
- 环境氛围：永恒黄昏（两颗恒星处于地平线下）
- 科技元素：悬浮的反重力交通舱（发出蓝绿色脉冲光）
请用500字详细描述，适合作为设计工具的输入文本。
```

2. **情节节奏检查**：使用表格输出每章情绪值：

```
分析前10章情绪曲线：
1. 每章标注情绪类型（紧张/悲伤/希望/疑惑）及强度（1-10分）
2. 识别情绪低谷章节（<3分）和高峰章节（>8分）
3. 建议调整方案，确保没有连续3章情绪类型相同
```

**使用说明**：本指南需配合《扣子空间高级提示词工程指南》中的基础方法论使用。每个阶段完成后，建议用"反向提示词"进行校验（如"列出本章违反的3条世界观规则"），确保创作逻辑自洽。创作过程中，可将关键设定保存为独立文档，便于后续提示词引用。
