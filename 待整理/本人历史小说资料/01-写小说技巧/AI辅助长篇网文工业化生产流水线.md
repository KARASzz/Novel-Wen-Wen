# AI辅助长篇网文工业化生产流水线

这不仅仅是写作教程，这是一套**工程学**与**文学**结合的解决方案。长篇网文的核心在于 **“稳定更新”** 与 **“逻辑自洽”** ，而AI最难克服的是 **“遗忘（Context Window限制）”** 与 **“平庸（逻辑回归）”** 。

本百科全书将分为三大部分：

1. **系统初始化（创作准备）** ：构建世界观数据库与人物卡片。
2. **核心渲染流程（创作实施）** ：从大纲到细纲，再到正文的迭代生成，以及如何解决AI“记性不好”的问题。
3. **后期合成与优化（创作总结）** ：润色、风格化与一致性校验。

---

# 第一部分：系统初始化（创作准备）

在写第一个字之前，你需要喂给AI足够的数据结构。不要让AI“凭空想象”，要让它“戴着镣铐跳舞”。

## 1.1 核心概念与卖点提炼（Idea Generation）

网文讲究“黄金三章”和“核心梗”。你需要通过AI快速通过排列组合找到爆点。

 **【策略】** ：使用“反差法”和“缝合怪法”来生成创意。

 **👉 提示词示例（直接复制）：**

```markdown
# Role: 资深网文主编

# Task:
请帮我构思一个具有“爆款潜质”的网络小说核心创意。

# Constraints:
1. 题材融合：请将 [题材A，如：赛博朋克] 与 [题材B，如：修仙] 进行融合。
2. 核心爽点：必须包含一个“金手指（Cheat System）”设定，且这个金手指必须有代价或限制。
3. 主角人设：主角必须具有“反差感”（例如：外表柔弱但杀伐果断，或身居高位却极其抠门）。
4. 输出格式：请提供5个不同的创意方案，每个方案包含：
   - 书名（震惊体/系统流风格）
   - 一句话简介（20字以内）
   - 核心冲突
   - 金手指机制
   - 预期读者群体

# User Input:
我想写一本关于“AI觉醒”和“古代权谋”结合的小说。
```

## 1.2 世界观数据库构建（World-Building Bible）

这是长篇小说不崩盘的基石。你需要让AI生成一份Markdown格式的设定集，并在后续写作中反复投喂。

 **【策略】** ：采用JSON或结构化文本，方便AI理解层级关系。

 **👉 提示词示例（直接复制）：**

```markdown
# Role: 世界观架构师

# Task:
基于我们确定的核心创意，构建一个详细的世界观设定集。

# Requirements:
请按照以下结构输出详细设定，不要写笼统的描述，要写具体的规则：

1. **力量体系（Power System）**：
   - 等级划分（Lvl 1 - Lvl 9），每个等级的具体表现力（如：Lvl 1能碎石，Lvl 9能碎星）。
   - 升级条件与代价。
   
2. **地理环境（Geography）**：
   - 核心地图板块及各板块的气候、特产。
   - 禁地/副本设定。

3. **势力分布（Factions）**：
   - 3个主要对立势力（名称、核心理念、标志性能力）。
   - 势力之间的仇恨链。

4. **经济与货币（Economy）**：
   - 货币名称及购买力锚定（例如：1个金币=普通家庭1月生活费）。

5. **特殊规则（Meta Rules）**：
   - 世界的底层逻辑（如：灵气复苏、数据化世界、克苏鲁降临）。

# Output Warning:
请使用结构清晰的Markdown列表格式，方便我后续复制作为“记忆文件”。
```

## 1.3 角色矩阵设计（Character Matrix）

不仅要设计主角，还要设计“关系网”。AI写群像戏很弱，必须预设好互动模式。

 **👉 提示词示例（直接复制）：**

```markdown
# Role: 角色设计专家 & 心理侧写师

# Task:
设计小说的主角团与核心反派。

# Format:
请为每个角色建立一张“人物卡（Character Card）”：

1. **姓名**：
2. **MBTI人格**：(如INTJ，用于控制AI生成的对话风格)
3. **核心欲望**：(他想要什么？这是驱动剧情的动力)
4. **恐惧/弱点**：(他怕什么？这是制造冲突的关键)
5. **外貌特征**：(包括一个标志性的动作或饰品，如“喜欢推眼镜”、“左手有烧伤”)
6. **说话风格**：(给出3句该角色的口头禅或典型台词)
7. **特殊能力**：
8. **与主角的关系**：(羁绊/仇恨/利用)

# Content:
请设计：
- 1名男主角（反套路，不要龙傲天）
- 1名核心女配角（非花瓶，有独立故事线）
- 1名宿敌（智商在线，理念冲突）
```

# 第二部分：核心渲染流程（创作实施）

这是最耗时的部分。我们将采用  **“大纲 -> 细纲 -> 场景 -> 正文”**  的瀑布流生成法。

## 2.1 动态大纲规划（Dynamic Plotting）

长篇小说需要分卷规划。不要试图一次性生成结局，而是按“卷”生成。

 **👉 提示词示例（直接复制）：**

```markdown
# Role: 剧情策划大师

# Context:
目前小说进展到第 [X] 卷，当前核心目标是 [例如：主角要通过宗门大比进入内门]。

# Task:
请为这一卷设计剧情结构，遵循“好莱坞三幕式”或“起承转合”结构。请规划大约20个章节的节点。

# Output Format:
- **第一幕（铺垫与触发）**：
  - 第1-5章：[简述核心事件，包含一个“激励事件”]
- **第二幕（冲突与试炼）**：
  - 第6-15章：[设置3个连续的波折/打脸情节，难度递增]
- **第三幕（高潮与结局）**：
  - 第16-20章：[大决战，伏笔揭晓，引出下一卷的钩子]

# Requirement:
每个节点必须包含明确的“爽点（High Point）”或“期待感（Hook）”。
```

## 2.2 章节细纲生成（Beat Sheet Generation）

**这是AI写作质量高低的关键。**  直接生成正文通常会流水账，必须先生成“分镜脚本”。

 **👉 提示词示例（直接复制）：**

```markdown
# Role: 导演 & 编剧

# Task:
为第 [X] 章《[章节名]》编写详细的分镜细纲（Beat Sheet）。

# Inputs:
- 本章目标：主角揭穿反派的阴谋，并获得宝物。
- 出场人物：主角A，反派B，路人C。

# Requirements:
请将本章拆分为4-5个场景（Scene），每个场景包含以下信息：
1. **场景地点/氛围**：(环境描写提示)
2. **角色动作/博弈**：(具体的物理动作，谁先出手，谁后退)
3. **关键对白要点**：(不要写全对话，只写对话的潜台词和目的)
4. **情绪曲线**：(从紧张到放松，或从压抑到爆发)
5. **感官细节**：(视觉、听觉、嗅觉的提示)

# Constraint:
这一步不要写正文！只写指导正文写作的指令。
```

## 2.3 正文生成与扩写（Drafting）

现在，利用上面的细纲，让AI一段一段地写。**切记：不要让AI一次写一整章（2000字），它会偷懒。每次只让它写一个场景（500-800字）。**

 **👉 提示词示例（场景描写 - 动作类）：**

```markdown
# Role: 动作指导 & 网文大神

# Task:
根据细纲中的【场景1】，撰写正文。

# Style Guidelines:
1. **短句为主**：战斗场景多用短句，营造紧迫感。
2. **动词精准**：禁止使用“狠狠地打”、“用力地踢”这种空洞描述。要用“侧身避过”、“肘击”、“寸劲爆发”等具体动作。
3. **侧面烘托**：通过旁观者的震惊、环境的破坏（如碎裂的地板、激荡的气流）来表现力量感。
4. **拒绝说教**：不要在战斗中插入大段心理分析。

# Input (Scene 1 Beat Sheet):
[粘贴刚才生成的场景1细纲]

# Action:
开始撰写，字数要求600-800字。
```

 **👉 提示词示例（场景描写 - 情感/对话类）：**

```markdown
# Role: 情感专栏作家 & 编剧

# Task:
根据细纲中的【场景2】，撰写一段文戏。

# Style Guidelines:
1. **潜台词（Subtext）**：角色说的话不能直白表达意图。比如想说“我喜欢你”，要说“今晚的月色很美”。
2. **神态与微动作**：在对话间隙插入动作描写（如：手指敲击桌面、眼神躲闪、深吸一口气），代替“他说”、“道”这种连接词。
3. **环境投射**：用环境描写（如：窗外的雨声、忽明忽暗的烛火）来隐喻角色的内心。

# Input (Scene 2 Beat Sheet):
[粘贴刚才生成的场景2细纲]

# Action:
开始撰写，字数要求500-800字。
```

## 2.4 上下文管理与记忆回溯（Context Management）

**核心痛点解决**：AI写到第10章忘了第1章的设定怎么办？  
**方法**：维护一个“滚动摘要（Rolling Summary）”。每写完一章，就让AI生成该章的浓缩摘要，并在写下一章时作为Context输入。

 **👉 提示词示例（生成摘要）：**

```markdown
# Role: 数据归档员

# Task:
请阅读刚刚生成的第 [X] 章正文，生成一份不超过200字的“剧情记忆点”。

# Requirements:
1. 记录关键道具的获取/消耗。
2. 记录角色关系的重大变化（如：A与B结盟）。
3. 记录留下的伏笔（未解决的悬念）。
4. 记录主角当前的身体状态（如：重伤、升级）。

# Output Format:
【第X章记忆文档】
- 状态：
- 物品：
- 剧情点：
```

 **👉 提示词示例（写作前的“催眠”）：**   
在开始写新章节前，先发送这个Prompt：

```markdown
# System Instruction:
你正在创作长篇小说《[书名]》。
以下是必须要遵守的【当前世界状态】：
1. 核心设定：[复制世界观数据库]
2. 人物现状：[复制人物卡]
3. 前情提要：[复制最近3章的滚动摘要]

请基于以上信息继续创作，确保逻辑连贯，不要出现设定冲突。
```

# 第三部分：后期合成与优化（创作总结）

AI生成的初稿通常“AI味”很重（喜欢用“总而言之”、“不仅...而且”等连接词，缺乏画面感）。需要进行二次润色。

## 3.1 “去AI味”润色（Polishing）

 **👉 提示词示例（直接复制）：**

```markdown
# Role: 毒舌文学编辑

# Task:
请修改以下段落，使其更具“网文感”和“代入感”。

# Rules:
1. **删除废话**：删掉所有的过渡性总结句（如“一场大战一触即发”、“在这个风起云涌的时代”）。
2. **加强感官**：将形容词转化为名词或动词。例如将“他很愤怒”改为“他额头的青筋暴起，手中的茶杯化为齑粉”。
3. **句式变化**：打破长句，使用短促有力的短句组合。
4. **Show, Don't Tell**：直接描写画面，不要告诉读者感受。

# Original Text:
[粘贴AI写的初稿段落]
```

## 3.2 风格化重写（Stylization）

如果你想模仿特定的作家风格（如猫腻的文青、土豆的热血、乌贼的克苏鲁风）。

 **👉 提示词示例（直接复制）：**

```markdown
# Role: 风格模仿专家

# Target Style: 古龙风格（极简、装逼、哲理、短句）

# Task:
请用古龙的笔法重写下面这段打斗描写。

# Key Features to Mimic:
1. 大量使用回车，一句一行。
2. 强调氛围和杀气，而不是具体的招式拆解。
3. 使用排比句。
4. 充满宿命感和孤独感的独白。

# Original Text:
[粘贴一段普通的打斗描写]
```

## 3.3 逻辑与一致性审查（Audit）

定期检查是否吃书（设定冲突）。

 **👉 提示词示例（直接复制）：**

```markdown
# Role: 逻辑侦探

# Task:
请检查以下新写的章节内容，对比之前的【设定数据库】。

# Database:
[粘贴设定集]

# New Content:
[粘贴新章节]

# Audit List:
1. 主角的能力是否超出了当前等级限制？
2. 反派的行为是否符合其性格逻辑？
3. 是否出现了之前未提及但突然出现的设定（机械降神）？

如果发现问题，请指出并提供修改建议。
```

# 附录：给架构师的“作弊码” (Tips)

1. **迭代提示（Iterative Prompting）** ：如果AI写得不好，不要直接重写，而是说：“保留第一段的氛围，但第二段的对话太生硬，请让反派表现得更阴险一点，重新生成。”
2. **温度设置（Temperature）** ：
   - 写**创意/大纲**时，设置 `Temperature = 0.8 ~ 1.0`（增加创造性）。
   - 写**正文/逻辑**时，设置 `Temperature = 0.5 ~ 0.7`（增加稳定性）。
3. **建立“词汇库”** ：创建一个包含你小说特有术语（如：灵压、查克拉、义体植入）的列表，每次生成前强调：“在描写时，优先使用以下专有名词：[...]”。

这一套流程，将AI从“帮我写个故事”的玩具，变成了“帮我生产每个零件”的机床。你需要做的，是做那个拥有最终剪辑权的**总导演**。
