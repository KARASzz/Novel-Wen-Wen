## 1. 创作前期准备

### 1.1 小说类型选择（2025 年番茄热门品类）

根据番茄小说 2025 年最新数据，以下品类最具潜力：

#### **都市题材（占平台流量 47%）**

- **核心组合**：重生逆袭 + 职业文
- **爆款案例**：《破产后，我在直播间捡垃圾成首富》（环保 + 直播 + 商战）
- **成功公式**：现实痛点（职场 / 婚恋 / 负债）+ 超现实金手指（系统 / 重生 / 空间）

#### **年代文（搜索量上涨 182%）**

- **热门方向**：80 年代创业文
- **爆款案例**：《带着全家穿越 1983》（美食 + 科技降维打击）
- **创作要素**：物资匮乏年代 + 现代知识碾压 + 家族群像

#### **脑洞奇幻（新兴蓝海）**

- **代表题材**：规则类怪谈
- **爆款案例**：《我在殡仪馆上夜班的 100 条禁忌》
- **成功要素**：细思极恐的日常场景 + 逻辑严密的生存守则

#### **其他热门品类**

- **末世科幻**：冰河末世、天灾求生、囤物资题材
- **言情甜宠**：豪门恩怨、追妻火葬场、系统返利
- **高概念脑洞**：全民游戏、超级工厂、黑科技流

### 1.2 核心卖点设计

#### **金手指设置原则**

1. **实用性强**：能直接解决主角当前困境
2. **成长性好**：有明确的升级路径
3. **独特性高**：避免同质化的系统设定

#### **常见金手指类型**

- **系统类**：签到系统、选择系统、职业系统
- **空间类**：储物空间、种植空间、时间加速空间
- **能力类**：读心术、预测未来、过目不忘
- **身份类**：重生、穿越、马甲大佬

#### **爽点设计公式**

- **打脸爽点**：前期受辱 → 获得能力 → 强势反击
- **逆袭爽点**：底层起步 → 快速成长 → 超越对手
- **情感爽点**：情感挫折 → 自我提升 → 真爱降临

### 1.3 世界观构建方法

#### **基础设定框架**

```
【世界观设定表】

1\. 时代背景：现代/古代/未来/架空

2\. 社会结构：阶级制度/政治体系/经济模式

3\. 地理环境：主要城市/地形特征/特殊地点

4\. 规则体系：超自然规则/社会规则/职业规则

5\. 科技水平：现代科技/修真体系/魔法世界
```

#### **设定细化技巧**

1. **分层植入**：避免开篇大段设定说明
2. **逐步揭示**：通过剧情发展自然展现世界观
3. **视觉化呈现**：用具体场景和物品体现设定

### 1.4 人物设定模板

#### **主角设定表**

```
【主角设定模板】

姓名：

外貌：（3个突出特征）

#### **配角设定原则**

1. **功能性配角**：推动剧情发展
2. **情感性配角**：提供情感支持

4. **成长性配角**：有独立的人物弧光

## 2. AI 工具选型与配置

### 2.1 推荐工具对比分析

#### **笔灵 AI（专业小说创作工具）**

**优势**：

- 专为小说创作优化，过审率 92%
- 200 + 小说写作功能
- 丰富的素材库和模板
- 一键生成大纲和章节内容

**劣势**：

- 部分高级功能需要付费
- 对复杂设定的理解有限

**适用场景**：

- 大纲生成和情节设计
- 人物设定和世界观构建
- 开头结尾创作

**操作步骤**：

1. 选择小说类型和题材
2. 输入核心设定和人物信息
3. 生成大纲和章节内容
4. 人工修改和润色

#### **蛙蛙写作（全链路 AI 创作平台）**

**优势**：

- 多 AI 模型一站式调用
- Agent 功能支持全流程创作
- 网文场景深度适配
- 支持小说转漫剧功能

**劣势**：

- 学习成本相对较高
- 需要良好的提示词技巧

**适用场景**：

- 长篇小说创作
- 多平台内容分发
- 多媒体 IP 开发

**操作步骤**：

1. 配置创作 Agent
2. 生成故事创意和大纲
3. 分章节创作内容
4. 质量检测和优化

#### **DeepSeek（长文生成专家）**

**优势**：

- 128K 上下文窗口
- 逻辑连贯性强
- 支持复杂情节设计
- 创作自由度高

**劣势**：

- 需要详细的提示词
- 网文风格适配一般

**适用场景**：

- 长篇小说续写
- 复杂情节设计
- 世界观构建

**操作步骤**：

1. 提供详细的故事设定
2. 制定分阶段创作计划
3. 生成章节内容
4. 调整和优化

#### **Kimi（中文续写专家）**

**优势**：

- 中文理解能力强
- 对话生成自然
- 支持长文档处理
- 免费版本功能丰富

**劣势**：

- 小说创作功能相对基础
- 生成速度一般

**适用场景**：

- 对话创作和人物互动
- 章节续写和内容扩充
- 语言润色和优化

#### **番茄 AI（平台内置工具）**

**优势**：

- 完全适配番茄平台风格
- 免费使用基础功能
- 与平台发布无缝对接
- 实时数据反馈

**劣势**：

- 功能相对简单
- 创作自由度有限

**适用场景**：

- 标题和简介生成
- 内容扩写和改写
- 卡文时的灵感获取

### 2.2 工具组合策略

#### **新手推荐组合**

```
【新手工具链】

构思阶段：笔灵AI（大纲生成）

写作阶段：蛙蛙写作（章节创作）

润色阶段：Kimi（语言优化）

发布阶段：番茄AI（平台适配）
```

#### **进阶使用策略**

1. **多模型协作**：不同工具负责不同环节
2. **交叉验证**：用多个工具生成内容进行对比
3. **个性化训练**：根据创作风格调整参数

### 2.3 基础配置设置

#### **通用参数设置**

```
【AI创作参数配置】

温度：0.7-0.9（保持创意性和连贯性平衡）

长度：根据章节需求设置

风格：选择符合题材的写作风格

角色一致性：开启（确保人物性格统一）

情节连贯性：开启（保持剧情逻辑）
```

#### **平台风格适配**

- **番茄风格**：节奏快、冲突强、爽点密集
- **知乎风格**：逻辑性强、观点独特、文笔优美
- **起点风格**：设定严谨、情节复杂、世界观宏大

## 3. 创作流程搭建

### 3.1 分阶段大纲生成法

#### **总纲生成模板**

```
【总纲生成提示词】

我要写一部\[类型]小说，总字数100万字。

核心设定：\[金手指/世界观/核心冲突]

主要人物：\[主角设定+关键配角]

故事主线：\[起承转合四部分]

请生成详细的小说总纲，包括：

1\. 故事梗概（500字）

2\. 主要人物介绍（每人200字）

3\. 分卷大纲（5-8卷）

4\. 核心冲突设计

5\. 结局走向
```

#### **卷纲设计方法**

```
【卷纲结构模板】

第X卷：\[卷名]

字数：XX万字

主题：本卷核心主题

主要事件：3-5个关键情节

人物成长：主角和重要配角的变化

卷末高潮：本卷的最高潮情节

悬念设置：为下一卷埋下的伏笔
```

#### **章纲写作技巧**

```
【章纲要素】

1\. 章节标题：吸引眼球的标题

2\. 核心事件：推动剧情的关键情节

3\. 人物互动：主要人物的对话和行动

4\. 场景描写：重要场景的环境刻画

5\. 情感变化：人物的心理活动

6\. 悬念设置：章节结尾的钩子
```

### 3.2 AI 章节创作技巧

#### **高效提示词模板**

```
【章节创作提示词】

当前章节：第X章

章节标题：

上章回顾：\[简要概括上章内容]

本章目标：\[推动剧情/展现设定/人物互动]

核心情节：\[主要事件和冲突]

人物状态：\[角色心情和动机]

场景设定：\[时间地点和环境]

写作风格：\[语言风格和节奏要求]

字数要求：2000-2500字

请按照番茄小说风格创作本章内容，要求：

1\. 开头有吸引力，快速进入剧情

2\. 中间有冲突和转折

3\. 结尾有悬念和钩子

4\. 语言流畅，符合网文风格
```

#### **避免同质化方法**

1. **个性化输入**：提供独特的设定和人物
2. **多角度生成**：用不同提示词生成多个版本
3. **人工融合**：综合多个 AI 版本的优点
4. **风格调整**：调整语言风格和叙事角度

#### **内容扩充技巧**

```
【内容扩充公式】

基础情节 + 细节描写 + 心理活动 + 对话互动 = 丰富内容

具体方法：

1\. 环境描写：用感官细节营造氛围

2\. 动作描写：分解动作，增加细节

3\. 心理描写：展现内心想法和情感

4\. 对话扩充：增加个性化对话
```

### 3.3 人工把控要点

#### **内容审核清单**

```
【章节质量检查】

✓ 情节逻辑：是否符合世界观设定

✓ 人物性格：是否保持角色一致性

✓ 节奏把控：是否张弛有度

✓ 爽点设置：是否有足够的爽点

✓ 悬念设置：结尾是否有吸引力

✓ 语言质量：是否流畅自然

✓ 字数达标：是否达到目标字数
```

#### **修改润色技巧**

1. **结构调整**：优化章节结构和节奏
2. **语言润色**：提升文字表现力
3. **情节优化**：增强冲突和转折
4. **人物深化**：丰富人物性格和动机

#### **一致性维护**

1. **设定一致性**：保持前后设定统一
2. **人物一致性**：维持人物性格稳定
3. **情节一致性**：确保剧情逻辑连贯
4. **风格一致性**：保持语言风格统一

## 3. 创作流程搭建

### 3.1 分阶段大纲生成法

#### **总纲生成步骤**

1. **确定核心概念**：一句话概括整个故事
2. **设计四大节点**：起承转合的关键情节
3. **规划故事弧线**：主角的成长轨迹
4. **分卷布局**：将故事分为 5-8 卷

#### **卷纲细化方法**

```
【卷纲创作模板】

卷名：

核心主题：

主要目标：

关键冲突：

重要场景：

人物发展：

卷末高潮：

下卷伏笔：
```

#### **章纲制定技巧**

1. **单章目标明确**：每章都要有明确的功能
2. **情节密度控制**：每章 2-3 个关键事件
3. **节奏变化设计**：快慢结合，张弛有度
4. **钩子设置**：每章结尾留有悬念

### 3.2 AI 辅助章节创作

#### **提示词工程技巧**

```
【高级提示词结构】

1\. 角色设定：详细的人物信息和性格特点

2\. 场景描述：具体的时间地点和环境氛围

3\. 情节要求：本章需要完成的剧情任务

4\. 风格指导：语言风格和叙事角度

5\. 字数控制：明确的字数要求

6\. 质量标准：对内容质量的具体要求
```

#### **多轮生成策略**

1. **第一轮**：生成完整章节内容
2. **第二轮**：优化语言表达和节奏
3. **第三轮**：增加细节描写和心理活动
4. **第四轮**：调整对话和互动

#### **个性化调整方法**

1. **风格调整**：根据读者反馈调整写作风格
2. **情节调整**：根据数据表现优化情节设计
3. **人物调整**：强化受欢迎的角色特点

### 3.3 人工质量把控

#### **内容质量评估标准**

```
【质量评估维度】

1\. 可读性：语言流畅度和阅读体验

2\. 逻辑性：情节发展的合理性

3\. 吸引力：读者的阅读兴趣

4\. 独特性：内容的原创性和特色

5\. 一致性：设定和人物的统一性
```

#### **修改优化流程**

1. **整体审查**：检查章节的整体效果
2. **细节修改**：优化具体的文字表达
3. **结构调整**：改善章节的结构布局
4. **质量验证**：确保修改后的质量提升

## 4. 番茄平台适配策略

### 4.1 黄金三章优化技巧

#### **第一章：3 秒抓眼球**

**核心目标**：在前 3 句话内抓住读者注意力

**爆款开头模板**：

```
【危机式开头】

"\[极端危险场景]，\[主角身份]突然意识到\[可怕真相]！"

【金手指落地】

"重生回到\[关键时间点]，\[主角]脑中响起\[系统声音]：'\[金手指功能]'"

【悬念式开头】

"我正在参加自己的葬礼，却看到\[反常现象]..."
```

**数据优化要点**：

- 第一章出现明确金手指或生死危机
- 避免开篇大段设定说明
- 前 300 字必须有强冲突

#### **第二章：强化冲突**

**核心目标**：让读者产生 "替主角着急" 的代入感

**情节设计公式**：

```
短期目标 + 强力阻碍 + 时间限制 = 高张力冲突

具体要求：

1\. 目标可视化：具体、可衡量的目标

2\. 阻碍具体化：明确的反派或困难

3\. 时间紧迫感：设定明确的时间限制
```

#### **第三章：爽点反馈**

**核心目标**：让读者尝到第一个甜头

**爽点设计类型**：

1. **打脸爽点**：反击嘲讽自己的人
2. **能力爽点**：首次使用金手指获得成功
3. **情感爽点**：获得他人认可或情感支持
4. **解决爽点**：成功解决眼前的危机

### 4.2 平台节奏适配

#### **番茄风格特点**

```
【番茄平台风格指南】

节奏：快速紧凑，3章完成打脸，5章换地图

冲突：每章都有冲突，避免平淡剧情

爽点：每章至少1个小爽点，每卷3-5个大爽点

钩子：每章结尾留有悬念，吸引追读

语言：简洁直白，避免复杂句式

情感：情绪极化，突出喜怒哀乐
```

#### **章节结构模板**

```
【番茄章节结构】

开头（20%）：快速进入剧情，展现当前状态

发展（60%）：推进情节，制造冲突和转折

结尾（20%）：设置悬念，留下钩子

字数分配：

\- 2000-2500字/章

\- 对话占30-40%

\- 描写占20-30%

\- 叙述占30-40%
```

### 4.3 标题和简介优化

#### **爆款标题公式**

```
【标题创作模板】

类型1：金手指+效果

《\[金手指]，\[具体效果]》

类型2：身份+反差

《\[普通身份]，其实是\[隐藏身份]》

类型3：危机+解决方案

《\[危机场景]，我靠\[方法]逆袭》

类型4：数字+悬念

《我在\[地点]的\[数字]个\[事件]》
```

#### **简介写作技巧**

```
【简介结构模板】

第一段：主角困境和金手指获得

第二段：主要冲突和发展方向

第三段：最终目标和悬念设置

关键要素：

\- 突出金手指特点

\- 展现核心冲突

\- 设置悬念吸引

\- 符合平台风格
```

### 4.4 标签和分类策略

#### **精准标签选择**

```
【标签组合策略】

主标签：\[主要类型]+\[核心金手指]

次标签：\[情节特点]+\[人物关系]

辅标签：\[热门元素]+\[个人特色]

示例：

主标签：都市重生 + 签到系统

次标签：打脸爽文 + 美女总裁

辅标签：商业帝国 + 校园生活
```

#### **分类选择技巧**

1. **选择流量大的分类**：都市、玄幻、言情
2. **结合细分题材**：重生、系统、年代文
3. **考虑平台扶持**：关注平台推荐的题材

## 5. 百万字创作规划

### 5.1 阶段性目标拆解

#### **创作进度规划表**

```
【百万字创作计划表】
