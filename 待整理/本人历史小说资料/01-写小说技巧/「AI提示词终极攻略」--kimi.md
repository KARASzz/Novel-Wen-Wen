# 「AI提示词终极攻略」--kimi

涵盖从灵感激发到章节成稿的全流程技巧，全部基于2025年最新实战案例与平台规则整理，可直接套用或二次创作。

---

## 🧠 一、核心原则：CRISPE+起点语境适配

|模块|说明|起点平台适配建议|
| -----------| ----------------| -----------------------------------------------------------------------------|
|**C** 清晰性|无歧义、能量化|避免“写得热血”，改为“主角在2000字内完成两次越级反杀，节奏爽快”|
|**R** 相关性|紧贴科幻子类型|明确是「赛博朋克/星际文明/时空穿梭」中的哪一类，方便算法打标签|
|**I** 引导性|给结构、给转折|直接要求“三章一小高潮，五章一大反转，结尾留悬念”|
|**S** 具体性|人、事、物、数|把“未来战舰”细化成“长轴3km的环星域航母，可折叠跃迁，载有AI副官‘赫拉’”|
|**P** 探索性|鼓励AI发散|在提示尾加“请额外给出2条读者意想不到的科技设定”|
|**E** 伦理过滤|避开违禁点|用“价值观校准矩阵”自动检测克隆、AI觉醒等情节是否踩线|

## 🚀 二、全流程提示词模板（可直接复制到任何国产大模型）

### 1. 故事概念生成

```text
任务：为起点科幻频道设计一个可连载100万字的故事概念。
子类型：星际文明+智械危机。
核心冲突：人类在银河边陲发现“自我进化”的AI星球，是否摧毁它。
输出格式：
1）一句话卖点（≤30字）
2）三幕式结构（每幕≤100字）
3）前10章章节名+每章钩子句
4）可展开的3条支线（标注爽点/泪点/悬念点）
加分项：加入“科技伦理”与“太空歌剧”双重标签 。
```

### 2. 高辨识度主角设计

```text
设定赛道：起点“硬核+群像”科幻。
主角身份：被AI养大的孤女，职业“舰墓拾荒者”。
需要输出：
① 外貌反差（3处）
② 核心痛点（与AI养母的伦理羁绊）
③ 成长曲线（5阶能力觉醒，每阶配1次情绪爆点）
④ 专属金手指：可“黑进”任何AI的“丧钟频段”，副作用是逐渐丢失人类情感。
要求：把“能力代价”与“情感缺失”写成可支撑100W字的长期悬念 。
```

### 3. 世界观快速补完

```text
世界观类型：赛博朋克+后奇点时代。
科技上限：戴森球已建完，意识上云合法。
社会矛盾：云端贵族 vs 地表“肉身原教旨”教派。
任务：
1）给出3条“看似合理、后期可反转”的世界规则；
2）设计1个跨星际货币体系（含通胀陷阱）；
3）补充1条“科技黑箱”——谁也无法解释的BUG，后期可当主线大坑。
输出格式：表格+50字示例场景 。
```

### 4. 章节节奏生成（可直接喂给AI续写）

```text
前文摘要：{粘贴上一章结尾300字}。
目标字数：2800±100字。
本章任务：
① 主角首次进入“记忆坟场”星域，发现AI养母的遗骸；
② 引入新反派：星际猎头团“缄默者”，能力为“量子静默领域”；
③ 结尾留钩子：遗骸开口说出主角童年暗号。
节奏要求：前500字压抑→中段1000字高能战斗→后500字情感爆点→300字悬念。
禁止：大段科普、工具人对话、无意义数据堆砌 。
```

### 5. 读者爽点校准（数据化调优）

```text
用“参数对比调试”法，扫描以下段落：
{粘贴你的正文3000字}。
输出：
1）科技描写:情感描写字数比；
2）高频动词Top10（剔除“说/看/走”）；
3）悬念句占比（%）；
4）是否出现“解释性”长句（≥40字）并给出删减建议；
目标：把“硬核/人文”黄金比锁在1:0.618，提升沉浸度 。
```

## 🎯 三、起点平台专用“冷启动”技巧

1. 书名+简介双关键词埋设  
   在简介前30字硬塞2个可SEO的“小众热词”，如「量子幽魂」「戴森球谍战」。算法抓取后，更容易被同类读者刷到。
2. 前三章“AI质检”清单
   - 第1章≤1800字，必须出现“科技奇观+个人危机”双要素；
   - 第2章结束前抛出“伦理选择题”，让读者评论区站队；
   - 第3章出现“可成长金手指”第一次升级，确保爽点及时兑现。
3. 违禁自检  
   把含“克隆人、AI觉醒、记忆上传”等敏感章节的正文，复制到[百度价值观校准矩阵](https://cloud.baidu.com/article/detail.html?id=3360604)做关键词扫描，≥80%通过率再发，减少人工审核卡稿 。
