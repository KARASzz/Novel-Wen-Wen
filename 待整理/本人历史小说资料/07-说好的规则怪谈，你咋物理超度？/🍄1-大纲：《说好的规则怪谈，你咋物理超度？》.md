## 二、世界观骨架

### 2.1 力量体系

**天选者位阶（本土体系）：**

```
①启示者 → ②解读者 → ③执典者 → ④铭刻者 → ⑤御律者 → ⑥主宰者 → ⑦超越者
```

**诡异序列（由低到高）：**

```
第七序列·蜉蝣 → 第六序列·夜行 → 第五序列·噬影 → 第四序列·厄临 → 第三序列·灾祸 → 第二序列·禁忌 → 第一序列·深渊 → 第零序列·不可名状
```

**主角（高武穿越者）：**

```
身份：肉身成圣的满级大佬，穿越时灵魂剥离，功法神通全失，只剩不灭肉身
真实战力：约等于第一序列·深渊（受压制状态）
系统检测：普通人（BUG级扮猪吃虎）
```

### 2.2 核心规则

1. **规则绝对性**：怪谈副本中，红字规则=绝对契约，违反者遭受"契约反噬"（心脏停跳/空间碾压/灵魂剥离）
2. **直播降临**：全球随机抽取天选者进入副本，全程直播。失败者所属国家将降临对应等级的怪谈灾难
3. **主角的BUG**：契约反噬本质是能量惩罚，主角肉身强度超出惩罚上限——相当于拿牙签捅钢板，规则自己崩溃

## 四、金手指设计

```
类型：【满级肉身】+【被动光环】

核心能力：
1. 万法不侵：任何基于"规则"的即死攻击，打在他身上只会"有点痒"
2. 物理超度：能抓实灵体，鬼魂在他手里有实感，可以被过肩摔

限制条件：
- 功法神通全失，只能用纯粹物理力量
- 唯一"软肋"：路痴+阅读理解能力为0，经常看不懂规则，被迫暴力通关

成长路线：
主角战力始终碾压当前副本，不存在"变强"的过程。
真正的成长线是【认知升级】：
- 前期：这世界的鬼真弱
- 中期：原来有更强的？打就是了
- 后期：发现万诡之主要入侵故乡 → 主动出击终结威胁

以及【世界认知】的成长：
- 全人类对主角的认知：炮灰 → 怪物 → 人类守护神
- 诡异对主角的恐惧：无视 → 警惕 → 闻风丧胆 → 集体PTSD
```
