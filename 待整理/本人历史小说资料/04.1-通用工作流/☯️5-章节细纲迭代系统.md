# ☯️5-章节细纲迭代系统 v1.0

## 核心理念

```
每25章为一个迭代周期
写作中发现的问题 → 反馈到下一轮细纲生成
防止剧情崩塌 + 保持爽点密度 + 角色弧光连贯
```

---

## 一、迭代触发时机

|触发点|动作|
| --------------------| ------------------------------------------|
|完成第25章正文|启动下一轮细纲生成前，先执行**迭代复盘**|
|写作中发现重大矛盾|立即记录，暂不修改细纲，集中在迭代期处理|
|分卷结束|强制执行**分卷级复盘**（比常规迭代更深入）|

---

## 二、迭代复盘表（每25章必填）

### 【迭代复盘表】第X-X+24章 → 第X+25-X+49章

```markdown
## 1️⃣ 状态快照（从正文中提取，非计划值）

| 项目 | 计划值（细纲） | 实际值（正文） | 偏差原因 |
|------|---------------|---------------|----------|
| 主角境界 | | | |
| 当前位置 | | | |
| 核心矛盾解决进度 | | | |
| 女主关系进展 | | | |
| 金手指解锁进度 | | | |

## 2️⃣ 问题清单

### 剧情层面
- [ ] 未闭合的伏笔：[列举]
- [ ] 意外展开的新线：[列举]
- [ ] 与分卷大纲的偏差：[列举]

### 角色层面
- [ ] 行为逻辑矛盾：[角色+具体问题]
- [ ] 戏份失衡：[谁太多/谁消失了]
- [ ] 人设漂移：[谁的性格写偏了]

### 节奏层面
- [ ] 爽点密度不足的章节：[章节号]
- [ ] 拖沓/注水的章节：[章节号]
- [ ] 悬念断裂的位置：[章节号]

## 3️⃣ 修正指令（输入下一轮细纲生成）

### 必须继承
- 状态继承：[从第X+24章结尾状态开始]
- 未闭合伏笔：[必须在下25章内回收的]
- 角色在场：[当前随行人员名单]

### 必须调整
- 分卷大纲偏差修正：[如何拉回主线]
- 角色戏份补偿：[谁需要加戏]
- 节奏优化：[下轮重点强化什么类型爽点]

### 新增元素
- 写作中产生的好点子：[临时灵感记录]
- 读者反馈热点：[如果已连载，记录评论区反应]
```

## 三、迭代输入模板

完成复盘表后，使用此模板启动下一轮细纲生成：

```markdown
# 章节细纲生成指令

Start_X = [起始章节号]

## 【迭代输入】

### 状态继承（从上轮正文提取）
- 主角当前境界：[实际值]
- 当前位置：[实际值]
- 随行人员：[名单]
- 未解决悬念：[列举3个]
- 金手指状态：[已解锁功能+冷却状态]

### 偏差修正
- 需拉回主线的点：[具体描述]
- 需补偿戏份的角色：[谁+补什么]
- 需回收的伏笔：[列举+目标章节]

### 节奏调整
- 上轮薄弱点：[类型]，本轮强化
- 上轮过剩点：[类型]，本轮减少
- 特别强调：[本轮必须达成的3个大爽点]

### 新增素材
- 临时灵感：[好点子记录]
- 设定集更新：[如有新增]

---
请执行阶段一至阶段六，生成第[X]-[X+24]章细纲。
```

## 四、分卷级复盘（每卷结束时）

比常规迭代更深入，增加以下检查：

```markdown
## 【分卷复盘】第X卷

### 核心弧光检验
- [ ] 本卷主角成长弧光是否完整？（起点→转折→终点）
- [ ] 本卷BOSS是否有足够铺垫+震撼结局？
- [ ] 本卷女主线是否有实质推进？

### 长线伏笔管理
| 伏笔 | 埋设章节 | 计划回收 | 当前状态 |
|------|----------|----------|----------|
| | | | 已回收/进行中/需调整 |

### 下卷衔接
- 本卷结尾钩子：[是什么]
- 下卷开篇必须承接：[列举]
- 势力格局变化：[需同步到设定集]

### 设定集更新清单
- [ ] 新增角色录入
- [ ] 势力关系更新
- [ ] 地图解锁
- [ ] 金手指新功能
```

## 六、快速迭代检查表（每日使用）

写正文时随手记录，不打断写作流：

```markdown
## 今日写作记录（第X章）

### 偏差记录
- [ ] 与细纲有重大偏离：[描述]
- [ ] 临时新增角色/设定：[记录]
- [ ] 遗留问题：[需后续处理]

### 灵感记录
- 好句子/好场景：[摘录]
- 可复用的桥段设计：[描述]
- 读者可能的爽点：[预判]
```

| ----------| ------------| ---------------------------|
