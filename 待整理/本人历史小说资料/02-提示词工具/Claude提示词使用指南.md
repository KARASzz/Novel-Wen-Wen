# Claude提示词使用指南

## 有效撰写提示词的通用技巧

### 1. 表述清晰、内容具体

- 在消息开头明确说明你的任务或问题。
- 提供上下文和细节，帮助Claude理解你的需求。
- 将复杂任务拆解为多个简单易执行的小步骤。

**欠佳的提示词示例**：  
<prompt>  
"帮我做一份演示文稿。"  
</prompt>

**优质的提示词示例**：  
<prompt>  
"我需要为公司季度销售会议制作一份10页的演示文稿，内容需涵盖第二季度销售业绩、热销产品以及第三季度销售目标。请为每一页幻灯片拟定大纲并标注核心要点。"  
</prompt>

**优质原因**：这份提示词包含了任务的具体细节，包括幻灯片页数、演示文稿的用途以及需要涵盖的核心主题。

### 2. 搭配示例说明

- 提供你期望得到的输出成果示例。
- 若需要特定的格式或风格，向Claude展示参考案例。

**欠佳的提示词示例**：  
<prompt>  
"写一封专业的邮件。"  
</prompt>

**优质的提示词示例**：  
<prompt>  
"我需要给客户写一封说明项目延期的专业邮件，以下是我之前写过的类似邮件模板：

尊敬的[客户名称]：  
展信佳。特此向您同步[项目名称]的最新进展，很遗憾项目遇到了突发问题，交付日期将顺延约两周。我们正全力解决问题，后续会及时向您同步推进情况。  
若您有任何疑问或顾虑，欢迎随时联系我。  
顺颂商祺！  
[你的姓名]

请参照这个邮件的语气和结构，为本次因供应链问题导致项目延期一个月的情况撰写新邮件。"  
</prompt>

**优质原因**：这份提示词提供了具体的风格和语气参考案例，让Claude撰写新邮件时有明确的依据。

### 3. 引导分步思考

- 面对复杂任务，要求Claude“分步思考”或“说明推理过程”。
- 这种方式能让Claude给出更准确、更详尽的回答。

**欠佳的提示词示例**：  
<prompt>  
"如何提升团队工作效率？"  
</prompt>

**优质的提示词示例**：  
<prompt>  
"我希望提升团队的工作效率，请结合以下几点分步分析思考：

1. 目前影响效率的问题（如会议过多、工作优先级不明确）
2. 可行的解决方案（如时间管理方法、项目管理工具）
3. 方案落地过程中可能遇到的问题
4. 效率提升效果的衡量方法

请为每个分析步骤简要说明推理依据，最后对所有想法进行总结。"  
</prompt>

**优质原因**：这份提示词引导Claude系统性地分析问题，为回答设定了清晰的框架，还要求说明推理过程，同时让Claude在最后进行总结，便于阅读理解。

### 4. 逐步优化完善

- 若Claude的初次回答不符合预期，提出具体的澄清或修改要求。
- 你可以直接说明“回答方向大致正确，但能否将X调整为更贴近Y的表述”。

**欠佳的提示词示例**：  
<prompt>  
"改得更好一点。"  
</prompt>

**优质的提示词示例**：  
<prompt>  
"回答的整体方向不错，请再做进一步优化，具体调整要求如下：

1. 语气更轻松亲切
2. 增加一个产品为客户解决问题的具体案例
3. 精简第二段内容，重点突出产品优势而非功能特点"  
   </prompt>

**优质原因**：这份提示词给出了具体的反馈和明确的优化要求，让Claude能针对性调整，而非让Claude主观判断“更好”的标准——毕竟Claude的理解往往和用户的需求存在偏差。

### 5. 充分利用Claude的知识库

- Claude拥有多领域的丰富知识，可大胆询问专业解释或背景信息。
- 务必提供相关的上下文和细节，让Claude的回答更贴合你的需求。

**欠佳的提示词示例**：  
<prompt>  
"什么是营销？该怎么做营销？"  
</prompt>

**优质的提示词示例**：  
<prompt>  
"我正在为全新的环保清洁产品线制定营销策略，能否为我介绍当下绿色营销的主流趋势？请包含以下内容：

1. 能打动环保意识较强的消费者的核心传播策略
2. 触达该类受众的有效渠道
3. 过去一年中成功的绿色营销案例
4. 需要规避的潜在问题（如被指责“漂绿”营销）

这些信息将用于指导我们制定营销方案。"  
</prompt>

**优质原因**：这份提示词结合具体场景，提出了针对性的问题，充分发挥Claude的知识库优势，同时说明信息的使用场景，让Claude能给出更贴合实际的回答。

### 6. 运用角色扮演模式

- 要求Claude以特定的角色或视角进行回答。

**欠佳的提示词示例**：  
<prompt>  
"帮我准备一场谈判。"  
</prompt>

**优质的提示词示例**：  
<prompt>  
"请你扮演我司背包生产业务的面料供应商，我正准备和该供应商谈判，希望将面料价格降低10%。请以供应商的身份提供以下内容：

1. 针对降价要求的三个潜在反对理由
2. 针对每个反对理由，给出我方可以反驳的观点
3. 供应商可能提出的两个替代直降方案

之后切换至我方视角，为我提供谈判技巧，帮助我达成降价目标。"  
</prompt>

**优质原因**：这份提示词通过角色扮演，从多个视角分析谈判场景，让谈判准备更全面。同时角色扮演能让Claude更好地贴合特定视角的表达逻辑，让回答更专业、更贴合实际。

## 不同任务的专属提示词技巧及示例

### 内容创作

1. **明确目标受众**

   - 告知Claude内容的阅读对象。

   **欠佳的提示词示例**：  
   <prompt>  
   "写一篇关于网络安全的内容。"  
   </prompt>

   **优质的提示词示例**：  
   <prompt>  
   "我需要为中小企业主撰写一篇关于网络安全最佳实践的博客，读者的技术基础较弱，因此内容需满足以下要求：

   1. 通俗易懂，尽量避免专业术语
   2. 实用性强，包含可快速落地的技巧
   3. 风格生动有趣，适当加入幽默元素，提升可读性

   请为这篇1000字左右的博客拟定大纲，涵盖中小企业主需掌握的5个核心网络安全做法。"  
   </prompt>

   **优质原因**：这份提示词明确了目标受众、内容语气和核心特点，为Claude创作合适、有效的内容提供了清晰指引。

2. **定义语气和风格**

   - 描述期望的内容语气。
   - 若有品牌风格指南，提炼核心要点告知Claude。

   **欠佳的提示词示例**：  
   <prompt>  
   "写一则产品介绍。"  
   </prompt>

   **优质的提示词示例**：  
   <prompt>  
   "请帮我为新款人体工学办公椅撰写产品介绍，语气专业且生动，贴合品牌亲切、创新、关注健康的品牌调性。介绍内容需包含：

   1. 突出椅子的核心人体工学设计
   2. 说明这些设计对用户健康和工作效率的益处
   3. 简要提及产品使用的环保材料
   4. 结尾加入引导语，鼓励读者体验产品

   字数控制在200字左右。"  
   </prompt>

   **优质原因**：这份提示词明确了产品介绍的语气、风格，以及需要包含的具体内容要素。

3. **确定输出结构**

   - 提供内容的基本大纲或需要涵盖的核心要点。

   **欠佳的提示词示例**：  
   <prompt>  
   "制作一份公司业绩的演示文稿。"  
   </prompt>

   **优质的提示词示例**：  
   <prompt>  
   "我需要制作一份第二季度公司业绩的演示文稿，按以下板块划分内容：

   1. 业绩总览
   2. 销售表现
   3. 客户获取情况
   4. 遇到的挑战
   5. 第三季度展望

   参考常规的商务演示文稿，为每个板块拟定3-4个核心要点，同时为每个板块推荐一种适合的数据可视化形式（如图表、图形）。"  
   </prompt>

   **优质原因**：这份提示词为内容设定了清晰的结构，还要求为每个板块提供具体的核心要点和数据可视化建议。

### 文档总结与问答

1. **明确需求细节**
   - 要求Claude总结文档的特定方面或章节。
   - 清晰、直接地提出问题。
   - 明确说明需要的总结形式（如输出结构、内容类型）。
2. **标注文档名称**
   - 提及附件文档的具体名称。
3. **要求标注引用来源**
   - 让Claude在回答中标注文档的具体引用位置。

以下是结合以上三个技巧的示例：

**欠佳的提示词示例**：  
<prompt>  
"帮我总结这份报告。"  
</prompt>

**优质的提示词示例**：  
<prompt>  
"我已附上一份50页的市场研究报告《2023年科技行业发展趋势》，请先针对人工智能和机器学习领域的趋势撰写两段总结内容，再回答以下问题：

1. 今年商业领域的三大人工智能应用方向是什么？
2. 机器学习对科技行业的岗位设置有哪些影响？
3. 报告中提及的人工智能落地应用存在哪些潜在风险和挑战？

回答问题时，请标注具体的引用章节或页码。"  
</prompt>

**优质原因**：这份提示词明确了总结的核心方向，提出了具体问题，还要求标注引用来源，能让回答更贴合需求、更具参考性；同时也确定了总结的输出形式，如限定为两段内容。

### 数据分析与可视化

1. **明确输出格式**

   - 清晰描述你期望的数据呈现形式。

   **欠佳的提示词示例**：  
   <prompt>  
   "分析我们的销售数据。"  
   </prompt>

   **优质的提示词示例**：  
   <prompt>  
   "我已附上名为《2023年销售数据》的电子表格，请对数据进行分析，并按以下格式呈现核心结论：

   1. 执行摘要（2-3句话）
   2. 核心指标：
      - 各季度总销售额
      - 表现最佳的产品品类
      - 增长最快的区域市场
   3. 发展趋势：
      - 列出3个显著趋势，并分别简要说明
   4. 建议方案：
      - 基于数据给出3条建议，并分别简要说明理由

   分析完成后，推荐三种能直观呈现这些结论的数据可视化形式。"  
   </prompt>

   **优质原因**：这份提示词为数据分析结果设定了清晰的呈现结构，明确了需要重点分析的核心指标，还要求给出建议和可视化形式，让分析结果更具实用性。

### 头脑风暴

1. 让Claude通过列举可能性或替代方案的方式生成创意，**明确要求Claude覆盖的思考方向**。

   **欠佳的提示词示例**：  
   <prompt>  
   "给我一些团队建设的想法。"  
   </prompt>

   **优质的提示词示例**：  
   <prompt>  
   "我们需要为20人的远程团队设计团队建设活动，请从以下方面协助头脑风暴：

   1. 推荐10个能促进协作的线上团队建设活动
   2. 为每个活动简要说明其培养团队协作能力的原理
   3. 标注各活动分别适合用于：  
      a) 团队破冰  
      b) 提升沟通能力  
      c) 锻炼解决问题能力
   4. 分别推荐一个低成本和一个高端版的活动方案。"  
      </prompt>

   **优质原因**：这份提示词为头脑风暴设定了具体的要求，包括创意数量、活动类型和额外的分类要求，能让输出结果更有条理、更具实用性。

2. 要求Claude以特定格式输出，如项目符号、编号列表、表格等，便于阅读。

   **欠佳的提示词示例**：  
   <prompt>  
   "对比几款项目管理软件。"  
   </prompt>

   **优质的提示词示例**：  
   <prompt>  
   "我们正在考虑三款项目管理软件：Asana、Trello和Microsoft Project，请按以下维度以表格形式进行对比：

   1. 核心功能
   2. 操作便捷性
   3. 可扩展性
   4. 定价（尽可能包含具体套餐）
   5. 集成能力
   6. 适用场景（如小型团队、大型企业、特定行业）"  
      </prompt>

   **优质原因**：这份提示词要求以表格形式呈现对比结果，并明确了对比维度，让信息更易理解、更易落地使用。

## 问题排查、减少幻觉输出、提升回答质量的技巧

1. **允许Claude表示不确定**
   - 告知Claude若遇到未知问题，可直接说明。例如：“若你对某个问题不确定，无需勉强回答，直接说明‘不知道’即可。”
2. **拆解复杂任务**
   - 若任务难度过高，导致Claude遗漏步骤或执行效果不佳，可将其拆解为小步骤，通过多条消息和Claude逐步完成。
3. **新请求包含完整上下文**
   - Claude不会保留过往对话的信息，因此在每一次新的对话请求中，都需包含所有必要的上下文。

## 综合型提示词优劣对比示例

以下示例结合了多种提示词撰写技巧，直观展示低效与高效提示词的差异。

### 示例1：制定营销策略

**欠佳的提示词**：  
<prompt>  
"帮我制定一份营销策略。"  
</prompt>

**优质的提示词**：  
<prompt>  
"请以资深营销顾问的身份，帮我为全新的环保智能手机配件产品线制定一份全面的营销策略，目标受众为具备环保意识的千禧一代和Z世代消费者。请提供详细的策略方案，包含以下板块：

1. 市场分析：
   - 环保数码配件领域的当前趋势
   - 2-3个核心竞争对手及其营销策略
   - 潜在市场规模和增长预测
2. 目标受众画像：
   - 理想客户的详细特征
   - 他们的痛点及产品的解决思路
3. 营销组合策略：
   - 产品：需要突出的核心功能
   - 定价：建议的定价策略及理由
   - 渠道：推荐的销售渠道
   - 推广：  
     a) 5个重点发力的营销渠道，并分别说明优劣  
     b) 3个产品上线的创意营销活动方案
4. 内容策略：
   - 5个能触达目标受众的内容主题
   - 推荐的内容形式（如博客、视频、信息图）
5. 关键绩效指标与效果衡量：
   - 5个需要跟踪的核心指标
   - 推荐的指标统计工具

请以带标题和项目符号的结构化形式呈现内容，相关部分请说明推理依据或提供简要示例。

在策略大纲后，请指出方案落地过程中可能遇到的挑战和风险，并为每个问题提供应对策略。"  
</prompt>

**优质原因**：这份提示词融合了角色设定、任务拆解、结构化输出、头脑风暴、要求说明推理依据等多种技巧，在给出清晰创作指引的同时，也为Claude的分析和创意发挥留出了空间。

### 示例2：分析财务报告

**欠佳的提示词**：  
<prompt>  
"分析这份财务报告。"  
</prompt>

**优质的提示词**：  
<prompt>  
"我已附上公司《2023年第二季度财务报告.pdf》，请以资深首席财务官的身份分析这份报告，并为董事会准备一份汇报材料，按以下结构呈现分析内容：

1. 执行摘要（3-4句话，提炼核心要点）
2. 财务表现总览：  
   a) 营收：对比上一季度及去年同期数据  
   b) 利润率：毛利率和净利率，并说明显著变化的原因  
   c) 现金流：指出潜在问题或积极变化
3. 核心绩效指标：
   - 列出5个核心指标及当前完成情况（以表格形式呈现）
   - 为每个指标简要说明其重要性及近期趋势
4. 业务板块分析：
   - 拆解三大核心业务板块的业绩表现
   - 找出表现最佳和最差的板块，并分析原因
5. 资产负债表复盘：
   - 指出资产、负债、所有者权益的显著变化
   - 计算并解读核心财务比率（如流动比率、资产负债率）
6. 未来发展预判：
   - 基于现有数据，对第三季度业绩做出3个核心预测
   - 提出2-3个能改善公司财务状况的战略举措
7. 风险评估：
   - 从报告中提炼3个潜在的财务风险
   - 为每个风险提供应对策略
8. 同行对比：
   - 将公司业绩与2-3个核心竞争对手对比（使用公开数据）
   - 指出公司的优势领域和待改进领域

请在合适的位置使用图表或表格可视化数据，所有的假设和解读都请明确说明并给出推理依据。

分析完成后，请列出5个董事会成员可能提出的问题，并附上建议回答。

最后，将整份分析内容浓缩为一个段落，作为我在董事会会议上的开场发言。"  
</prompt>

**优质原因**：这份提示词融合了角色扮演、结构化输出、具体数据分析要求、预测分析、风险评估、同行对比，甚至提前预判了后续问题，在给出清晰分析框架的同时，引导Claude进行深度分析和战略思考。
