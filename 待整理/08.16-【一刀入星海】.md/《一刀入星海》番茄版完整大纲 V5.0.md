```
古代猎人陈山穿越到2247年，

他只有一把刀，和三十年猎虎豹熊狼的经验。

第一个铁血，死在陷阱里。
第二个铁血，死在追踪中。

但陈山不知道，每杀一个铁血，他都在失去作为"人"的东西。
```

## 【第二步】金手指设计

### 2.1 金手指四要素

|要素|内容|
| ------| ----------------------------------------------------------------------------|
|**获取方式**|穿越时带了一把刀，刀上有八个缺口，每个缺口都是一次生死搏杀的记忆|
|**核心能力**|"认知盲区猎杀"——能看穿对手依赖的认知系统（科技/文化/本能），利用盲区击杀|
|**升级路径**|每猎杀一个铁血，解锁一层认知：陷阱→追踪→规则→心理→文化→哲学|
|**代价机制**|每杀一个铁血，失去一部分人性（第1个：享受猎杀；第5个：差点忘记儿子）|

### 2.2 能力边界

**能做什么：**

- 看穿铁血依赖热成像的盲区（用泥浆隔绝）
- 看穿铁血"尊重强者"的文化盲区（用规则羞辱）
- 看穿铁血战术配合的漏洞（让他们内讧）

**不能做什么：**

- 不能正面硬刚（战力差距太大）
- 不能破解所有科技（只能利用使用者的依赖性）
- 不能无限使用（每次猎杀都在失去人性）

**代价可视化：**

```
第1个铁血：开始享受猎杀的快感
第2个铁血：对尸体失去敬意
第3个铁血：用铁血逻辑思考问题
第4个铁血：差点对儿子说"你太弱了"
第5个铁血：必须选择——杀死断牙=失去最后的人性
```

## 【第四步】世界观核心设定

### 4.1 时空背景（200字）

```
2247年，铁血族母舰降临地球。
他们不是侵略者，是"猎手"——按照"荣耀准则"猎杀强者。

地球被划为"狩猎保护区"，人类是"合法猎物"。
铁血族每年派出狩猎队，猎杀人类强者，收集头骨作为战利品。

但有个秘密：铁血族正在用"培养舱"改造人类幼崽，
培养成"完美猎物"，以维持狩猎文化的传承。

陈山的儿子，就是被选中的"种子"之一。
```

### 4.2 科技体系

|科技类型|能力上限|限制|代价|
| ----------| --------------| -----------------------| -----------------------|
|热成像|透视生物体温|无法识别冷血/泥浆覆盖|过度依赖=失去原始感知|
|隐形装置|光学隐形|无法隐藏声音/气味|能量耗尽会暴露|
|等离子炮|远程秒杀|需要充能3秒|过热会炸膛|
|培养舱|改造生物基因|只能改造幼体（<18岁）|被改造者失去原生记忆|

**核心规则：科技越强=依赖性越强=盲区越大**

### 4.3 势力版图

|势力名|核心利益|和主角关系|代表人物|
| ------------| ------------------------| ------------| ------------------|
|断牙狩猎队|猎杀地球强者，收集头骨|敌对→尊重|断牙（队长）|
|铁血母舰|维持狩猎文化传承|敌对|审判者（舰长）|
|人类幸存者|活下去|盟友|飞行员老李|
|铁血改革派|废除"猎杀弱者"准则|后期盟友|新生（断牙之子）|
|铁血保守派|维护传统狩猎文化|终极敌人|永恒（族长）|

### 4.4 核心词条

```
-荣耀准则：铁血族的狩猎规则，包括"尊重强者""光明正大""不杀弱者"
- 培养舱：改造人类幼崽的装置，47小时后完成基因改写
- 认知盲区：依赖某种系统（科技/文化）导致的感知死角
- 骨哨：陈山给儿子做的虎骨哨子，上面刻着"平安"
- 断牙：铁血队长的代号，因为在一次狩猎中被猎物打断獠牙
```

## 【第五步】人物骨架

### 5.1 主角：陈山

```
【初始处境】
- 身份：古代猎人，猎了三十年虎豹熊狼
- 困境：穿越到未来，儿子被抓，自己被五个铁血包围
- 阶级落差：从山林猎手到星际猎杀游戏的"猎物"

【金手指】
- 类型：认知盲区猎杀
- 核心能力：看穿对手依赖的系统，利用盲区击杀
- 代价：每杀一个铁血，失去一部分人性

【动机链】
- 短期（1-25章）：救出儿子
- 中期（26-200章）：保护儿子和幸存者，击退母舰
- 终极（201-500章）：改写铁血文化，让他们不再猎杀无辜

【性格弧线】
- 起点：谨慎的猎人，只想保护儿子
- 中点撕裂（第139章）：杀死断牙后，差点忘记儿子的脸
- 终点蜕变（第500章）：选择不杀永恒，而是用"传承"改写铁血文化
```

### 5.2 反派：断牙（第一季核心反派）

```
【动机】
他认为狩猎是宇宙最高的艺术，
只有不断猎杀强者，才能证明自己的存在价值。

【能力】
铁血族最强猎手之一，猎遍星际，从未失手。

【弱点】
过度骄傲，认为科技是"作弊"，
最终选择扔掉所有装备，只用骨刀和陈山决斗。

【和主角的冲突】
他猎杀了陈山的儿子（未遂），
但在追逐过程中，逐渐认可陈山是"真正的猎手"。

【结局】
第139章，他在决斗中输给陈山，
临死前把刀插在地上，刀尖朝向陈山（投降礼），
说："你赢了，但别忘了，你也是猎手。"
```

### 5.3 核心配角

**儿子·陈山娃（16岁）**

- 功能1：推动主角动机（救子）
- 功能2：制造内线冲突（第150章被救出后，已被部分改造，对父亲说"你杀了太多人"）
- 功能3：承担传承主题（第500章，儿子继承父亲的刀，成为新一代猎手）

- 功能1：第300章登场，代表铁血改革派
