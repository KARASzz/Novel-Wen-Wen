## 第一部分：番茄平台认知

### 1.1 番茄 vs 起点核心差异

|维度|起点|番茄|你要做什么|
| ------| ---------------------| --------------------| ------------------------|
|**读者群**|25-35岁，付费意愿强|18-30岁，下沉市场|文字更白话，爽点更直接|
|**付费模式**|订阅制|免费+广告|每章必须有钩子留人|
|**章节长度**|3000-4000字|2500-3000字|一章只写一个主爆点|
|**爽点密度**|每3-5章一个|每2-3章一个|不能有纯铺垫章|
|**推荐机制**|编辑推荐|算法推荐|前三章留存率决定生死|
|**热门赛道**|玄幻修仙|诸天流（2025爆发）|必须带"诸天"标签|
|**标题**|可以文艺|必须带爽点关键词|"第X章 猎杀虫族女王"|
|**对话**|可以文雅|必须白话|每句话≤10字|
|**更新**|可以断更|断更=死亡|必须日更|

### 1.2 番茄2026年热门赛道

```
【TOP5赛道】
1. 诸天流（平台力推，算法倾斜）
2. 战神流（退伍兵王回归都市）
3. 鉴宝流（捡漏发家致富）
4. 系统流（仍然是主流）
5. 重生复仇（都市打脸）

【诸天流为什么火】
- 每个世界都是新鲜感（读者不疲劳）
- 可以蹭知名IP热度（降低认知成本）
- 改编潜力大（单元剧模式）
- 平台正在力推（算法倾斜明显）
```

### 1.3 番茄算法逻辑

```
【推荐三要素】
1. 前三章留存率（>75%才有推荐）
2. 章节完读率（>70%才继续推）
3. 日更稳定性（断更=推荐归零）

【算法喜欢】
- 标题带"诸天"关键词
- 开头500字有冲突
- 章末有强钩子
- 每2-3章有爆点
- 日更不断

【算法讨厌】
- 标题太文艺
- 开头写环境
- 章末没钩子
- 连续铺垫章
- 断更
```

## 第二部分：诸天流500章特性

### 2.1 诸天流 vs 单世界差异

|维度|单世界500章|诸天流500章|关键差异|
| ------| -------------| ------------------| ------------|
|**场景**|容易单调|每125章换世界|永远新鲜|
|**敌人**|容易重复|每世界换敌人类型|永远有挑战|
|**爽点**|容易疲劳|每世界换爽点类型|永远有期待|
|**改编**|单一故事|单元剧模式|改编容易|
|**延展性**|500章到头|可以无限写|续集潜力|
|**版权**|可能侵权|可以原创或蹭多IP|风险分散|

### 2.2 四世界结构设计

```
【第一世界】星猎族世界（1-125章）
- 主线：救出儿子→猎杀五个星猎战士
- 场景：原始丛林→星猎营地→培养舱飞船
- 敌人：星猎族（原创，规避铁血版权）
- 战利品：星猎面具（热成像）
- 人性流失：失去"敬畏"（开始享受猎杀）

【第二世界】虫族世界（126-250章）
- 主线：保护幸存者→猎杀虫族女王
- 场景：荒凉星球→人类基地→虫族巢穴
- 敌人：虫族（工虫/兵虫/脑虫/女王）
- 战利品：虫族基因（力量×10）
- 人性流失：失去"同情"（对弱者冷漠）

【第三世界】机甲废土（251-375章）
- 主线：保护地下城→猎杀机械泰坦
- 场景：废土地表→地下城→机甲工厂
- 敌人：失控机甲（侦察/战斗/指挥/泰坦）
- 战利品：AI芯片（战术计算）
- 人性流失：失去"恐惧"（变得疯狂）

【第四世界】神族战场（376-500章）
- 主线：联合文明→猎杀神族至高→最终选择
- 场景：高维战场→神族母舰→神族圣殿
- 敌人：神族（先锋/审判者/至高）
- 战利品：拒绝选择（保留人性）
- 人性流失：差点失去"自我"→最终找回

每世界125章 + 独立主线 + 独立高潮 + 独立完结感
```

```

【推荐】
- 《诸天猎手：我用陷阱猎杀万界强者》（直接）

【不推荐】
- 《一刀入星海》（没有"诸天"关键词）

- 《星际狩猎》（没特色）
```

### 3.2 标签选择

```
【主标签】（必选2个）
诸天 + 系统流

【爽点标签】（必选2个）
扮猪吃虎 + 智斗

【钩子标签】（选1个）
硬核 / 复仇
```

### 3.3 简介（番茄版·300字）

```
古代猎人陈山穿越到2247年，发现儿子被星际战士囚禁。

他激活了"猎手空间"——只要猎杀每个世界的最强者，就能进入下一个世界。

第一世界，他用陷阱猎杀星际战士。
第二世界，他用星际装备猎杀虫族女王。
第三世界，他用虫族基因猎杀机械泰坦。

当他站在多元宇宙之巅，所有强者才明白——
真正的猎手，从不依赖科技，只依赖智慧。

但他不知道，每猎杀一个世界，他都在失去作为"人"的东西。
当儿子哭着说"你不是我爸爸"时，他才发现——
自己已经变成了比猎物更可怕的怪物。

最终，他必须选择：继续猎杀成为诸天主宰，还是停下保留最后的人性？

【关键】
- 前50字必须有冲突
- 中间展示四个世界
- 结尾留悬念+代价
```

## 第四部分：猎手空间金手指设计

### 4.1 金手指四要素

```
【获取方式】
穿越时，陈山的刀（有八个缺口）吸收虎血，激活"猎手空间"

【核心能力】
1. 世界穿梭：猎杀当前世界最强者后，解锁下一世界
2. 战利品保留：每个世界可以带走一件核心战利品
3. 实力叠加：每个世界的能力/装备可以累积
4. 认知盲区猎杀：核心能力，在所有世界通用

【升级路径】（500章版）
第1-125章：陷阱猎杀（原始技术）
第126-250章：装备猎杀（星猎面具+陷阱）
第251-375章：基因猎杀（虫族基因+装备+陷阱）
第376-500章：全能猎杀（AI芯片+基因+装备+陷阱）

【代价机制】（可视化）
每个世界失去一部分人性：
- 第一世界：失去"敬畏"（开始享受猎杀）
- 第二世界：失去"同情"（对弱者冷漠）
- 第三世界：失去"恐惧"（变得疯狂）
- 第四世界：差点失去"自我"（最终选择找回）
```

### 4.2 猎手空间界面（可视化）

```
【空间外观】
虚空大厅，中央插着陈山的刀，刀身有八个发光缺口

【当前状态】（第1章）
缺口1：【星猎族世界】- 进行中
缺口2：【？？？】- 未解锁
缺口3：【？？？】- 未解锁
缺口4：【？？？】- 未解锁
缺口5-8：【？？？】- 未解锁（续集预留）

【任务显示】
当前世界：星猎族世界
主线任务：猎杀五个星猎战士
奖励：解锁缺口2，选择一件战利品
失败惩罚：永远困在当前世界
```

### 4.3 战利品系统

|世界|战利品选项|陈山选择|效果|下世界用途|
| -------| ----------------------------| ----------| ---------------------| ------------|
|世界1|星猎面具/隐形装置/等离子刀|星猎面具|热成像+生命探测|追踪虫族|
|世界2|虫族基因/脑虫神经索/酸液腺|虫族基因|力量×10，感官×100|徒手撕机甲|
|世界3|泰坦核心/AI芯片/纳米装甲|AI芯片|战术计算，预判能力|对抗神族|
|世界4|神族权杖/高维视角/时间回溯|拒绝选择|保留人性|带儿子回家|

**战利品规则：**

- 每个世界只能带走一件
- 战利品会根据下一世界自动适配
- 不能带走"人"（儿子自动跟随）
- 战利品可以叠加使用

### 4.4 认知盲区猎杀核心方法论

```
【什么是认知盲区】
依赖某种系统（科技/文化/本能）导致的感知死角

【四个世界的认知盲区】
世界1（星猎族）：
- 依赖热成像 → 用泥浆隔绝
- 依赖"荣耀法典" → 用规则羞辱

世界2（虫族）：
- 依赖群体意识 → 切断脑虫
- 依赖数量优势 → 引诱自相残杀

世界3（机甲）：
- 依赖AI计算 → 用不可预测的原始战术
- 依赖能量供应 → 切断能源

世界4（神族）：
- 依赖高维视角 → 用低维的"直觉"
- 依赖规则 → 打破规则

【陈山的优势】
他不依赖任何系统，只依赖经验和直觉
所以他没有盲区，或者说盲区最小
```

## 第五部分：章节写作技巧

### 5.1 番茄章节结构（2500-3000字）

```
【开头】（300字）
- 第一句：动作/对话/冲突
- 前300字：钩子+冲突+悬念

【中段】（1000字）
- 推进剧情
- 爆点必须在1000字前出现
- 每500字一个小冲突

【结尾】（200字）
- 章末钩子（悬念/危机/反转）
- 让读者想看下一章
```

### 5.2 开头公式

```
【第一句铁律】
必须是：动作/对话/冲突

✅ 好开头：
"刀刃插进老虎的脖子。"
"猎手空间开启。"
"五个星猎战士包围了陈山。"

❌烂开头：
"月光洒在丛林里。"（环境）
"陈山想起了往事。"（回忆）
"这是2247年。"（背景）
```

### 5.3 爽点设计（诸天版）

```
【爽点类型】（每章选一个）
- 打脸爽：轻蔑→出手→震惊（300字）
- 反杀爽：绝境→翻盘→碾压（500字）
- 装逼爽：低调→被迫出手→震撼（400字）
- 获得爽：战斗→胜利→获得战利品（200字）
- 身份爽：隐藏→暴露→震惊（300字）
- 认知爽：盲区→利用→击杀（500字）
- 世界切换爽：完成任务→开启新世界（新增，300字）

【爽点位置】
必须在1000字前出现

【爽点禁区】
❌ 铺垫超过500字
❌ 爽点太弱（说狠话不算）
❌ 连续重复（三章都打脸）
❌ 不可视化（"变强了"看不见）
```

### 5.4 章末钩子（诸天版）

```
【钩子类型】
- 悬念钩：抛出新问题
- 危机钩：更强敌人出现
- 反转钩：推翻前面认知
- 装逼钩：主角说狠话
- 代价钩：人性流失警告
- 世界钩：下一世界预告（新增）

【钩子公式】
最后50字 + 强情绪 + 让人想点下一章

✅ 好钩子：
"但陈山不知道，真正的危机才刚开始。"
"猎手空间开启：下一世界，虫族母巢。"
"儿子看着父亲，眼里全是恐惧。"

❌ 烂钩子：
"陈山回家了。"（太平淡）
"明天继续战斗。"（没悬念）
```

### 5.5 对话技巧

```
【对话铁律】
1. 每句话≤10字
2. 禁止"的地得"连用
3. 禁止文言文
4. 多用短句

【对比】
❌ 起点式：
"阁下实力不凡，在下佩服。"（11字）

✅ 番茄式：
"你很强。"（3字）
"谁教的？"（4字）

【冲突对话】
A嘲讽（1句）→ B冷笑（1句）→ A愤怒（1句）→ B出手
```

### 5.6 战斗场景

```
【战斗节奏】
铺垫（50字）→ 交锋（300字）→ 终结（100字）
总计≤500字

【战斗描写】
只写结果，不写过程

❌ 烂写法：
"陈山抬起右手，握紧刀柄，用力向前刺去..."

✅ 好写法：
"陈山出刀。
星猎倒下。
其他四个星猎懵了。"
```

### 5.7 标题公式（诸天版）

```
第X章 +爽点关键词 + 情绪词

【关键词库】
战斗类：猎杀/反杀/秒杀/碾压/团灭
情绪类：震惊/懵了/傻眼/跪了/慌了
身份类：暴露/曝光/真相/原来/竟然
装逼类：打脸/装逼/嘲讽/后悔/求饶
悬念类：发现/秘密/阴谋/危机/绝境
代价类：失控/黑化/迷失/选择
世界类：传送/开启/降临/新世界（新增）

【示例】
✅ 第3章：猎杀星猎战士！
✅ 第125章：猎手空间开启！下一世界
✅ 第250章：虫族基因异变！儿子恐惧
✅ 第500章：最终选择！回归地球

❌ 第1章：山中有虎（太文艺）
```

## 第六部分：四世界管理策略

### 6.1 世界规划铁律

```
每个世界必须有：
1. 独立主线（能单独讲一个完整故事）
2. 独立高潮（世界末必有S级爆点）
3. 独立完结感（给读者阶段性满足）
4. 下世界钩子（最后5章埋钩子）
5. 125章均衡分配
```

### 6.2 世界切换技巧

```
【世界末最后5章】
倒数第5章：本世界最终爆点
倒数第4章：情感沉淀
倒数第3章：战利品选择
倒数第2章：下世界预告
倒数第1章：传送开启

【新世界前5章】
第1章：新世界展开（环境+危机）
第2章：主角适应（用上世界战利品）
第3章：发现新敌人
第4章：制定新计划
第5章：第一次小胜（给信心）
```

### 6.3 每个世界核心变化

```
【世界1→世界2】
场景：丛林 → 荒凉星球
敌人：星猎族 → 虫族
战力：原始陷阱 → 陷阱+星猎面具
格局：救子 → 保护幸存者
代价：享受猎杀 → 对弱者冷漠

【世界2→世界3】
场景：星球 → 废土
敌人：虫族 → 机甲
战力：面具+陷阱 → 基因+面具+陷阱
格局：保护 → 反抗
代价：冷漠 → 疯狂

【世界3→世界4】
场景：废土 → 高维战场
敌人：机甲 → 神族
战力：基因+面具+陷阱 → AI+基因+面具+陷阱
格局：反抗 → 改写
代价：疯狂 → 差点失去自我→找回
```

## 第七部分：爆点管理系统（280个）

### 7.1 爆点分级

```
【S级爆点】（每世界1个，共4个）
- 猎杀核心反派
- 世界观重大揭露
- 主角质变升级
- 用于世界末高潮
```

## 第十二部分：避坑指南（诸天流专项）

### 12.1 番茄致命错误

```
❌ 错误1：前三章没爆点
后果：算法不推荐，书直接死
解决：前三章每章必须有爆点

❌ 错误2：章节超过3000字
后果：读者看不完，完读率低
解决：严格控制2500-3000字

❌ 错误3：开头写环境描写
后果：读者直接跑
解决：第一句必须是冲突

❌ 错误4：对话超过10字
后果：读者看不懂
解决：每句话≤10字

❌ 错误5：断更
后果：算法直接不推
解决：必须日更，保持存稿

❌ 错误6：标题不带"诸天"
后果：错失热门赛道流量
解决：书名必须带"诸天"关键词

❌ 错误7：世界切换太突兀（新增）
后果：读者不适应，掉读严重
解决：最后5章铺垫，前5章适应

❌ 错误8：战利品无限叠加（新增）
后果：主角太无敌，三章就腻
解决：每个战利品有使用限制
```

### 12.2 诸天流特有的坑

```
❌ 坑1：世界变成流水账
症状：每个世界都是"到达→战斗→离开"
原因：没有独立主题和情感高潮
解决：每个世界必须有独立的情感线

❌ 坑2：战利品过于万能
症状：主角拿到战利品后无敌
原因：没有设置使用限制
解决：每个战利品有明确的能力边界

❌ 坑3：儿子成工具人
症状：儿子只是跟着走，没有存在感
原因：没有给儿子独立的成长线
解决：每个世界儿子都要有成长和冲突

❌ 坑4：人性流失不可视化
症状：读者感受不到主角的变化
原因：只在心理描写里提，没有具体行为
解决：每25章必须有一次可视化的人性流失表现

❌ 坑5：四个世界重复
症状：读者说"又是这套路"
原因：每个世界的敌人类型/战斗方式/场景太相似
解决：每个世界必须有明显差异化

❌ 坑6：最终选择铺垫不足
症状：第500章的选择很突兀
原因：前面没有铺垫
解决：从第1章开始埋伏笔，每个世界强化一次

❌ 坑7：新世界认知成本高
症状：读者看不懂新世界的设定
原因：一次性投放太多信息
解决：新世界前5章只投放核心设定，其他边写边补

❌ 坑8：世界切换节奏乱
症状：有的世界100章，有的150章
原因：没有提前规划
解决：严格按125章×4的结构
```

### 12.3 防疲劳策略

```
【读者疲劳】
症状识别：
- 完读率连续下降
- 评论区抱怨"水"
- 留存率低于60%

应对方案：
1. 立刻插入一个B级爆点
2. 提前引爆一个伏笔
3. 让配角发光（换个视角）
4. 写一场酣畅淋漓的战斗
5. 如果在世界末期，提前切换世界

【作者疲劳】
症状识别：
- 写不出来
- 写得很痛苦
- 质量明显下降

应对方案：
1. 每周休息一天
2. 每世界结束休息3天
3. 卡文时跳过，写下一个爽点
4. 实在不行，写一章战斗
5. 或者提前切换世界（给自己新鲜感）
```

```
- 传送光芒笼罩

- 章末：到达新世界

- 环境描写（≤100字）

```

## 第十五部分：战利品叠加管理（新增）

### 15.1 战利品叠加规则

```
【叠加原则】
1. 每个战利品可以和其他战利品组合使用
2. 但每个战利品有使用限制（能量/次数/冷却）
3. 不能无限叠加导致无敌

【示例】
世界2（拥有：星猎面具）
- 用面具追踪虫族
- 但面具能量有限，每天只能用3小时
- 能量耗尽需要充能

世界3（拥有：星猎面具+虫族基因）
- 用面具定位敌人
- 用虫族基因强化的力量徒手撕机甲
- 但基因强化有副作用（皮肤异变）

世界4（拥有：星猎面具+虫族基因+AI芯片）
- 用面具定位
- 用基因强化战斗
- 用AI芯片计算战术
- 但AI芯片会压制情感
```

### 15.2 战利品使用限制

|战利品|能力|限制|副作用|
| ----------| ---------------------| ----------------------| --------------------|
|星猎面具|热成像+生命探测|能量限制，每天3小时|长期使用视力下降|
|虫族基因|力量×10，感官×100|消耗体力，战斗后虚弱|皮肤异变，失去人性|
|AI芯片|战术计算，预判能力|需要大脑供能，会头痛|压制情感，失去自我|

### 15.3 战利品组合使用示例

```
【场景】世界3，对抗机械泰坦

第1步：用星猎面具定位泰坦弱点（能源核心）
第2步：用虫族基因强化，徒手撕开外壳
第3步：用陷阱（原始技术）引诱泰坦进入
第4步：组合爆发，一击必杀

【画面描写】
陈山戴上星猎面具，热成像启动。
泰坦的能源核心在胸口，闪着红光。

他激活虫族基因，皮肤上绿色纹路蔓延。
力量暴涨。

"吼——"

陈山冲向泰坦，双手撕开外壳。
火花四溅。

泰坦反击，巨拳砸下。

陈山早就设好陷阱——
泰坦踩中陷阱，失去平衡。

陈山抓住机会，一拳轰进能源核心。

"轰！"

泰坦爆炸。

陈山站在废墟中，喘着粗气。
皮肤上的绿色纹路更深了。

儿子看着父亲，不敢靠近。
```
