## 第一部分：番茄平台认知

### 1.1 番茄 vs 起点核心差异

|维度|起点|番茄|你要做什么|
| ------| ---------------------| -------------------| ------------------------|
|**读者群**|25-35岁，付费意愿强|18-30岁，下沉市场|文字更白话，爽点更直接|
|**付费模式**|订阅制|免费+广告|每章必须有钩子留人|
|**章节长度**|3000-4000字|2500-3000字|一章只写一个爽点|
|**爽点密度**|每3-5章一个|每2-3章一个|不能有纯铺垫章|
|**推荐机制**|编辑推荐|算法推荐|前三章留存率决定生死|
|**标题**|可以文艺|必须带爽点关键词|"第X章 猎杀铁血战士"|
|**对话**|可以文雅|必须白话|每句话≤15字|
|**更新**|可以断更|断更=死亡|必须日更|

### 1.2 番茄读者画像

```
【核心特征】
- 年龄：18-30岁
- 阅读时间：碎片化（通勤、午休、睡前）
-阅读习惯：快速翻页，不喜欢长段落
- 付费意愿：低（看免费+广告）
- 耐心：极低（3章不爽就跑）

【他们要什么】
- 直接的爽感（不要绕弯子）
- 快速的节奏（不要慢热）
- 简单的文字（不要文言文）
- 强烈的画面感（能脑补成短视频）
- 每章都有期待（章末钩子）

【他们不要什么】
- 复杂的世界观
- 文艺的描写
- 慢热的开局
- 纯铺垫的章节
- 虐主的剧情
```

### 1.3 番茄算法逻辑

```
【推荐三要素】
1. 前三章留存率（>75%才有推荐）
2. 章节完读率（>70%才继续推）
3. 日更稳定性（断更=推荐归零）

【算法喜欢】
- 标题带爽点关键词
- 开头500字有冲突
- 章末有强钩子
- 每章有爆点
- 日更不断

【算法讨厌】
- 标题太文艺
- 开头写环境
- 章末没钩子
- 连续铺垫章
- 断更
```

## 第二部分：500章长篇特性

### 2.1 500章 vs 120章差异

|维度|120章短篇|500章长篇|关键差异|
| ------| ------------| -------------| ------------------|
|**连载周期**|60天|250天|从冲刺变马拉松|
|**爆点密度**|每章必须有|每2-3章一个|可以适当降低|
|**节奏**|一路高潮|波浪式|高潮→缓冲→高潮|
|**场景**|单一场景|必须轮换|每100章换场景|
|**敌人**|固定敌人|必须升级|每100章换敌人|
|**配角**|固定配角|必须轮换|每50章换配角|
|**读者疲劳**|不用管|必须管理|建立防疲劳机制|
|**作者疲劳**|不用管|必须管理|每季休息一周|

### 2.2 四季结构设计

```
【第一季】个人复仇（1-200章）
- 主线：猎杀五个铁血
- 场景：原始丛林
- 敌人：五人猎队
- 结局：救出儿子

【第二季】保护家园（201-300章）
- 主线：对抗铁血母舰
- 场景：地球+母舰
- 敌人：精英小队
- 结局：击退母舰

【第三季】星际格局（301-400章）
- 主线：组建反铁血联盟
- 场景：星际空间
- 敌人：铁血各族
- 结局：联盟成立

【第四季】文明改写（401-500章）
- 主线：反攻铁血母星
- 场景：铁血母星
- 敌人：保守派
- 结局：改写文化

每季独立主线 + 独立高潮 + 独立完结感
```

## 第三部分：商业化包装

### 3.1 书名公式（番茄版）

```
公式：核心元素 + 爽点暗示

【推荐】
- 《一刀猎杀星际战士》（直接）
- 《古代猎人在星际》（身份对比）
- 《我用陷阱猎铁血》（方法暗示）

【不推荐】
- 《一刀入星海》（太文艺）
- 《猎手传说》（太抽象）
- 《星际狩猎》（没特色）
```

### 3.2 标签选择

```
【主标签】（必选1个）
科幻 / 星际战争 / 异族入侵

【爽点标签】（必选2个）
爽文 + 反杀 /扮猪吃虎 + 智斗

【钩子标签】（选1个）
硬核 / 热血 / 复仇
```

### 3.3 简介（番茄版·150字）

```
古代猎人陈山穿越到2247年，
发现儿子被铁血战士猎杀。

他只有一把刀，
但他猎了三十年的虎豹熊狼。

第一个铁血，死在陷阱里。
第二个铁血，死在追踪中。
第五个铁血，放下所有装备，
只带一把刀走进丛林——

它终于明白，谁才是真正的猎手。

【关键】
- 前50字必须有冲突
- 中间展示爽点
- 结尾留悬念
```

## 第四部分：金手指设计

### 4.1 金手指四要素

```
【获取方式】
穿越时带了一把刀，刀上有八个缺口，
每个缺口都是一次生死。

【核心能力】
"读兽术"——把任何猎手当野兽来猎
- 看脚印知道移动习惯
- 听声音判断情绪伤势
- 闻气味追踪位置
- 用陷阱杀死自大的猎手

【升级路径】（500章版）
第1-100章：把铁血当野兽
第101-200章：发现规则，用规则
第201-300章：理解文化，心理战
第301-400章：组建联盟，战术升级
第401-500章：文明对话，哲学碰撞

【代价机制】
每杀一个铁血，失去一部分人性
- 第1个：开始享受猎杀
- 第2个：对尸体没敬意
- 第3个：用铁血逻辑思考
- 第4个：差点忘记儿子
- 第5个：必须选择人性还是复仇
```

## 第五部分：章节写作技巧

### 5.1 番茄章节结构（2500-3000字）

```
【开头】（300字）
- 第一句：动作/对话/冲突
- 前300字：钩子+冲突+悬念

【中段】（1000字）
- 推进剧情
- 爆点必须在1000字前出现
- 每500字一个小冲突

【结尾】（200字）
- 章末钩子（悬念/危机/反转）
- 让读者想看下一章
```

### 5.2 开头公式

```
【第一句铁律】
必须是：动作/对话/冲突

✅ 好开头：
"刀刃插进铁血的脖子。"
"你儿子，是我杀的。"
"五个铁血战士包围了陈山。"

❌ 烂开头：
"月光洒在丛林里。"（环境）
"陈山想起了往事。"（回忆）
"这是2247年。"（背景）
```

### 5.3 爽点设计

```
【爽点类型】（每章选一个）
- 打脸爽：轻蔑→出手→震惊（300字）
- 反杀爽：绝境→翻盘→碾压（500字）
- 装逼爽：低调→被迫出手→震撼（400字）
- 获得爽：战斗→胜利→获得装备（200字）
- 身份爽：隐藏→暴露→震惊（300字）

【爽点位置】
必须在1000字前出现

【爽点禁区】
❌ 铺垫超过500字
❌ 爽点太弱（说狠话不算）
❌ 连续重复（三章都打脸）
❌ 不可视化（"变强了"看不见）
```

### 5.4 章末钩子

```
【钩子类型】
- 悬念钩：抛出新问题
- 危机钩：更强敌人出现
- 反转钩：推翻前面认知
- 装逼钩：主角说狠话

【钩子公式】
最后50字 + 强情绪 + 让人想点下一章

✅ 好钩子：
"但陈山不知道，真正的危机才刚开始。"
"远处，一个独眼铁血走了过来。"
"骨哨上，刻着一行字：爸爸救我。"

❌ 烂钩子：
"陈山回家了。"（太平淡）
"明天继续战斗。"（没悬念）
```

### 5.5 对话技巧

```
【对话铁律】
1. 每句话≤15字
2. 禁止"的地得"连用
3. 禁止文言文
4. 多用短句

【对比】
❌ 起点式：
"阁下实力不凡，在下佩服。"

✅ 番茄式：
"你很强。"
"谁教你的？"

【冲突对话】
A嘲讽（1句）→ B冷笑（1句）→ A愤怒（1句）→ B出手
```

### 5.6 战斗场景

```
【战斗节奏】
铺垫（50字）→ 交锋（300字）→ 终结（100字）
总计≤500字

【战斗描写】
只写结果，不写过程

❌ 烂写法：
"陈山抬起右手，握紧刀柄，用力向前刺去..."

✅ 好写法：
"陈山出刀。
铁血倒下。
其他四个铁血懵了。"
```

### 5.7 标题公式

```
第X章 + 爽点关键词 + 情绪词

【关键词库】
战斗类：猎杀/反杀/秒杀/碾压/团灭
情绪类：震惊/懵了/傻眼/跪了/慌了
身份类：暴露/曝光/真相/原来/竟然
装逼类：打脸/装逼/嘲讽/后悔/求饶
悬念类：发现/秘密/阴谋/危机/绝境

【示例】
✅ 第3章：猎杀铁血战士！
✅ 第25章：铁血震惊：这个人类不对劲
✅ 第50章：用假气味引嗅影进陷阱

❌ 第1章：山中有虎（太文艺）
```

## 第六部分：四季管理策略

### 6.1 季度规划铁律

```
每季必须有：
1. 独立主线（能单独讲一个完整故事）
2. 独立高潮（季末必有S级爆点）
3. 独立完结感（给读者阶段性满足）
4. 下季钩子（最后5章埋钩子）
```

### 6.2 季度切换技巧

```
【季末最后5章】
倒数第5章：本季最终爆点
倒数第4章：情感沉淀
倒数第3章：短暂平静
倒数第2章：下季危机预兆
倒数第1章：新危机爆发

【新季前5章】
第1章：新危机展开
第2章：主角应对
第3章：发现新敌人
第4章：制定新计划
第5章：第一次小胜（给信心）
```

### 6.3 每季核心变化

```
【第一季→第二季】
场景：丛林 → 母舰
敌人：五人队 → 精英队
战力：个人 → 小团队
格局：生存 → 保护

【第二季→第三季】
场景：地球 → 星际
敌人：精英队 → 各族
战力：小团队 → 联盟
格局：保护 → 反抗

【第三季→第四季】
场景：星际 → 母星
敌人：各族 → 保守派
战力：联盟 → 文明
格局：反抗 → 改写
```

## 第七部分：爆点管理系统

### 7.1 爆点分级

```
【S级爆点】（每季1-2个）
- 猎杀核心反派
- 世界观重大揭露
- 主角质变升级
- 用于季末高潮

【A级爆点】（每25章1个）
- 猎杀次要反派
- 获得关键装备
- 重要配角牺牲
- 用于卷末高潮

【B级爆点】（每10章1个）
- 一次漂亮反杀
- 一次规则利用
- 一次智斗胜利
- 用于维持热度

【C级爆点】（每2-3章1个）
- 小规模战斗
- 获得小道具
- 小配角发光
- 用于日常更新
```

### 7.2 爆点储备库（500章专用）

```
【战斗类】（准备50个）
陷阱反杀×15
正面硬刚×10
智斗获胜×10
装备碾压×10
联手作战×5

【情感类】（准备30个）
父子互动×10
战友牺牲×5
敌人认可×5
回忆杀×5
传承时刻×5

【世界观类】（准备20个）
新种族登场×5
历史真相×5
科技突破×5
文化冲突×5

【反转类】（准备20个）
敌人变盟友×5
盟友背叛×3
真相揭露×7
身份曝光×5
```

### 7.3 爆点使用原则

```
1. 不要连续用同类型爆点
2. 每季至少用5种不同类型
3. S级爆点必须提前10章铺垫
4. A级爆点提前5章铺垫
5. B/C级爆点可以即兴
6. 永远保持10个备用爆点
```

## 第八部分：节奏控制技巧

### 8.1 波浪式节奏

```
高潮期（20章）→ 缓冲期（5章）→ 高潮期（20章）

【高潮期】
- 连续战斗
- 爆点密集
- 每章都有冲突
- 读者肾上腺素飙升

【缓冲期】
- 不是无聊，是蓄力
- 展示主角成长
- 埋下新伏笔
- 让读者喘口气

比例：高潮4: 缓冲1
```

### 8.2 每100章大节奏

```
第1-100章：建立世界观+ 第一季完结
第101-200章：扩大格局 + 第二季完结
第201-300章：星际视野 + 第三季完结
第301-400章：文明碰撞 + 第四季前半
第401-500章：终极对决 + 全书完结

每100章必须：
- 换一个大场景
- 换一批敌人
- 升级一次战力
```

### 8.3 轮换制度

```
【配角轮换】（每50章）
第1-50章：主角+儿子
第51-100章：主角+飞行员
第101-150章：主角+断牙回忆
第151-200章：主角+幸存者领袖
...

【场景轮换】（每100章）
第1-100章：原始丛林
第101-200章：铁血营地+飞船
第201-300章：星际空间
第301-400章：铁血母星
第401-500章：荣耀殿堂+地球

【战斗类型轮换】（每50章）
第1-50章：陷阱战
第51-100章：追逐战
第101-150章：正面硬刚
第151-200章：智斗战
...
```

## 第九部分：工作流程

### 9.1 日更工作流（每天2章）

```
【早上8:00-9:00】预热
□ 看昨天数据（留存率/完读率）
□ 如果数据差，调整今天内容
□ 写今天2章的章节卡

【上午9:00-12:00】写作
□ 写第一章（2500-3000字）
  - 开头300字（钩子）
  - 中段1000字（爆点在1000字前）
  - 结尾200字（钩子）
□ 检查：爆点够强吗？钩子够强吗？

【下午14:00-17:00】写作
□ 写第二章（2500-3000字）
□ 用不同的爆点类型
□ 检查标题（带关键词了吗）

【晚上17:00-18:00】发布
□ 通读两章，删废话
□ 检查对话（每句≤15字）
□ 发布

【睡前】
□ 写明天第一章开头300字
□ 不想剧情，让潜意识工作
```

### 9.2 周复盘工作流

```
【每周日晚上】
□ 统计本周数据
□ 找出数据最好的3章（总结经验）
□ 找出数据最差的3章（避免重复）
□ 检查本周是否偏离大纲
□ 列出下周要兑现的伏笔
□ 准备5个备用爆点
□ 写下周前3章的大纲
```

### 9.3 月复盘工作流

```
【每月最后一天】
□ 统计本月总体数据
□ 分析数据趋势（上升/平稳/下降）
□ 检查本月是否完成季度目标
□ 调整下月节奏（加快/放慢）
□ 更新人物状态卡
□ 检查伏笔管理表
□ 准备下月的10个A级爆点
```

### 9.4 季复盘工作流

```
【每季结束后】
□ 休息一周（必须休息）
□ 统计本季总体数据
□ 总结本季成功经验
□ 总结本季失败教训
□ 规划下季主线
□ 设计下季核心反派
□ 准备下季的20个B级爆点
□ 写下季前10章的详细大纲
```

## 第十部分：提示词系统

### 提示词1：章节大纲生成

```
【输入】
我要写第X章，主角当前状态是[状态]，
本章目标是[目标]，字数2500-3000字。

【输出】
```

## 第十一部分：数据管理

### 11.1 关键数据指标

```
【前三章留存率】

- 合格：60-75%
- 危险：<60%（算法不推荐）

【日更新字数】
- 最低：3000字（2章×1500字）
- 推荐：4000字（2章×2000字）
-冲榜：6000字（3章×2000字）
```

### 11.2 数据监控系统

```
【每日必看】
- 昨天章节留存率（必须>60%）
- 昨天章节完读率（必须>70%）
- 评论区热度（有没有爆点讨论）

【每周必看】
- 本周平均留存率（必须>65%）
- 本周新增追读（是否增长）
- 本周掉读情况（哪章掉得多）

【每月必看】

- 哪些章节数据最好（总结经验）
- 哪些章节数据最差（避免重复）
```

### 11.3 数据波动应对

```
【留存率突然下降】
原因：上一章太水/爆点不够/节奏太慢
应对：下一章立刻插入爆点

【完读率突然下降】
原因：本章太长/废话太多/没有钩子
应对：下一章控制字数，强化钩子

【评论区骂"水"】
原因：连续几章没爆点
应对：立刻写一场战

【推荐量突然下降】
原因：断更/数据差/算法调整
应对：保持日更，提高质量
```

## 第十二部分：避坑指南

### 12.1 番茄致命错误

```
❌ 错误1：前三章没爆点
后果：算法不推荐，书直接死
解决：前三章每章必须有爆点

❌ 错误2：章节超过2500字
后果：读者看不完，完读率低
解决：严格控制2500-3000字

❌ 错误3：开头写环境描写
后果：读者直接跑
解决：第一句必须是冲突

❌ 错误4：对话太文艺
后果：读者看不懂
解决：每句话≤15字

❌ 错误5：断更
后果：算法直接不推
解决：必须日更，保持存稿

❌ 错误6：标题不带关键词
后果：点击率低
解决：标题必须带爽点关键词

❌ 错误7：铺垫章节
后果：读者流失
解决：番茄没有铺垫章
```

### 12.2 500章特有的坑

```
❌ 坑1：中期失速
症状：写到200章，不知道写什么
原因：季度规划不清晰
解决：提前规划好四季主线

❌ 坑2：配角过多
症状：配角太多，主角戏份被稀释
原因：每季都加新配角
解决：配角轮换制，旧配角退场

❌ 坑3：战力崩溃
症状：主角太强，没有对手
原因：升级太快
解决：每季换更强的敌人

❌ 坑4：伏笔烂尾
症状：前期埋的伏笔忘了兑现
原因：没有伏笔管理表
解决：建立伏笔管理系统

❌ 坑5：读者流失
症状：写到300章，留存率暴跌
原因：节奏单调，读者疲劳
解决：每100章换场景+换敌人

❌ 坑6：作者崩溃
症状：写到400章，写不动了
原因：连续高强度更新
解决：每季休息一周，保持存稿

❌ 坑7：爆点重复
症状：读者说"又是这招"
原因：爆点类型太单一
解决：建立爆点储备库，轮换使用

❌ 坑8：场景单调
症状：读者视觉疲劳
原因：500章都在一个场景
解决：每100章换场景
```

### 12.3 防疲劳策略

```
【读者疲劳】
症状识别：
- 完读率连续下降
- 评论区抱怨"水"
- 留存率低于60%

应对方案：
1. 立刻插入一个B级爆点
2. 提前引爆一个伏笔
3. 让配角发光（换个视角）
4. 写一场酣畅淋漓的战斗
5. 跳过当前剧情，直接写下一个高潮

【作者疲劳】
症状识别：
- 写不出来
- 写得很痛苦
- 质量明显下降

应对方案：
1. 每周休息一天（不更新）
2. 每50章休息3天（存稿期）
3. 每季结束休息一周（调整期）
4. 卡文时跳过，写下一个爽点
5. 实在不行，写一章战斗（万能）

预防措施：
- 永远保持10章存稿
- 每周提前写好下周大纲
- 每月复盘一次节奏
- 不要连续写超过3个月
```

```
- 每周休息一天
- 记住：写完就是胜利
```

```
陈山握紧刀，警惕地观察四周。

这里的树很奇怪，叶子是蓝色的。
空气里有股怪味。
远处传来奇怪的声音。

两米高，全身盔甲，手里拿着奇怪的武器。

陈山屏住呼吸，准备退走。

陈山的手抖了。

【结尾500字】
陈山的脑子一片空白。

儿子的骨哨，为什么会在这里？
儿子在哪？

他想冲过去，但理智告诉他不行——
这些怪物很危险。

陈山深吸一口气，退进丛林。

把儿子带回家。

远处，那个独眼的怪物突然转头，看向陈山藏身的方向。

陈山一动不动。

三秒后，怪物收回视线。

陈山握紧刀，刀刃上还有虎血。
```
