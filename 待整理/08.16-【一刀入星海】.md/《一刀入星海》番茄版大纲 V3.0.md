
## 【第一步】商业化包装（番茄版）

**书名：** 《一刀猎杀星际战士》  
（原名太文艺，番茄要直接）

**标签：**

- 主标签：科幻 + 星际战争
- 爽点标签：爽文 + 反杀 + 扮猪吃虎
- 钩子标签：硬核 + 复仇 + 热血

**简介（番茄版·200字）：**

```
古代猎人陈山，穿越到2247年。

落地就看见五个铁血战士，
其中一个腰间挂着他儿子的骨哨——
那是他亲手做的成人礼。

陈山只有一把刀。
但他猎了三十年的虎豹熊狼，
这些星际猎手，也不过是会用工具的野兽。

第一个铁血，死在陷阱里。
第二个铁血，死在追踪中。
第三个铁血，死在自己的科技下。

当最后一个铁血放下所有装备，
只带一把刀走进丛林时——
它终于明白，谁才是真正的猎手。
```

## 【第二步】金手指设计（番茄版）

### 2.1 金手指四要素

**获取方式：**   
穿越时带了一把刀——刀刃上有八个缺口，每个缺口都是一次生死。  
这把刀跟了他三十年，是他唯一的武器。

**核心能力：**   
"读兽术"——把任何猎手当成野兽来猎

- 看脚印知道体重和移动习惯
- 听声音判断情绪和伤势
- 闻气味追踪目标位置
- 用陷阱杀死任何自大的猎手

**升级路径（番茄版·简化）：**

```
第1阶段（1-30章）：把铁血当野兽猎
第2阶段（31-60章）：发现铁血有规则，开始用规则
第3阶段（61-90章）：理解铁血文化，开始心理战
第4阶段（91-120章）：和最强铁血的终极对决
```

**代价机制：**   
每杀一个铁血，陈山就失去一部分人性——

- 杀第一个：开始享受猎杀
- 杀第二个：对尸体没有敬意
- 杀第三个：开始用铁血的逻辑思考
- 杀第四个：差点忘记儿子的脸
- 杀第五个：必须选择——人性还是复仇
