# 番茄小说顶流密码·写作手册

---

## 一、番茄vs起点：核心差异

|维度|起点|番茄|你要怎么做|
| ------| ---------------------| ---------------------| --------------------------|
|**读者群**|25-35岁，付费意愿强|18-30岁，下沉市场|文字更白话，爽点更直接|
|**付费模式**|订阅制，看重月票|免费+广告，看重留存|每章必须有钩子，不能断更|
|**章节长度**|3000-4000字|1500-2000字|一章只写一个爽点|
|**爽点密度**|每3-5章一个|每章必须有|不能有铺垫章|
|**推荐机制**|编辑推荐+榜单|算法推荐|前三章留存率决定生死|
|**标题**|可以文艺|必须带爽点关键词|"第X章 猎杀铁血战士"|

## 二、番茄顶流密码

### 2.1 黄金三章铁律（生死线）

```
第一章：必须在500字内出现冲突
第二章：必须有一次小爽（打脸/反杀/获得）
第三章：必须有一次大爽（身份曝光/实力展示/反派震惊）

前三章留存率<60%，这书就死了
```

### 2.2 番茄爽点公式

```
番茄爽点 = 直接+快速+可视化

直接：不绕弯子，主角想干就干
快速：从冲突到爽点≤300字
可视化：必须有画面感，能脑补成短视频
```

**对比：**

❌ 起点式（太慢）：

```
陈山思考了三天，终于想到一个计划。
他开始布置陷阱，花了两天时间...
```

✅ 番茄式（够快）：

```
陈山冷笑。
三分钟后，铁血踩进陷阱，惨叫响彻丛林。
```

### 2.3 番茄章节结构（1500-2000字）

```
开头（300字）：钩子+冲突
中段（1000字）：推进+爽点
结尾（200字）：钩子+悬念

每章只写一件事，不要多线并进
```

## 三、番茄章节标题技巧

### 3.1 标题公式

```
第X章 + 爽点关键词 + 情绪词

爽点关键词：猎杀/反杀/打脸/震惊/碾压/暴露
情绪词：！/？/...
```

**示例：**

❌ 文艺标题（番茄不吃这套）：

```
第一章 山中有虎
第二章 异世初临
第三章 初次交锋
```

✅ 番茄标题（算法喜欢）：

```
第一章 穿越！发现儿子的遗物
第二章 猎杀星际战士！
第三章 铁血震惊：这个人类不对劲
```

### 3.2 标题关键词库

```
【战斗类】
猎杀/反杀/秒杀/碾压/团灭/一刀/爆发

【情绪类】
震惊/懵了/傻眼/跪了/慌了/怕了

【身份类】
暴露/曝光/真相/原来/其实/竟然

【装逼类】
打脸/装逼/嘲讽/轻蔑/后悔/求饶

【悬念类】
发现/真相/秘密/阴谋/危机/绝境
```

## 四、番茄开头技巧

### 4.1 第一句话铁律

```
第一句话必须是：
- 动作（"刀刃插进铁血的脖子"）
- 对话（"你儿子，是我杀的"）
- 冲突（"五个铁血战士包围了陈山"）

禁止：
❌ 环境描写（"月光洒在丛林里"）
❌ 心理描写（"陈山想起了往事"）
❌ 背景介绍（"这是2247年"）
```

### 4.2 前300字必须出现的元素

```
□ 主角名字（让读者记住）
□ 核心冲突（谁vs谁）
□ 情绪钩子（愤怒/恐惧/震惊）
□ 悬念（为什么会这样？）
```

**示例：**

```
刀刃插进铁血战士的脖子，崩出第八个缺口。

陈山没松手，直到对方停止挣扎。他从尸体腰间解下骨哨——
那是他亲手给儿子做的成人礼。

但儿子在哪？

远处传来脚步声，又有四个铁血战士赶来。
陈山握紧刀，刀刃上的血还没干。

"来吧。"
```

## 五、番茄爽点设计

### 5.1 每章爽点类型（必选一个）

|类型|公式|字数|示例|
| ------| ---------------------------| -------| --------------------------------|
|**打脸爽**|轻蔑→出手→震惊|300字|铁血嘲笑陈山，结果被一刀反杀|
|**反杀爽**|绝境→翻盘→碾压|500字|被包围→触发陷阱→敌人团灭|
|**装逼爽**|低调→被迫出手→震撼全场|400字|陈山不想动手，但一出手就是秒杀|
|**获得爽**|战斗→胜利→获得装备/信息|200字|杀死铁血，获得高科技武器|
|**身份爽**|隐藏→暴露→众人震惊|300字|铁血发现陈山是顶级猎手|

### 5.2 番茄爽点禁区

```
❌ 铺垫太长（超过500字没爽点=读者跑了）
❌ 爽点太弱（"主角说了句狠话"不算爽点）
❌ 爽点重复（连续三章都是打脸，读者会腻）
❌ 爽点不可视化（"主角变强了"看不见）

✅ 每章爽点必须有画面感
✅ 每章爽点必须不重样
✅ 每章爽点必须在1000字前出现
```

## 六、番茄对话技巧

### 6.1 对话铁律

```
1. 每句话≤15字（太长读者看不进去）
2. 禁止"的地得"连用（"他慢慢地走了过来"→"他走过来"）
3. 禁止文言文（"尔等"→"你们"）
4. 多用短句，少用长句
```

**对比：**

❌ 起点式（太文）：

```
"阁下实力不凡，在下佩服。不知阁下师承何处？"
```

✅ 番茄式（够白）：

```
"你很强。"
"谁教你的？"
```

### 6.2 冲突对话公式（番茄专用）

```
A嘲讽（1句） → B冷笑（1句） → A愤怒（1句） → B出手

每轮对话≤3句，立刻进入战斗
```

**示例：**

```
"就你？也配猎我？"铁血轻蔑。
陈山没说话，只是握紧了刀。
"找死！"铁血冲过来。

三秒后，铁血倒在陷阱里。
```

## 七、番茄战斗场景

### 7.1 战斗节奏（番茄专用）

```
铺垫（50字） → 交锋（300字） → 终结（100字）

总计≤500字，不要写太长
```

### 7.2 战斗描写公式

```
动作（1句） → 结果（1句） → 反应（1句）

禁止写过程，只写结果
```

**对比：**

❌ 起点式（太细）：

```
陈山抬起右手,握紧刀柄,用力向前刺去。
刀尖划过空气,发出破空声。
铁血想躲,但已经来不及了。
刀刃刺进了他的脖子...
```

✅ 番茄式（够快）：

```
陈山出刀。
铁血倒下。
其他四个铁血懵了。
```

## 八、番茄章末钩子

### 8.1 钩子类型（每章必选一个）

|类型|公式|示例|
| ------| --------------| ------------------------------------|
|**悬念钩**|抛出新问题|"但陈山不知道，真正的危险才刚开始"|
|**危机钩**|更强敌人出现|"远处，一个独眼铁血走了过来"|
|**反转钩**|推翻前面认知|"骨哨上，刻着一行字：爸爸救我"|
|**装逼钩**|主角说狠话|"陈山：'还有谁？'"|

### 8.2 钩子禁区

```
❌ 太文艺（"月光如水"）
❌ 太平淡（"陈山回家了"）
❌ 没悬念（"明天继续战斗"）

✅ 必须让读者想看下一章
✅ 必须有情绪（震惊/恐惧/期待）
✅ 必须≤50字
```

## 九、番茄大纲特殊要求

### 9.1 章节长度调整

```
起点大纲：每章3000-4000字
番茄大纲：每章1500-2000字

调整方法：
起点1章= 番茄2章

示例：
起点第3章"猎杀初血"（3500字）
↓
番茄第5章"设置陷阱"（1500字）
番茄第6章"初血惨死！"（1800字）
```

### 9.2 番茄分卷结构

```
起点：4卷，每卷15-20章
番茄：8卷，每卷8-12章

原因：番茄读者喜欢频繁的"阶段性胜利"
```

### 9.3 番茄章节卡模板

```
【第X章】标题：___________

【开头钩子】（300字）
- 第一句：___________

- 爽点类型：打脸/反杀/装逼/获得/身份
- 爽点位置：第___字出现
- 爽点画面：___________

【章末钩子】（200字）
- 钩子类型：悬念/危机/反转/装逼
- 钩子内容：___________

【检查项】
□ 本章有爽点吗？

## 十、番茄工作流（日更版）

### 每日写作SOP（番茄专用）

```
【早上8:00-9:00】
□ 看昨天章节数据（留存率/完读率）
□ 如果留存率<70%，找出问题（爽点不够？钩子不强？）
□ 写今天2章的章节卡（每章1500-2000字）

【上午9:00-12:00】
□ 写第一章（1500-2000字）
  - 开头300字（钩子）
  - 中段1000字（爽点）
  - 结尾200字（钩子）
□ 自查：爽点在1000字前出现了吗？

【下午14:00-17:00】
□ 写第二章（1500-2000字）
  - 用不同的爽点类型（不要重复）
□ 自查：章末钩子够强吗？

【晚上17:00-18:00】
□ 通读两章，删掉所有废话
□ 检查对话（每句话≤15字）
□ 检查标题（带爽点关键词了吗？）
□ 发布

【睡前】
□ 写明天第一章的开头300字
```

## 十二、番茄数据指标

### 12.1 关键数据

```
【前三章留存率】
- 优秀：>70%
- 合格：60-70%
- 危险：<60%（算法不会推荐）

【章节完读率】
- 优秀：>80%
- 合格：70-80%
- 危险：<70%（说明章节太水）

【日更新字数】
- 最低：3000字（2章×1500字）
- 推荐：4000字（2章×2000字）
-冲榜：6000字（3章×2000字）
```

### 12.2 数据优化策略

```
如果留存率低：
→ 检查前三章爽点够不够
→ 检查开头钩子强不强
→ 检查标题吸不吸引人

如果完读率低：
→ 检查章节有没有废话
→ 检查爽点位置是不是太靠后
→ 检查章末钩子强不强

如果推荐量低：
→ 保持日更（断更=死亡）
→ 提高前三章留存率
→ 增加更新字数
```

## 十三、番茄避坑指南

### 13.1 致命错误（碰了就死）

```
❌ 前三章没爽点

❌ 开头写环境描写（读者直接跑）

❌ 标题不带关键词（点击率低）

```

### 13.2 番茄特殊禁区

```
❌慢热开局（番茄读者没耐心）
❌ 多线叙事（番茄读者容易乱）
❌ 复杂世界观（番茄读者不爱看设定）
❌ 文艺腔调（番茄读者要直接爽）
❌ 虐主（番茄读者只要爽，不要虐）
```

## 十五、番茄黄金三章（完整版）

### 第一章：《穿越！发现儿子遗物》（1800字）

```
【开头300字】
刀刃插进老虎的脖子。

陈山松了口气，这是他给儿子准备的成人礼——
猎一头虎，用虎骨做刀柄。

突然，天空裂开一道光。

陈山还没反应过来，脚下的地面消失了。
等他睁开眼，周围已经不是熟悉的山林。

【中段1000字】
陈山握紧刀，警惕地观察四周。

这里的树很奇怪，叶子是蓝色的。
空气里有股怪味。
远处传来奇怪的声音。

他循着声音走过去，看见了五个怪物。

两米高，全身盔甲，手里拿着奇怪的武器。
它们正在"处理"人类尸体。

陈山屏住呼吸，准备退走。

但他看见了一个东西——
那个最年轻的怪物腰间，挂着一个骨哨。

陈山的手抖了。

那是他亲手给儿子做的，上面有他刻的记号。

【结尾500字】
陈山的脑子一片空白。

儿子的骨哨，为什么会在这里？
儿子在哪？

他想冲过去，但理智告诉他不行——
这些怪物很危险。

陈山深吸一口气，退进丛林。

他是猎人，猎人不会冲动。
他要先观察，找到机会，然后——

把儿子带回家。

远处，那个独眼的怪物突然转头，看向陈山藏身的方向。

陈山一动不动。

三秒后，怪物收回视线。

陈山握紧刀，刀刃上还有虎血。
很快，就会有新的血了。
```

### 第二章：《设置陷阱！》（1600字）

```
【开头300字】
陈山跟踪了这些怪物三个小时。

他发现了几件事：
1. 它们有等级，独眼的是老大
2. 它们走的路线很固定
3. 它们会说话，但听不懂

最重要的是——
它们走路的方式，和猛兽一样。

陈山笑了。

【中段1000字】
陈山开始设陷阱。

在地上挖了个坑，
底下插满削尖的木桩，

这是他猎了三十年的老办法。

管你是什么怪物，
掉进去，就得死。

一个小时后，
那个腰间挂着骨哨的年轻怪物走了过来。

陈山屏住呼吸。

更近了。

【结尾300字】
年轻怪物一脚踩在树叶上。

树叶塌了。

怪物掉进坑里，
尖木桩刺进它的腿，
它发出一声惨叫。

它的盔甲太硬，木桩没刺穿要害。

陈山皱眉。

这些怪物的防御比他想的强。

怪物挣扎着要爬出来，
其他四个怪物听到声音，正在赶来。

陈山必须做出选择：
是现在逃走，还是——

他看了一眼怪物腰间的骨哨。

"对不起了。"

陈山从树上跳下来。

## 十六、番茄作者生存指南

### 16.1 日更铁律

```
番茄=日更平台

断更一天，推荐量腰斩
断更三天，算法放弃你
断更一周，这书就死了

最低标准：每天2章（3000字）
推荐标准：每天2-3章（4000-6000字）
```

### 16.2 番茄作者的10个习惯

```
1. 每天固定时间更新（培养读者习惯）
2. 每章必须有爽点（没爽点=没推荐）
3. 标题必须带关键词（影响点击率）
4. 章末必须有钩子（影响留存率）
5. 每天看数据（留存率/完读率）
6. 备3章存稿（防止意外断更）
7. 对话要白话（番茄读者不爱文艺腔）
8. 章节要短（1500-2000字最佳）
9. 爽点要快（1000字内必须出现）
```
