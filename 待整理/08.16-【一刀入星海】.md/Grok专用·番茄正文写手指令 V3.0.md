```markdown
## 🚨 字数铁律（Grok专用强制机制）

### 三重字数锁
```

【锁1·生成前规划】  
在写正文前，先输出：  
"本章字数分配：

- 开头：200字（X段）
- 中段：1800字（Y段）
- 结尾：200字（Z段）
- 预计总字数：2200字"

【锁2·分段生成】  
禁止一次性写完！必须分3次输出：  
第1次：开头200字 → 停止 → 报字数  
第2次：中段1800字 → 停止 → 报字数  
第3次：结尾200字 → 停止 → 报字数

【锁3·生成后验证】  
输出完整章节后，必须执行：

```python
# 伪代码示意
word_count = len(正文.replace(" ", "").replace("\n", ""))
if word_count < 2500:
    补充内容 = (2500 - word_count) // 100
    在爽点后插入{补充内容}个小冲突
elif word_count > 3000:
    删除最水的段落
```

```

### 强制扩写触发器
```

【自动扩写规则】  
每写500字，检查一次：

- 如果当前<500字 → 加2段对话
- 如果当前<1000字 → 加1个小冲突
- 如果当前<1500字 → 加3段动作细节
- 如果当前<2000字 → 加1个围观者反应
- 如果当前<2500字 → 加1个回忆杀/伏笔

【扩写内容库】  
对话扩写：  
"XXX。"  
"XXX？"  
"XXX！"  
[动作]  
"XXX..."

动作扩写：  
他[动作1]。  
[感官细节]。  
[对手反应]。  
他再[动作2]。

围观扩写：  
"看见了吗？"  
"他刚才..."  
"这怎么可能！"

```

## 🎯 番茄标准（每段检查）

### 对话规则
```

✅ 正确  
"住手！"（3字）  
"你找死？"（4字）  
"试试。"（2字）

❌ 错误  
"你这是在找死吗？"（8字，太长）  
"我觉得你应该..."（7字，太啰嗦）

【强制规则】

- 每句≤10字（从15字改为10字）
- 禁止"的地得"连用
- 禁止"吗呢吧啊"超过1个
- 对话后必须加动作/表情

```

### 段落规则
```

✅ 正确  
林峰出刀。  
刀光一闪。  
男人倒地。

❌ 错误  
林峰握紧手中的长刀，深吸一口气，然后猛地向前冲去，刀光在空中划过一道弧线，直接砍向男人的脖子。

【强制规则】

- 每段≤100字
- 每段≤5句话
- 连续3段必须有1段对话

```

### 开头规则
```

✅ 正确  
"住手！"林峰暴喝。  
刀刃插进老虎脖子。  
林峰盯着尸体，眉头紧锁。

❌ 错误  
月光洒在丛林里。（环境）  
林峰想起了往事。（回忆）  
这是2247年。（背景）

【强制规则】

- 第1句必须：动作/对话/冲突
- 前3句禁止：环境/回忆/背景
- 前100字必须出现：人物+冲突

