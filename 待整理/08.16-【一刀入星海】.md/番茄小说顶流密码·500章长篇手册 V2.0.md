## 第一部分：番茄平台认知

### 1.1 番茄 vs 起点核心差异

|维度|起点|番茄|你要做什么|
| ------| ---------------------| -------------------| ------------------------|
|**读者群**|25-35岁，付费意愿强|18-30岁，下沉市场|文字更白话，爽点更直接|
|**付费模式**|订阅制|免费+广告|每章必须有钩子留人|
|**章节长度**|3000-4000字|2500-3000字|一章只写一个主爆点|
|**爽点密度**|每3-5章一个|每2-3章一个|不能有纯铺垫章|
|**推荐机制**|编辑推荐|算法推荐|前三章留存率决定生死|
|**标题**|可以文艺|必须带爽点关键词|"第X章 猎杀铁血战士"|
|**对话**|可以文雅|必须白话|每句话≤10字（修订）|
|**更新**|可以断更|断更=死亡|必须日更|

### 1.2 番茄读者画像

```
【核心特征】
- 年龄：18-30岁
- 阅读时间：碎片化（通勤、午休、睡前）
-阅读习惯：快速翻页，不喜欢长段落
- 付费意愿：低（看免费+广告）
- 耐心：极低（3章不爽就跑）

【他们要什么】
- 直接的爽感（不要绕弯子）
- 快速的节奏（不要慢热）
- 简单的文字（不要文言文）
- 强烈的画面感（能脑补成短视频）
- 每章都有期待（章末钩子）

【他们不要什么】
- 复杂的世界观
- 文艺的描写
- 慢热的开局
- 纯铺垫的章节
- 虐主的剧情
```

### 1.3 番茄算法逻辑

```
【推荐三要素】
1. 前三章留存率（>75%才有推荐）
2. 章节完读率（>70%才继续推）
3. 日更稳定性（断更=推荐归零）

【算法喜欢】
- 标题带爽点关键词
- 开头500字有冲突
- 章末有强钩子
- 每2-3章有爆点
- 日更不断

【算法讨厌】
- 标题太文艺
- 开头写环境
- 章末没钩子
- 连续铺垫章
- 断更
```

## 第二部分：500章长篇特性（修订版）

### 2.1 500章 vs 120章差异

|维度|120章短篇|500章长篇|关键差异|
| ------| ------------| -----------------| ----------------------|
|**连载周期**|60天|300天（含缓冲）|从冲刺变马拉松|
|**爆点密度**|每章必须有|每2-3章一个|可以适当降低|
|**节奏**|一路高潮|波浪式|高潮→缓冲→高潮|
|**场景**|单一场景|必须轮换|每50章换场景（修订）|
|**敌人**|固定敌人|必须升级|每季换敌人|
|**配角**|固定配角|必须轮换|每50章换配角|
|**读者疲劳**|不用管|必须管理|建立防疲劳机制|
|**作者疲劳**|不用管|必须管理|每季休息一周|

### 2.2 四季结构设计（均衡版）

```
【第一季】猎杀五个铁血（1-125章）
- 主线：救出儿子（25章内完成）→ 保护儿子 → 猎杀断牙
- 场景：丛林 → 铁血营地 → 培养舱飞船
- 敌人：五人狩猎队
- 结局：断牙投降礼，陈山意识到失去人性

【第二季】对抗母舰（126-250章）
- 主线：拒绝加入铁血 → 击杀精英小队 → 决战审判者
- 场景：地球废墟 → 母舰内部 → 星际空间
- 敌人：精英小队 + 审判者
- 结局：母舰撤离，儿子说"爸爸你变了"

【第三季】星际逃亡与联盟（251-375章）
- 主线：逃离地球 → 组建反铁血联盟 → 发现铁血秘密
- 场景：星际空间 → 异族星球 → 铁血母星外围
- 敌人：铁血各族哨站
- 结局：发现铁血曾经也是猎物

【第四季】反攻母星与文化改写（376-500章）
- 主线：联手新生 → 摧毁荣耀殿堂 → 改写铁血文化
- 场景：铁血母星 → 荣耀殿堂 → 地球（终章）
- 敌人：保守派 + 永恒
- 结局：传承永续

每季125章 + 独立主线 + 独立高潮 + 独立完结感
```

## 第三部分：商业化包装

### 3.1 书名公式（番茄版）

```
公式：核心元素 + 爽点暗示

【推荐】
- 《一刀猎星海》（直接）
- 《古代猎人在星际》（身份对比）
- 《我用陷阱猎铁血》（方法暗示）

【不推荐】
- 《一刀入星海》（太文艺）
- 《猎手传说》（太抽象）
- 《星际狩猎》（没特色）
```

### 3.2 标签选择

```
【主标签】（必选1个）
星际 / 异族入侵

【爽点标签】（必选2个）
扮猪吃虎 + 智斗

【钩子标签】（选1个）
硬核 / 复仇
```

### 3.3 简介（番茄版·150字）

```
古代猎人陈山穿越到2247年，
发现儿子被铁血战士囚禁在培养舱，即将被改造成猎物。

他只有一把刀，和三十年猎虎豹熊狼的经验。

第一个铁血，死在陷阱里。
第二个铁血，死在追踪中。
第五个铁血，放下所有装备，只带一把刀走进丛林——

它终于明白，谁才是真正的猎手。

但陈山不知道，每杀一个铁血，他都在失去作为"人"的东西。

【关键】
- 前50字必须有冲突
- 中间展示爽点
- 结尾留悬念+代价
```

## 第四部分：金手指设计（认知盲区版）

### 4.1 金手指四要素

```
【获取方式】
穿越时带了一把刀，刀上有八个缺口，
每个缺口都是一次生死搏杀的记忆。

【核心能力】
"认知盲区猎杀"——能看穿对手依赖的认知系统（科技/文化/本能），
利用盲区击杀。

不是"把铁血当野兽"，而是"看穿铁血依赖科技的盲区"。

【升级路径】（500章版）
第1-25章：陷阱猎杀（利用地形盲区）
第26-50章：追踪猎杀（利用感知盲区）
第51-100章：规则猎杀（利用文化盲区）
第101-125章：心理猎杀（利用认知盲区）
第126-250章：战术猎杀（利用配合盲区）
第251-375章：文明猎杀（利用历史盲区）
第376-500章：哲学猎杀（利用存在盲区）

【代价机制】（可视化）
每杀一个铁血，失去一部分人性：
- 第1个（嗅影）：开始享受猎杀的快感
- 第2个（铸械）：对尸体失去敬意
- 第3个（刻典）：用铁血逻辑思考问题
- 第4个（雷鸣）：差点对儿子说"你太弱了"
- 第5个（断牙）：必须选择——杀死他=失去最后的人性
```

### 4.2 认知盲区核心方法论

```
【什么是认知盲区】
依赖某种系统（科技/文化/本能）导致的感知死角。

【铁血的认知盲区】
1. 科技依赖盲区：
   - 依赖热成像 → 用泥浆隔绝体温
   - 依赖隐形装置 → 用声音/气味追踪
   - 依赖等离子炮 → 近身肉搏

2. 文化依赖盲区：
   - "尊重强者"准则 → 故意展示实力，让他们不敢偷袭
   - "光明正大"准则 → 用陷阱羞辱他们
   - "不杀弱者"准则 → 装弱引诱

3. 本能依赖盲区：
   - 猎手本能 → 反向追踪
   - 荣誉本能 → 激怒他们做蠢事
   - 等级本能 → 让他们内讧

【陈山的优势】
他不依赖任何系统，只依赖经验和直觉。
所以他没有盲区，或者说盲区最小。

【陈山的代价】
每次利用盲区猎杀，他都在学习铁血的思维方式，
最终他也会产生新的盲区——"猎手盲区"。
```

## 第五部分：章节写作技巧

### 5.1 番茄章节结构（2500-3000字）

```
【开头】（300字）
- 第一句：动作/对话/冲突
- 前300字：钩子+冲突+悬念

【中段】（1000字）
- 推进剧情
- 爆点必须在1000字前出现
- 每500字一个小冲突

【结尾】（200字）
- 章末钩子（悬念/危机/反转）
- 让读者想看下一章
```

### 5.2 开头公式

```
【第一句铁律】
必须是：动作/对话/冲突

✅ 好开头：
"刀刃插进老虎的脖子。"
"你儿子，是我杀的。"
"五个铁血战士包围了陈山。"

❌烂开头：
"月光洒在丛林里。"（环境）
"陈山想起了往事。"（回忆）
"这是2247年。"（背景）
```

### 5.3 爽点设计

```
【爽点类型】（每章选一个）
- 打脸爽：轻蔑→出手→震惊（300字）
- 反杀爽：绝境→翻盘→碾压（500字）
- 装逼爽：低调→被迫出手→震撼（400字）
- 获得爽：战斗→胜利→获得装备（200字）
- 身份爽：隐藏→暴露→震惊（300字）
- 认知爽：盲区→利用→击杀（新增，500字）

【爽点位置】
必须在1000字前出现

【爽点禁区】
❌ 铺垫超过500字
❌ 爽点太弱（说狠话不算）
❌ 连续重复（三章都打脸）
❌ 不可视化（"变强了"看不见）
```

### 5.4 章末钩子

```
【钩子类型】
- 悬念钩：抛出新问题
- 危机钩：更强敌人出现
- 反转钩：推翻前面认知
- 装逼钩：主角说狠话
- 代价钩：人性流失警告（新增）

【钩子公式】
最后50字 + 强情绪 + 让人想点下一章

✅ 好钩子：
"但陈山不知道，真正的危机才刚开始。"
"远处，一个独眼铁血走了过来。"
"骨哨上，刻着一行字：爸爸救我。"
"陈山看着镜子，发现自己的眼神和铁血一样冷。"（新增）

❌ 烂钩子：
"陈山回家了。"（太平淡）
"明天继续战斗。"（没悬念）
```

### 5.5 对话技巧（修订版）

```
【对话铁律】
1. 每句话≤10字（从15字改为10字）
2. 禁止"的地得"连用
3. 禁止文言文
4. 多用短句

【对比】
❌ 起点式：
"阁下实力不凡，在下佩服。"（11字）

✅ 番茄式：
"你很强。"（3字）
"谁教的？"（4字）

【冲突对话】
A嘲讽（1句）→ B冷笑（1句）→ A愤怒（1句）→ B出手

【示例】
铁血："虫子。"（2字）
陈山："试试。"（2字）
铁血："找死！"（2字）
陈山出刀。
```

### 5.6 战斗场景

```
【战斗节奏】
铺垫（50字）→ 交锋（300字）→ 终结（100字）
总计≤500字

【战斗描写】
只写结果，不写过程

❌ 烂写法：
"陈山抬起右手，握紧刀柄，用力向前刺去..."

✅ 好写法：
"陈山出刀。
铁血倒下。
其他四个铁血懵了。"

【认知盲区战斗模板】（新增）
1. 铁血依赖X系统（50字）
2. 陈山发现盲区（100字）
3. 利用盲区设陷阱（200字）
4. 铁血中招（100字）
5. 补刀（50字）
```

### 5.7 标题公式

```
第X章 + 爽点关键词 + 情绪词

【关键词库】
战斗类：猎杀/反杀/秒杀/碾压/团灭
情绪类：震惊/懵了/傻眼/跪了/慌了
身份类：暴露/曝光/真相/原来/竟然
装逼类：打脸/装逼/嘲讽/后悔/求饶
悬念类：发现/秘密/阴谋/危机/绝境
代价类：失控/黑化/迷失/选择（新增）

【示例】
✅ 第3章：猎杀铁血战士！
✅ 第25章：救出儿子！培养舱倒计时
✅ 第58章：用假气味引嗅影进陷阱
✅ 第125章：断牙投降礼！陈山失去人性（新增）

❌ 第1章：山中有虎（太文艺）
```

## 第七部分：爆点管理系统（280个）

### 7.1 爆点分级（修订版）

```
【S级爆点】（每季1个，共4个）
- 猎杀核心反派
- 世界观重大揭露
- 主角质变升级
- 用于季末高潮

【A级爆点】（每25章1个，共20个）
- 猎杀次要反派
- 获得关键装备
- 重要配角牺牲
- 用于卷末高潮

【B级爆点】（每10章1个，共50个）
- 一次漂亮反杀
- 一次规则利用
- 一次智斗胜利
- 用于维持热度

【C级爆点】（每2-3章1个，共200个）
- 小规模战斗
- 获得小道具
- 小配角发光
- 用于日常更新

总计：4+20+50+200 = 274个（预留6个机动）
```

### 7.2 爆点储备库（500章专用）

```
【战斗类】（80个）
陷阱反杀×20
正面硬刚×15
智斗获胜×20
装备碾压×15
联手作战×10

【情感类】（50个）
父子互动×15
战友牺牲×10
敌人认可×10
```

## 第十五部分：500章作者生存法则

### 15.1 十大生存法则

```
1. 永远保持10章存稿（救命稻草）
2. 每周休息一天（防止崩溃）
3. 每季休息一周（必须休息）
4. 数据差不要慌（立刻插爆点）
5. 卡文就跳过（写下一个爽点）
6. 不要和读者吵架（浪费时间）
7. 不要追求完美（完成>完美）
8. 不要轻易改大纲（容易乱）
9. 相信自己的节奏（别被带偏）
10. 写完就是胜利（500章是马拉松）
```

### 15.2 心态管理

```
【正常心态】
- 数据有波动很正常
- 偶尔写得不好很正常
- 读者有负面评论很正常
- 卡文很正常

【危险心态】
- 数据一差就想弃书
- 被负面评论影响情绪
- 和读者对骂
- 频繁改大纲
- 追求完美主义

【调整方法】
- 只看有价值的评论
- 数据差就插爆点
- 卡文就跳过
- 每周休息一天
- 记住：写完就是胜利
```

### 15.3 时间管理

```
【日常时间分配】
写作：6小时（上午3小时+下午3小时）
休息：2小时（中午+晚饭）
复盘：1小时（看数据+规划）
其他：15小时（睡觉+生活）

【不要做的事】
- 不要熬夜写作（质量差）
- 不要连续写超过3小时（效率低）
- 不要在状态差时硬写（浪费时间）
- 不要频繁看数据（影响心态）
- 不要和读者长时间互动（浪费时间）
```
