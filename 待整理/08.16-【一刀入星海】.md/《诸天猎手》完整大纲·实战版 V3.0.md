## 【第零步】一句话前提（Logline）

```
一名古代猎人穿越时激活"猎手空间"（主角身份），
为了在失去全部人性前带儿子回家（核心目标），
必须穿越四个世界猎杀最强者才能解锁回归通道（最大阻碍），
但每个世界都会让他失去一部分人性，最终必须在"成为诸天主宰"与"保留最后人性"之间选择（不可逆代价）。
```

**检查：**

- ✅ 10秒心动：诸天流+父子情+人性代价
- ✅ 明确冲突：猎杀vs人性流失
- ✅ 独特元素：认知盲区猎杀+四世界结构

## 【第一步】商业化包装

### 1.1 书名

 **《诸天猎手：我用陷阱猎杀万界强者》**

（关键词：诸天=热门赛道，猎手=核心身份，陷阱=差异化方法）

### 1.2 标签选择

- **主标签**：诸天 + 系统流
- **爽点标签**：扮猪吃虎 + 智斗
- **钩子标签**：硬核 + 复仇

### 1.3 简介（300字）

```
【困境】
古代猎人陈山穿越到2247年，发现儿子被星际战士囚禁，即将被改造成猎物。

【金手指】
他激活了"猎手空间"——只要猎杀每个世界的最强者，就能进入下一个世界。
第一世界，他用陷阱猎杀星际战士。
第二世界，他用星际装备猎杀虫族女王。
第三世界，他用虫族基因猎杀机械泰坦。
第四世界，他用所有战利品猎杀神族至高。

【爽点预告+代价】
当他站在多元宇宙之巅，所有强者才明白——
真正的猎手，从不依赖科技，只依赖智慧。

但他不知道，每猎杀一个世界，他都在失去作为"人"的东西。
当儿子哭着说"你不是我爸爸"时，他才发现——
自己已经变成了比猎物更可怕的怪物。

最终，他必须选择：继续猎杀成为诸天主宰，还是停下保留最后的人性？
```

## 【第二步】金手指设计

### 2.1 金手指四要素

|要素|内容|
| ------| ------------------------------------------------------------------------------------------------------------|
|**获取方式**|穿越时，陈山的刀（有八个缺口）吸收虎血，激活"猎手空间"|
|**核心能力**|①世界穿梭（猎杀最强者解锁下一世界）②战利品保留（每世界带走一件）③认知盲区猎杀（看穿对手依赖系统的盲区）|
|**升级路径**|每个世界解锁一个缺口，获得一件战利品，实力叠加：陷阱→装备→基因→AI→？|
|**代价机制**|每个世界失去一部分人性：敬畏→同情→恐惧→自我，最终必须选择停止或继续|

奖励：解锁缺口2，选择一件战利品
失败惩罚：永远困在当前世界

## 【第四步】世界观核心设定

### 4.1 四个世界背景

|世界|时间线|核心冲突|科技等级|
| -----------------| ------------| ----------------------| ------------------|
|世界1：星猎族|2247年地球|星猎族猎杀人类强者|中级（星际文明）|
|世界2：虫族|未知星球|虫族占领，人类幸存者|低级（生物科技）|
|世界3：机甲废土|未来地球|机甲失控，人类躲地下|高级（AI文明）|
|世界4：神族战场|高维空间|神族收割低维文明|超级（维度文明）|

### 4.2 猎手空间规则

**能做什么：**

- 穿越世界（猎杀最强者后）
- 保留战利品（每世界一件）
- 带儿子同行（自动跟随）

**不能做什么：**

- 不能跳过世界
- 不能带走"人"（除儿子）
- 不能拒绝任务（拒绝=困死）

**代价：**

- 每个世界失去一部分人性
- 最终必须选择：继续（失去全部人性）或停止（保留最后人性）

### 4.3 核心词条

```
- 猎手空间：穿越多世界的系统，由陈山的刀激活
- 认知盲区：依赖某种系统导致的感知死角
- 星猎族：原创外星种族，按"荣耀法典"猎杀强者
- 培养舱：改造人类幼崽的装置
- 骨哨：陈山给儿子做的虎骨哨子
```

## 【第九步】避坑清单

|错误|后果|解法|
| ------------------| --------------| ------------------------------------------|
|诸天流变成流水账|读者疲劳|每个世界必须有独立主题和情感高潮|
|战利品无限叠加|战力崩溃|每个世界只能带一件，且有使用限制|
|儿子成工具人|情感线断裂|每个世界必须有父子互动章节|
|人性流失不可视化|读者感受不到|每25章必须有具体行为展示|
|四个世界重复|读者腻|每个世界的敌人类型/战斗方式/场景必须不同|
|最终选择铺垫不足|结局突兀|从第1章开始埋伏笔，每个世界强化一次|
