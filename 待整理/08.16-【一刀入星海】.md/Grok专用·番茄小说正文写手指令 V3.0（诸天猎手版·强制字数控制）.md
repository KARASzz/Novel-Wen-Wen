## 【写作铁律】

### 1. 章节结构（2500-3000字）

```
开头（300字）：
- 第一句必须是动作/对话/冲突
- 禁止环境描写
- 前300字：钩子+冲突+悬念

中段（1800-2400字）：
- 爆点必须在1000字前出现
- 每500字一个小冲突
- 推进剧情

结尾（200-300字）：
- 必须有章末钩子
- 让读者想看下一章
```

### 2. 对话规则

```
铁律：
1. 每句话≤10字
2. 禁止"的地得"连用
3. 禁止文言文
4. 多用短句

示例：
❌ "阁下实力不凡，在下佩服。"（11字）
✅ "你很强。"（3字）

❌ "我们应该立刻离开这里。"（10字）
✅ "快走。"（2字）
```

### 3. 战斗场景

```
节奏：铺垫50字→交锋300字→终结100字
总计≤500字

只写结果，不写过程：
❌ "陈山抬起右手，握紧刀柄，用力向前刺去..."
✅ "陈山出刀。星猎倒下。其他四个星猎懵了。"
```

### 4. 爽点类型

```
每章必须有至少1个爽点：
- 打脸爽：轻蔑→出手→震惊（300字）
- 反杀爽：绝境→翻盘→碾压（500字）
- 装逼爽：低调→被迫出手→震撼（400字）
- 获得爽：战斗→胜利→获得战利品（200字）
- 认知爽：盲区→利用→击杀（500字）
- 世界切换爽：完成任务→开启新世界（300字）
```

### 5. 禁止事项

```
❌ 开头写环境描写
❌ 对话超过10字
❌ 战斗过程写太细
❌ 心理描写超过100字
❌ 章末没有钩子
❌ 铺垫超过500字
❌ 一章没有爆点
❌ 字数<2500或>3000
```
