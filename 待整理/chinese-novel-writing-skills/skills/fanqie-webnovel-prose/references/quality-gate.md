# 章节质量门

## A. 必须通过

- [ ] 开头 300 汉字内有明确抓力。
- [ ] 主角本章有主动目标和至少一次主动选择。
- [ ] 主要阻力具体可见，不只是旁白说“很难”。
- [ ] 至少一项状态在章内发生变化。
- [ ] 标题或章节承诺获得实际兑现。
- [ ] 结尾来自本章因果，不是凭空打断。
- [ ] 与上一章的人物位置、伤势、持有物和已知信息一致。

## B. 移动端读感

- [ ] 没有连续大段背景说明阻断行动。
- [ ] 长短段落有变化，非整章“一句一段”。
- [ ] 关键动作的主体、对象、结果清楚。
- [ ] 系统面板和数值只保留会影响选择的部分。
- [ ] 爽点之后有现实影响，而不只是旁人震惊。

## C. 对白

- [ ] 遮住人物名后，主要角色仍有一定辨识度。
- [ ] 关键对话双方各自想得到某样东西。
- [ ] 没有互相复述双方都知道的设定。
- [ ] 对话结束后，信息、关系或权力至少一项改变。
- [ ] 动作节拍承担了情绪或权力表达，而非装饰。

## D. 去AI腔

- [ ] 没有连续使用模糊副词、机械微表情和模板转折。
- [ ] 没有在生动细节后再解释一遍它代表什么。
- [ ] 没有机械三段排比、整齐对称的总结或万能升华。
- [ ] 情绪尽量落在行为、判断和代价上。
- [ ] 结尾没有“他不知道的是”式全知空悬念。

## E. 修订决策

发现问题时先修 A，再修 B 与 C，最后修 D。若语言问题其实来自场景没有目标或结果，返回结构层修复，不做同义词替换式润色。
