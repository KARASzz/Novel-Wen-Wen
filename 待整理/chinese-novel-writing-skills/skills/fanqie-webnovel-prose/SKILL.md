# 番茄网文正文

把已有设定和章节大纲转成可直接连载的中文网文正文。优先保证读者能迅速看懂人物此刻要什么、阻力是什么、这一章改变了什么，再追求辞藻。

## 与其他技能的分工

- 需要新建项目、总纲或卷纲时，先用故事初始化或情节结构技能。
- 需要核对人物档案、世界规则时，先读取相应项目文件。
- 本技能负责正文落地与章级质检，不擅自重做全书结构。
- 若项目已有 `chapter-writing` 工作流，沿用它的文件命名、状态更新和连续性记录；本技能作为中文网文正文层。

## 开始前读取

按可用性读取，不因缺少非关键材料而停工：

1. 本章大纲、目标字数、视角与预期结尾。
2. 上一章正文，至少读取结尾 800 至 1500 字。
3. 故事总纲、当前卷纲、人物卡、力量体系。
4. 连续性记录：时间、地点、伤势、物品、已知信息、未兑现伏笔。

信息不足时采用最小假设，并避免新增会改变主线的大设定。需要具体风格规则时读取 [references/prose-guide.md](references/prose-guide.md)；交稿前读取 [references/quality-gate.md](references/quality-gate.md)。

## 正文工作流

### 1. 固定本章承诺

动笔前在内部明确五件事：

- 主角本章眼前目标。
- 阻止目标的具体人、规则或代价。
- 读者本章期待看到的兑现。
- 结尾必须发生的状态变化。
- 下一章钩子属于新信息、新选择还是新后果。

若大纲只有事件清单，把事件改写成“因为—所以—但是”的因果链，避免流水账。

### 2. 设计开场抓力

- 开头 300 个汉字内出现异常、冲突、损失风险或迫切欲望中的至少一项。
- 承接上一章遗留动作，不用大段回顾重新热场。
- 首屏优先出现人物行动与具体对象，少用世界观说明和空泛感慨。
- 黄金三章每章都给出可感知回报：能力展示、资源到账、身份变化、秘密确认或危机反转。

### 3. 分场写作

每个场景使用以下循环：

1. 角色采取可见行动。
2. 外界给出阻力或意外反馈。
3. 角色获得新信息并作出选择。
4. 局面发生不可忽略的小变化。

场景只在目标、地点、时间或权力关系明显变化时切换。转场用动作、结果或新问题衔接，不写总结式过渡。

### 4. 控制爽点与信息

- 爽点必须由前置压迫、能力限制和角色选择共同换来，不能只靠围观者惊叹。
- 每次展示能力都带来结果或代价；系统面板只呈现本次变化相关字段。
- 先让读者看见问题，再给规则解释；解释尽量嵌入行动、交易、争执或失败。
- 大爽点前可短暂压缩节奏，大爽点后用一两个具体反应确认影响，随后立刻进入新问题。
- 同一章至少改变一项状态：资源、关系、认知、位置、伤势、身份或任务。

### 5. 写对白

- 每场关键对话中，双方都要有不能直接说出的目的。
- 台词同时承担至少两项功能：推进事件、显露性格、改变关系、制造压力、埋下信息。
- 不让角色互相解释双方都知道的常识。
- 用词、句长、回避方式和攻击方式区分人物，不靠口癖堆砌。
- 动作节拍优先于密集的“说道、问道、冷笑道”；动作必须反映选择或权力变化。

### 6. 收束章末

结尾必须落在一个已经发生的变化上，并打开下一步：

- 新信息推翻旧判断；
- 主角作出有代价的选择；
- 刚获得的回报暴露更大用途；
- 本章行动引发立刻可见的后果。

避免只用敲门、电话响起、黑影出现或“他不知道的是”制造空钩子。悬念应建立在读者已经理解的利害关系上。

## 修订顺序

按顺序修订，避免一边改句子一边推翻结构：

1. **连续性**：人、时、地、伤势、物品、能力限制是否一致。
2. **因果**：每个重要结果是否来自前一动作或已建立规则。
3. **兑现**：标题、本章承诺和读者等待的场面是否真正出现。
4. **节奏**：删除重复说明，拆开手机端过长段落，保留必要停顿。
5. **对白**：检查人物声线、潜台词、权力变化和信息倾倒。
6. **语言**：处理套话、抽象情绪、机械排比和重复连接词。
7. **钩子**：确认结尾既完成本章，又迫使读者关心下一步。

需要量化信号时运行：

```powershell
python scripts/check_prose.py path/to/chapter.md
```

脚本只提供风险信号，不以词频代替创作判断。对每一处命中结合语境决定保留或修改。

## 输出要求

- 用户要正文时，直接交付正文，不先输出长篇方法说明。
- 保持既定人称、视角、时态、专名、能力规则和人物关系。
- 默认采用适合手机阅读的短中段落，但避免每句话都单独成段。
- 不在正文里插入写作分析、括号备注、TODO、质量评分或作者解释。
- 用户要求润色时保留情节事实与人物动机；发现结构问题先指出影响，再做最小改动。
- 不模仿在世作者的独特文风；改用可描述的高层特征，如快节奏、冷峻、口语化或强悬念。

## 最低交付门槛

交稿前必须能回答：

- 开头 300 字的抓力是什么？
- 主角做了哪个主动选择？
- 本章兑现了什么，而不只是承诺了什么？
- 至少哪一项状态发生了变化？
- 章末为什么让读者在意下一章？

任一项答不出来，先补齐再交稿。
