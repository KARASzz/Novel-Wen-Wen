# 中文小说人物对白

让每场对话同时承载欲望、阻力、人物声音和关系变化。对白不是现实录音，而是经过压缩、读起来像自然说话的行动。

## 先确定任务模式

- **创作**：根据场景目标和人物资料直接写可用对白。
- **重写**：保留事实、结果和人物立场，只修改失真的台词及必要动作节拍。
- **诊断**：指出声线、潜台词、信息、节奏和权力问题；用户未要求时不重写。

若用户明确要成稿，直接交付对白场景，不先写长篇理论。

## 开始前读取

按可用性读取，不因缺少非关键材料停工：

1. 场景前因、地点、在场人物和必须发生的结果。
2. 人物卡、关系史、已知信息和不能说出口的事。
3. 上一段正文与后续衔接。
4. 风格样本、视角、人称和标点规范。

需要建立或区分人物声线时读取 [voice-and-subtext.md](references/voice-and-subtext.md)。需要量化候选信号时运行 `scripts/check_dialogue_zh.py`；脚本不替代语境判断。

## 对话契约

动笔前在内部锁定每个主要人物的四项：

- **明面目标**：此刻公开想得到什么。
- **隐藏目标**：真正想确认、逼迫、掩盖或换取什么。
- **筹码与风险**：能施加什么压力，最怕暴露或失去什么。
- **底线**：绝不会直接承认或绝不会主动谈起什么。

再锁定场景结束时必须变化的一项：信息、选择、关系、权力或行动方向。

## 写作循环

每轮交锋使用“动作—反应—调整”，但不要机械三段式：

1. 一方用台词或行动试探、索取、回避或施压。
2. 对方按自己的目标回应，可以误解、撒谎、打断、转移或拒绝。
3. 新信息或权力变化迫使至少一方调整策略。
4. 在最有压力的位置结束交流，不把潜台词解释完。

争执需要递进时，从以下阶梯选择必要层级：试探 → 施压 → 拒绝 → 揭短/亮筹码 → 不可撤回的决定。不要为了热闹把每场对话都推到最高级。

## 人物声音

用选择方式区分人物，不只靠口头禅：

- 句长和完整度；
- 直接、绕弯、反问、沉默或抢话的倾向；
- 更相信规则、利益、感情、身份还是经验；
- 面对压力时攻击、讨好、讲理、装傻或撤退；
- 常用词域、称呼方式以及刻意避开的词。

遮住人物名后，重要人物仍应有一定辨识度，但不要把每句都写成声线展示。

## 中文自然度

- 允许省略、半句、改口、接不上话和答非所问，但必须符合情境。
- 紧张时通常缩短表达；掌权者也可能故意说得慢而完整。
- 不让人物互相解释双方都知道的常识；让信息从冲突、误判或发现中出现。
- 不用随机“嗯、那个、就是说”制造人味，不给所有角色统一塞网络热梗、粗口或方言。
- 避免成簇出现“淡淡地说、冷冷地说、声音不大却、不容置疑、嘴角微微上扬”。
- 沿用项目既定引号和段落格式，不擅自统一成另一套标点。

## 动作节拍

动作必须承担至少一个功能：改变距离、控制物件、暴露犹豫、争夺话语权或造成实际后果。删除只为替换“他说”的装饰动作。

连续交流在说话者清楚时可省略标签；身份可能混淆时优先使用简洁标签。不要让每句台词后都跟一个微表情。

## 重写顺序

1. 保留必须传递的事实和场景结果。
2. 删除共同常识、复述和旁白解释。
3. 为双方补足不同目标与策略。
4. 区分声音，调整打断、停顿和动作节拍。
5. 检查结尾是否产生变化，而非只把信息说完。

默认做最小充分修改。若问题来自人物动机或场景结构，说明原因并交回对应技能，不靠增加俏皮话掩盖。

## 质量门

交付前确认：

- 双方各自想得到某样东西，而非一人提问一人讲解。
- 至少一半关键台词同时承担两项功能：推进、塑造、施压、改变关系或埋置信息。
- 有可感知的“所说”与“所想/所求”差距，但不是每句话都故弄玄虚。
- 对话结束后，信息、选择、关系、权力或行动方向至少一项改变。
- 动作节拍属于这些人物和这个地点，而非可粘贴到任何场景。
- 没有替读者总结潜台词。

## 与小说技能套件的边界

- `character-management`：建立人物身份、关系和长期声线档案。
- `character-arc`：处理对白背后的信念变化。
- `scene-sequencing`：修复场景目标和节奏结构。
- `chapter-writing` / `fanqie-webnovel-prose`：把对白嵌入完整章节。
- `fiction-humanizer-zh`：明确点名后做成稿末轮去 AI，不重新设计对话目标。
