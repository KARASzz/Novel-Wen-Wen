# 人物声线与潜台词工作表

## 声线卡

为重要人物记录下列项目；只选真正影响台词的内容：

| 维度 | 可选方向 |
|---|---|
| 句长 | 短促、均衡、长句绕弯、先长后短 |
| 完整度 | 完整句、省略多、常改口、常被打断 |
| 直接度 | 直说、暗示、反问、讲故事、沉默施压 |
| 证据偏好 | 规则、利益、感情、身份、经验、直觉 |
| 压力反应 | 攻击、讲理、讨好、装傻、转移、撤退 |
| 称呼系统 | 名字、姓氏、职务、亲属称谓、故意不用称呼 |
| 词域 | 职业词、地域表达、年代用语、受教育程度 |
| 禁区 | 不承认的欲望、不提的人、不能暴露的知识 |

口头禅最多作为低频信号。真正的声音来自角色如何选择证据、如何回避以及压力下先保护什么。

## 场景对话卡

写作前用一句话填写：

- A 表面要：
- A 实际要：
- A 筹码 / 风险：
- B 表面要：
- B 实际要：
- B 筹码 / 风险：
- 双方共同知道：
- 双方认知差：
- 结束后的变化：

共同知道的内容不得用问答重新讲一遍。需要告诉读者时，让角色在争议、误判、隐瞒或实际后果中暴露它。

## 潜台词手段

- **替代话题**：谈天气、工作或物件，实际谈关系和信任。
- **错误答案**：回答字面问题，却躲开真正问题。
- **条件交换**：用信息换承诺、行动或沉默。
- **称呼变化**：职务变名字、昵称变全名，表示距离改变。
- **重复变义**：复用早先一句话，让关系变化赋予新含义。
- **第三对象**：借评价别人表达对眼前人的判断。
- **沉默与未完成**：只在沉默造成压力或选择时使用。

潜台词不是把每句话写成谜语。角色在安全、亲密或已无退路时可以直说。

## 冲突递进

1. **试探**：确认对方知道多少、愿意让多少。
2. **施压**：缩小退路，提醒代价或亮出部分筹码。
3. **拒绝**：不接受对方框架，改变话题或行动。
4. **揭短**：点破矛盾、旧账或隐藏动机。
5. **不可撤回**：说出或做出会永久改变关系的事。

递进来自策略和代价变化，不来自音量不断增大。

## 中文对白常见失真

- 每个人都说书面、完整、逻辑严密的长句。
- 为读者安排“提问型工具人”。
- 每句都能独立做金句，没人说普通但有目的的话。
- 角色用同样的网络词、骂法、比喻和反问。
- 用“冷笑、淡淡、微微、缓缓”替代真实权力变化。
- 台词后旁白立即解释“他其实是在试探她”。
- 所有人都按轮次发言，没人抢话、忽略、误读或退出。

## 类型调整

- **悬疑**：控制谁知道什么；误导必须符合人物利益，线索不能只靠故意不说。
- **言情**：关系推进来自试探、边界和选择，不靠误会无限拖延。
- **权谋**：每句话对应筹码、身份和可追责后果，避免人人都说玄虚谜语。
- **喜剧**：笑点来自人物逻辑碰撞和时机，不靠全员抖机灵。
- **爽文**：压迫和反击都要改变现实；围观者不轮流替读者喊震惊。
- **生活流**：允许闲话，但闲话需暴露关系、习惯或未说出口的压力。

## 改写保护

- 保留事实、立场、关系结果和信息差。
- 保留符合角色的笨拙、重复、方言和不完整表达。
- 不为了“自然”随意加粗口、口癖、停顿词或网络梗。
- 不把所有台词都改短；长句可能是职业习惯、控制策略或情绪失控。
- 不模仿在世作者的独特句式；使用可描述的高层特征。
