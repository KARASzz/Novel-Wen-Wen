## 【开工前必读】这份大纲怎么用？

**三条铁律：**

1. **先填第零步到第三步，再动笔写正文** —— 这四步没搞定，后面全是坑
2. **世界观别写太细** —— 只写影响主线的核心设定,其他边写边补
3. **每填完一个模块，问自己：这个设定能产生冲突吗？**  —— 不能产生冲突的设定=废话

**示例项目说明：**   
全文会用《星痕觉醒》这个虚拟项目做示例。你可以直接套用这个结构，把内容换成你自己的。

## 【第零步】一句话前提（Logline）——命根子

**公式：主角身份 + 核心目标 + 最大阻碍 + 独特科幻元素 + 不可逆代价**

### 示例填空：

```
【项目：星痕觉醒】
一名被植入违禁AI芯片的废品回收工（主角身份），
为了找到杀死妹妹的真凶并阻止人类记忆被集体抹除（核心目标），
必须潜入三大星际财阀的数据核心（最大阻碍），
但每次神经入侵都会让他的人类记忆被芯片AI逐步覆盖（不可逆代价）。
```

### 你的项目填空：

```
【你的书名：___________】
一名_________（主角身份），
为了_________（核心目标），
必须_________（最大阻碍），
但每次_________都会_________（不可逆代价）。
```

**检查标准：**

- ✅ 这句话能让陌生人在10秒内心动吗？
- ✅ 有明确的冲突和代价吗？
- ✅ 科幻元素够独特吗？（不是"穿越""重生"这种烂大街的）

写不出这句话，**停，别往下走**。

## 【第二步】金手指设计——网文的命根子

### 2.1 金手指四要素

|要素|说明|示例（星痕觉醒）|
| ------| --------------------------------------| --------------------------------------|
|**获取方式**|够惨够意外，不能是"系统自动绑定"|妹妹死后，林墨被强制植入违禁芯片|
|**核心能力**|一句话说清，越具体越好|能入侵任何数字系统，读取/篡改数据|
|**升级路径**|数据化、可视化，读者要看到进度条在涨|芯片等级1-9阶，每阶解锁新入侵权限|
|**代价机制**|每次使用的不可逆后果，没代价=没张力|每次入侵消耗人类记忆，最终会被AI覆盖|

### 2.2 你的金手指填空

```
【获取方式】___________
【核心能力】___________（一句话）
【升级路径】___________（数据化）
【代价机制】___________（不可逆）
```

### 2.3 金手指禁区（碰了直接扑街）

-❌ 万能系统（什么都能干=什么都不爽）

- ❌ 无代价外挂（读者看三章就腻）
- ❌ 升级路径不清晰（读者不知道主角变强了多少）
- ❌ 能力描述太抽象（"掌控命运"这种鬼话）

## 【第三步】黄金三章拆解——生死线

**铁律：前三章写不好，后面一百万字都是白扯。**

### 第一章：钩子 + 困境 + 预兆（3000-4000字）

**任务清单：**

- [ ] 前500字：强画面钩子（爆炸/追杀/死亡/冲突）
- [ ] 1000字内：主角身份 + 当前困境（够惨）
- [ ] 2000字：世界观核心设定投放（别超过3个专有名词）
- [ ] 章末：金手指触发预兆（意外事件/绝境时刻）

**示例（星痕觉醒·第一章）：**

```
开头500字：林墨在废品站被财阀执法队追杀，妹妹为救他被当场"记忆清洗"
1000字：交代身份（废品回收工）、世界观（三大财阀统治）、困境（妹妹变成植物人）
2000字：林墨潜入医院想救妹妹，发现她被植入了违禁芯片
章末：妹妹死亡瞬间，芯片自动转移到林墨大脑，他昏迷
```

### 第二章：金手指到账+ 第一次小爽（3000-4000字）

**任务清单：**

- [ ] 金手指能力展示（具体、可视化）
- [ ] 主角第一次使用（小试牛刀）
- [ ] 获得关键信息或小装备
- [ ] 埋下更大悬念（谁杀了妹妹?芯片来历?)

**示例：**

```
林墨醒来，发现脑海里多了AI"星痕"
第一次入侵：黑进医院系统，看到妹妹死亡真相（被财阀做实验）
小爽点：顺手黑了追杀他的执法队长的账户，转走100万星币
章末：星痕告诉他，芯片来自一个"已死的文明"
```

### 第三章：绝境反杀 + 大悬念（3000-4000字）

**任务清单：**

- [ ] 主角陷入绝境（被围/被抓/被追杀）
- [ ] 用金手指完成第一次漂亮反杀
- [ ] 确立主角"扮猪吃虎"人设
- [ ] 章末：抛出全书最大悬念（暗线钩子）

**示例：**

```
财阀派出赏金猎人抓林墨
林墨用芯片入侵猎人的机甲系统，反杀
爽点：当着所有人的面，让猎人的机甲自爆
章末：星痕突然说："你妹妹的死，和'宇宙记忆收割计划'有关。人类文明，只剩300天。"
```

## 【第九步】避坑清单——常见致命错误

|错误|后果|解法|检查方法|
| ----------------| --------------------| --------------------------| --------------------------------|
|科技无代价|悬念归零，读者弃书|每项能力绑定等价牺牲|问自己：用这个能力要付出什么？|
|伏笔烂尾|口碑崩塌|大纲期锁定兑现节点|列出所有伏笔的兑现章节|
|主角是剧情容器|读者无共情|主角必须主动推动改变|问自己：这章是主角推动的吗？|
|世界观百科化|阅读窒息|信息随情节需要分批投放|每章专有名词≤3个|
|设定中途撤回|读者信任崩溃|规则公示后不可更改|建立"设定锁定表"|
