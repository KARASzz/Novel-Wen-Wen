# ⚛️0-《符号之海》初版写作注意事项

1. 先别急着写百万字正文：用“分层大纲 + 里程碑”把崩盘风险前置消灭

- **超详细大纲是防崩神器**​：别只写“暴动 → 对撞 → 肃清”三步走，要把百万字拆成​**3-5个大弧**（每个弧20-40万字），每个大弧有独立高潮 + 结局感，但又推进主线。
  - 示例结构（适合你的设定）：
    - **弧1（前20-30万字）** ：发现/发明技术 → 阶层固化显现 → 底层觉醒（主角从“见证者”到“参与者”）。
    - **弧2（中30-50万字）** ：底层语义黑客崛起 → 小规模暴动/游击 → 官方镇压升级（引入“语义污染”副作用，预埋肃清者）。
    - **弧3（后30-50万字）** ：全面决战 → 时空撕裂 → 肃清者降临（高潮 + 主题升华：人类是否配拥有“命名现实”的权力）。
  - 每个弧结束时要有“阶段性爽点/情感高潮”，让读者觉得“值了”，也给你自己缓冲（写崩一个弧还能重来）。
- **小纲 + 中纲 + 大纲三层法**（很多百万字作者用这个）：
  - 大纲：全书主线、主题、结局（不变的骨架）。
  - 中纲：每10-20万字一个章节群，列出关键事件、人物变化、伏笔回收。
  - 小纲：每3-5万字（约10-15章）写一次，列对话要点、场景、转折、钩子。
  - 每写完一个小纲，就问自己：“这里逻辑通吗？人物动机变了吗？主题深化了吗？如果现在烂尾，这里还能独立成篇吗？”

## 2. 防崩核心技巧（针对你的硬核科幻）

- **设定“防火墙”** ​：把符号之海、语义编码规则写成​**固定文档**（像代码规范），每写到新场景前必查：这个坍缩合理吗？有没有自相矛盾？（硬科幻最怕后期“设定崩”）。
- **人物别工具人**：主角/反派/关键配角要有独立弧光，别全为剧情服务。底层主角可以从“愤怒 → 迷茫 → 领悟权力腐蚀”转变；精英可以有“理想主义崩坏”的悲剧感。后期崩多因人物突然变傻/变圣母。
- **节奏控制**：别前期太爽后期水。常见比例：前30%铺世界+冲突，中40%层层升级+副线，后30%高潮+收束。你的设定适合“每10万字一个大概念炸弹”（新语义应用、新副作用、肃清者线索）。
- **伏笔闭环**：列个“伏笔表”（Excel或Notion）：发明时埋的“暗能量副作用”、底层口号的“集体语义隐患”、主角的“个人创伤”，后期必须一一回收。起点读者最恨“挖坑不填”。
- **主题别飘**：你的核心是“语言即权力/现实的原罪”，每弧结束都要强化一次，别后期突然变成“人类团结打外星人”这种俗套。
- **字数规划**：目标百万，别一下冲。日更4000-6000字稳节奏，先冲30-50万字看数据/自我审视，再决定是否继续。
