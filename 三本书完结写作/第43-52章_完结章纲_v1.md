## 逐章五拍纲

### 第43章 屏幕外的战争

1. **承接**：直播画面在姜渡坠入黑雾后全黑，系统把信号标成失联；控制室里有人要按流程公布失败概率，龙国参谋组和国际观察员各自承受城市级灾难风险。
2. **压力**：沈棠不把“失联”当“死亡”。她调出坠落前后的声纹、节拍和气压杂音，找出黑屏里仍有与列车同步的金属回响；证据有限，不能宣称姜渡肯定活着。
3. **选择**：有人要求停止直播避免扩大恐慌，沈棠坚持保留原始信号，指出关闭记录会让其他国家失去最后的客观依据。她主动把自己对姜渡的偏见和期待排除在判断之外，只报能核验的波形变化。
4. **升级**：各国观察员看见副本的失败警告仍在倒数，城灾预警开始联动；沈棠用列车速度与回响间隔推算出一个移动声源正在追近列车，但她没有办法把分析传给姜渡。
5. **钩子**：黑屏中的绿灯忽然亮起，扬声器传出一串逆风声与金属刮擦。沈棠把手按在控制台上：“把全程录下来。”屏幕边缘出现一条由远及近的白色信号线。

### 第44章 终结者归来

1. **承接**：白色信号线沿着列车方向移动；车厢内幸存者只看见黑窗和肉壁，杰森假装受惊，山本一郎避开他的目光。
2. **追车**：从姜渡视角写他落到站台后先确认自己没摔坏枕头，随后发现列车跑远、站台脏乱且广播仍吵。他沿墙面和检修通道追车，动作夸张但路径清楚，身体没有新增重伤。
3. **回车**：列车重新加速，姜渡从车窗外赶上，撞开一扇玻璃回到车厢。玻璃碎片落地，乘客因此有真实危险；他把碎片拨到一边、拍掉衣服上的灰，动作延续既有的嫌脏与讲究。
4. **反应**：全球直播恢复，沈棠确认他归来但不替他解释；伊万诺夫从惊讶转成警惕，山本确认姜渡确实没有死，杰森无法再装成目击者。
5. **钩子**：姜渡看着杰森，问“你刚才……推了我？”杰森嘴唇动了动，没能马上说出答案；车顶坏掉的红灯闪了一次。

### 第45章 推你的人

1. **对质**：杰森先说自己只是在混乱里扶人，随后改口称姜渡自己跌出去；他的说法前后矛盾。姜渡不以暴怒替代判断，只指出他坠落前身体已经远离人群，不可能是“被挤”出去。
2. **证词**：山本承认自己看见杰森伸手推人，也承认自己为了少一个对手而选择沉默。他不求谅解，只把所见时间、位置、动作写在车票背面并对准直播镜头。
3. **立场**：伊万诺夫拒绝替姜渡动手，挡在杰森与其他乘客之间，要求把证据留给所有直播观众。姜渡收回抬起的手，明确表示等回到现实再算责任。
4. **后果**：系统红灯因同时收到相互矛盾的声音判定而反复闪烁，旧规则仍有危险；车厢地板再次蠕动，广播宣布即将经过岔道，乘客必须先确认站点。
5. **钩子**：小熊枕头从座位底下滚出来，枕套里露出一角硬纸卡。姜渡弯腰捡起，手指摸到一张被汗浸软的车票。

### 第46章 枕头里的车票

1. **票面**：姜渡把车票抽出来，票面清楚写着“人间站”；他终于承认自己之前没有看过。几名幸存者也检查各自车票，目的站彼此不同，都是各自回到现实的唯一站点。
2. **歧路**：车内电子屏、广播与窗外站牌开始给出不同站名，甚至把乘客姓名贴到错误车门。众人意识到站名和提示可以是诱饵，但票面没有变化。
3. **核验**：沈棠在屏幕外看见车票的近景，确认票面和直播规则一致；她只把观察留给指挥组，不向车内发送凭空可得的提示。山本用票面字形、车厢号和已过站次核对列车路线。
4. **行动**：姜渡把自己票面朝外夹在枕头套上，不再把它塞回去；乘客按各自票面整理出可见的次序，但不能在行驶中跨车厢换位。伊万诺夫的票写“北境站”，山本的写“樱岛站”，杰森的写“联邦站”。
5. **钩子**：前方白光亮起，广播报“北境站”；窗户倒影里却同时出现一块“黄泉”站牌。伊万诺夫闭上眼，开始默数五秒。

### 第47章 北境站不卖酒

1. **规则压力**：列车停靠前，车窗倒影里的“黄泉站”不断向乘客招手；站台实际灯牌看似北境站。伊万诺夫的票正对北境站，不能让错站的影像改变下车判断。
2. **验证**：伊万诺夫按规则闭眼五秒，姜渡也照做；其他乘客通过车票触感和站台广播的停顿位置交叉核验，没有任何人靠跨车厢或触碰倒影来试错。
3. **协作**：站门被活体车厢半堵住，乘客恐慌推挤。姜渡只把门保持在可通行宽度，伊万诺夫带领自己的同胞按票依次下车，禁止他们抢跑。
4. **离别**：北境站与票面一致，伊万诺夫安全离车。临走前他把酒壶放在座位上当作给姜渡的谢礼，又收回去，改成重重拍了一下车厢外壳，免得瓶子成为车内诱饵。
5. **钩子**：列车启动，伊万诺夫在站台上举起拳头；车窗里一排倒影却没有跟着举拳，反而齐刷刷指向山本的座位。

### 第48章 樱岛站，证词先行

1. **承接**：山本意识到自己面前的倒影在模仿他，却晚了半拍。他闭眼默数五秒，睁开后把手从刀柄上移开，避免被恐惧牵着走。
2. **责任**：杰森低声暗示山本只要改口就能把责任推回姜渡；山本拒绝。他将证词对准全球直播镜头复述一遍，承认自己看见推搡却没阻止，必须面对这份沉默的后果。
3. **站点**：广播说“樱岛站已过”，票面和车门标记却显示列车仍在樱岛站。众人回到已验证的优先级：先认自己的车票，再看可被伪造的站牌与广播。
4. **离车**：山本按票下车。他把金丝眼镜摘下来擦净，再戴回去，向姜渡鞠躬但不求原谅；他将在现实接受调查并提交原始记录。
5. **钩子**：车门关闭后，电子屏上“联邦站”出现又被红线划掉，换成“黄泉”。杰森抓紧了自己的车票。

### 第49章 自己的车票

1. **联邦站**：系统用一段姜渡坠车画面诱使乘客相信联邦站已经过去；杰森急于下车，想趁混乱离开直播视线。
2. **证据**：沈棠让外界团队把原始视频、山本的现场证词和车内时间码分开保存。她不替任何国家宣布裁决，只确认直播已记录杰森的手碰到姜渡背部、随后姜渡坠落。
3. **错误选择**：杰森试图拿另一名乘客的票冒充自己的票，列车门口的验证器不响应；他抢夺时被同伴制止。姜渡不替系统杀人，只把人和票分开，要求杰森按自己的票作选择。
4. **下车**：联邦站真正亮起，杰森的票与站点吻合。他被迫下车，直播画面同步切到现实接应区，等待他的不是胜利欢呼，而是针对推人和作伪证的正式调查。
5. **钩子**：杰森离开后，车厢里只剩姜渡与少数持“人间站”等后续站点车票的乘客。路线屏上的人间站被整块涂黑，列车却开始减速。

### 第50章 人间站被删了

1. **矛盾**：姜渡的票仍写“人间站”，电子屏和广播却都说下一站是黄泉。有人准备下车逃命，姜渡把票举到灯下，提醒众人黄泉是唯一明确禁止下车的终点。
2. **找路**：幸存者沿车厢内壁摸到被腐肉盖住的线路图，发现线路图上有一段被撕去，但纸纤维留下“人间站”的压痕。车票、撕口和站间节拍能互相对上。
3. **外界对应**：沈棠看见直播镜头扫过线路图，复核地图压痕与前几站间隔；她把可确认的事实汇报给联合观察席，不向读者虚构精确的城市灾害数字。
4. **坚持**：广播不断叫乘客“立刻下车”，车窗倒影中出现熟悉的亲友；乘客按第三条规则闭眼五秒，没有人踏上黄泉站台。姜渡把枕头压在车门前，挡住渗入车厢的苍白手指。
5. **钩子**：列车心跳突然停止一拍，随后全部灯光熄灭。姜渡票上的“人间站”三个字在黑暗里反出微弱白光。

### 第51章 把列车停下来

1. **抵达**：车窗外出现真实人间站的站台标记，车票上的字与站台边缘压印完全吻合。列车却没有按时开门，肉壁开始合拢，试图把最后几名乘客留到黄泉。
2. **按规矩行动**：乘客没有在行驶中跨车厢；列车完全停稳后，他们才按各自票面排到对应车门。没有票面相符者不被允许抢先下车。
3. **开门**：姜渡用身体和双手撑住即将闭合的门，力量只作用在门框，不伤及乘客；其他人逐个把票递到验证器上，乘客一个接一个离车。
4. **最后一人**：确认剩余活着的参赛者都已下车，姜渡才折回停稳的前车厢，沿着广播声找到被血肉包裹的播报核心／牵引节点。系统以黄泉规则恐吓，他只按住那块仍在跳动的核心，将其从线路上拔出并摔碎。
5. **钩子**：车灯全部熄灭，直播画面第一次不再出现红色警告。姜渡走下空站台，回头看见列车连同黄泉站牌一起塌成一堆安静的废铁和灰烬。

### 第52章 世界安静以后

1. **收束信号**：控制室收到参赛者返回确认，所有仍存活乘客离开副本；城市级灾难预警停止，全球规则直播窗口关闭。已经失去的人没有被复活，沈棠要求将名单和事故记录保留下来。
2. **公开后果**：联邦国针对杰森的推人和作伪证展开正式调查；山本按承诺提交原始证词并为自己的沉默负责；伊万诺夫在直播中向姜渡举起酒壶。只写已经发生的处分流程，不编造读者数据或平台成绩。
3. **主角落地**：姜渡回到现实，第一反应是问有没有安静房间和干净衣服。沈棠终于见到他本人，但不把他当战利品、神像或研究对象。
4. **关系落点**：沈棠承认自己曾把他的随手动作分析成战术；姜渡承认他就是嫌吵、想睡。两人不许诺夸张关系，只约定下次见面不带直播、不问测试题，先让他睡够。
5. **终章画面**：沈棠把小熊枕头放回床头，关掉屋里的广播和灯。门外最后一块系统屏幕熄灭，屋里只剩姜渡平稳的呼吸声。全书在安静而具体的物件/动作上结束，不出现下一轮副本提示。
