
# 第45章：修船申请全被拒

张霸天是在第二天中午停的船。

他没停边境港。那是最近的大港，上一次靠它的时候他被接待得很隆重，这一次他不想再被接待了。这一次他只想买一个阀、补一块板。

他停的是边境港下游的一个小港，纳塔港。银河边缘的一个小补给点，规模介于能停船和能加油之间。

港里没什么人。泊位上停着三条船，两条是运货的，一条看不出用途。加油桩上挂着牌子，牌子上的数字被涂改过三次，新的压在旧的上面。

他以前路过这里一次。那次他下船买压缩饼干，港口没理他。

他当时觉得没人理挺好。

他把船停在泊位上。停好之后他把翻译器在工作台上摆正，屏幕朝上。他没按灭，也没戴。

虫子在舱门口转了两圈，跟着他下了船。

从泊位到港务处要穿过一段露天的场地。地上有一层薄灰，是别处的船卸货落下的。场子中间堆着几个空箱子，箱子上的标识被雨水泡花了。

他走进港务处。

港务处是一间小屋子，屋里一个柜台，柜台后面坐着一个港务员。纳塔港这种小港，港务员大半是人类，小港付不起银河高级文明的工钱。

港务员手上有活，正在往一本册子上抄东西。抄完最后一行，他抬起头，说：“填表。”

他拿了表。

表是港务处的标准表，六栏：船名、船籍、船型、船长姓名、船长所属单位、本次申请事项。

表是塑封的，边上有一道折痕，折痕那里被翻过很多次，塑封膜起了一层白毛。表格右上角印着一行小字：本表一式两份，第二份留存本港。

他用港务员推过来的一支笔填。

船名：无。

船籍：无。

船型：无。

船长姓名：张霸天。

船长所属单位：他停了一下。他想起太阳系边缘回收站，那是他以前填过的，后来不填了。这一次他也不填。他写：无。

本次申请事项：二号能源管线老化、舱门密封条需更换。

虫子蹲在屋门口，前爪搭在门槛上，往里看。它没有进来。

港务员接过表，一栏一栏看。看到第一栏，他抬了一次头。看到第三栏，他抬头看了两秒。

“你没船名。”

“我没有正式船名。”

“船籍也是空的。”

“船是我自己改的。”张霸天说，“我也不知道它算什么船型。”

港务员把表放下：“你等等。”

他拿起内部通讯器：“港长，这边来了一位，船名、船籍、船型都填无的，说要修二号能源管线和舱门密封条。”

通讯器那头顿了一下：“让他等一下，我查一下系统。”

港务处只有一把椅子，是港务员自己坐的那把。他搬了一把塑料椅出来，红色的，看着有年头，坐上去会响。

张霸天坐下。

他把表在膝盖上放平，又拿起来看了一眼。第六栏那几个字是他自己写的，写得不好看：二号能源管线老化、舱门密封条需更换。

柜台后面的墙上贴着一张海报，银河公共航道管理局发的。画面上一条很漂亮的船，船身上八个字：安全航行，快乐回家。

他看着这八个字看了一会儿。

这八个字跟他没关系。

港长来了。

港长是个中年男人，手里拿着一份打印件，是刚才去查系统带回来的。他在张霸天面前坐下。

“先生，您填的表。”港长停了一下，“系统提示，您的船载终端信号不匹配。”

“什么意思？”

“我们这种小港的港务系统接在银河公共航道系统上。船进港，系统自己读它的终端标识，读完那一栏就能填。这一栏填不出来。”

张霸天看着那张打印件。打印件上他填的那几行字都认得，港口那一栏是空的。

“空的？”

“不是空，是显示不出来。”港长把打印件转过来，指着系统回传的那一行，“系统提示：本标识对应等级，不显示。本港看到的就这一句。”

“那是不能修，还是不能填？”

“都不能。”港长说，“按港务条例第三十二条，系统识别不出等级的维修申请，本港不予受理。”

张霸天伸手把柜台上的笔拿了过来。

他在第三栏“船型”那三个无上面划了一道，把“自改货船”四个字填了进去。填完把表往柜台里侧推。

港务员拿起表，对着柜台后面那台小机器的读口塞进去。机器嗡了一声，吐出一张很窄的纸条。港务员低头看了两秒，摇头，把表退回来。

“还是这句。”他说。

“机器看的是终端。”港长说，“不是看您写什么。”

港长从柜台后面的架子上拿下一本硬壳册子，翻到中间，用两根手指按住一页往下压。册子里的纸边已经发黄，翻页的时候有一股旧纸的味道。

他找到那一段，念了出来：

「第三十二条：维修申请的接收方须能够识别申请对象的船载终端标识。系统显示本标识对应等级为不显示的，申请不予受理。
附则：上述申请本港不转呈其他港。」

念完他把册子合上。

“附则那一行是这一条里最要紧的。”他说，“本港不转呈。刚才我跟您说的所有港都用同一个标识，说的也是这一句。”

张霸天把膝盖上那张表拿起来，摊在两个人中间的桌沿上，指着第六栏。

“字我看得懂。”他说，“表我也填完了。这一栏我写的是二号能源管线老化，舱门密封条要换。我问的不是字，我问你能不能修。”

港长低头看那一栏。

“先生，这两条我们确实没有配件。”

“那你给我个说法。”张霸天说，“是没有，还是不接。”

港长没有拿笔。

“没有。”他说，“小港的管线配件一年进一次，进多少看配额。这一季我们刚领完。”

“那别的港有。”

“有。”

“你们这里配的是什么型号。”

港长看了他一眼：“先生，我们不记型号。配额单上写的是高压管、密封条、垫圈，每样多少件写死在上面。这一季的单子上没有二号能源管线那一类。”

“那我这表往别的港递不行？”

港长还是没拿笔。

“先生，我再说一遍。受理的时候看的是整条船，不是第六栏。”他说，“您这一栏写两样写十样，换成哪一样都一样。”

“我就补一条密封条。”张霸天说，“别的我不修。”

“换成哪一项都一样。”

张霸天把表拿回来。

“那我换个港。”

“接入银河公共航道系统的港，用的也是这个标识。”港长说，“您换港，换不掉这一栏。”

张霸天捏着表角，没起身。

“这句话我听懂了。”他说，“你给我找个能修的地方。”

港长看着那一栏，过了片刻，摇头。

他把那张表抽出来，在下面盖了章。章是红的：本港不予受理。盖完他把表推到张霸天面前。

“先生。”港长停了一下，“您填的那一栏，船长所属单位，是空的。”

张霸天抬头。

“银河文明里，没有船长的所属单位是空的。”

“我知道。”

“您以前填过吗。”

“填过。那时候在太阳系边缘回收站。”

港长愣了一下，没再往下问。

张霸天站起来：“我去别的港试试。”

“先生。”

“什么事？”

“这张表的复印件，我能留一份吗？”

“干什么？”

“我提交给总署对接单位一份。”

“总署？”

“银河异常文明接触管理总署。”

“他们怎么知道我来这里？”

“您船进港的时候，系统已经记录了。”

张霸天没说话。

他第一次知道，他船进一个港，总署就知道。

“那我这张表，有没有回执。”

港长把本子重新翻开，翻到最前面那一页。那一页印着三行样表，样表下面写着填表说明。

“回执要有编号。”他说，“编号由系统给。系统给您不显示，这一栏它连号都编不出来。”

“那就是没有回执。”

“您可以自己去别处问。”港长说，“别处也是这句话。”

“那张表你留。”张霸天说，“我去别的地方。”

张霸天转身走了出去。

出门的时候虫子还蹲在门槛外头。见他出来，它站起来，跟在他脚边。它没进过那间屋子，也没碰里面任何东西。

他走到门口回了一次头。港长已经坐回柜台后面，低头看那张表。

他往回走。场子上的灰被风卷起来一点，落在他的鞋面上。那三个空箱子还堆在原地。

他回到船上，坐在驾驶座上。舱门缝还在漏风，风很小，他把手贴在缝上试了一下，手指是凉的。

他把那张表摊在工作台上。表上五个无，最后那一栏还在：二号能源管线老化、舱门密封条需更换。

这是他要修的东西。

他把手伸到工作台下面，摸到那只记账用的旧终端，按亮。屏幕上只有两行：余额 237，本月已出 0。

本月已出后面那个 0 他看了两遍。这两个月他什么都没买成。

他把表收起来，压在报价表下面。那张报价表是别人很早以前给他的，上面写着二号能源管线的更换费用。表压下去，只露出一个角。那个角上印着一个数字，位数比二百三十七多一位。

翻译器还摆在台子上，还是上次摘下来的样子，屏幕朝上。

他看着，没拿。

他想起看那张报价表的时候看了两遍，看完之后他换了一个二手阀。

他要修的是管线。他连阀都换不起。

阀是便宜的那一项，管线是贵的那一项。这些年他只修便宜的那一项，贵的往后拖，拖到报价表上的数字比他手里的钱多出不止一倍。

他坐了很久。

接下来去哪儿，他不知道。

终端弹出一条消息：

「您离开纳塔港。海关系统记录：无异常。」

他看完关掉。

港务处的灯亮着的时候，那份表的复印件已经进了总署对接单位的服务器。备注那一栏港长填了两遍。

三十分钟后，那份复印件到了阿南德·拉奥的案头。阿南德看到的是这一行：

「船长所属单位：无（备注：口述曾填“太阳系边缘回收站”）」

他看完这一行，把报告合上，想了很久。

张霸天把船开出纳塔港。纳塔港的灯落在后面，越来越小，最后一格一格灭在画面边上。

他没往那边看。

他往航道深处开。航道的灯标一节一节往后退，下一个港在哪里，他不知道。他把手放在推进杆上，船往前去了一点。
