# 第90章：邪神不会用筷子

第二顿在第二天傍晚。

早上他开舱门，它在外头站着，像站了一夜。他没问它一夜在哪儿，它也没说。

他上岸，它跟着。他走得快，它也快；他停，它也停。过街的时候，它落脚的位置跟他齐着，像拿尺量过。绕过一个水坑，它也绕，绕的弧线跟他差不多。路边洒水车过来，他往旁边让了半步，它也让半步。排队买早点，它排在他半步外，学他盯着前头人的后脑勺，一下不眨。天凉，他跺了一下脚。它也跺了一下，跺的节奏跟他一样。

路人眼里就是个高一点、静一点的伙子。没人多看一眼。

他在船上收拾了个把钟头，它站在舱门口看。看他叠被子，看他把桌上的东西一件一件摆回原位，看他刷牙。他刷牙的时候，它也学。它没有牙刷，它就那么站着，两根手指在嘴上游了个来回，路线跟他嘴里那把牙刷一个样。他漱完口把水吐掉，它也把那个动作做了，做得很完整，就是没有水。

他出门的时候，把虫子往工作服口袋里深处按了按。它看见他这个动作，把这个也记了：那个装死的小东西，要搁在口袋里。

虫子还在他工作服口袋里，一上午没动。它学他学得越像，虫子僵得越死。他隔一会儿伸手探一下。还活着，就是不睁眼，不伸腿，随他揣了一路。钉子跟着他，指示灯一下都没亮。

傍晚他还是去了那条街，还是那张桌子。老板认得他了：“又来啦？今天吃啥？”

它坐下来，没等他开口，自己说：“炒面。”

老板一愣：“它倒门儿清。”

“教过它。”他说，“两碗。”

它把昨晚那八块钱的炒面记住了，今天自己点。它点的跟他教的一点不差：炒面，八块，不加蛋。别的词它没编。编不出来，也不乱编。

它坐下以后，先把两手平放在桌沿上，跟他昨晚一个姿势。摆完，它又把桌上那瓶醋往桌子中间挪了挪，摆得端端正正。老板过来抹桌子，看见它摆醋，多看了一眼，没说什么。它把老板这一眼也收了：不算异常。

老板拿来抹布擦桌子，看了它两眼，没多问。这条街上什么样的人都有，静一点算什么。

花生米先上，一碟，摊在桌心。他捻了一颗，拇指食指一捏，扔进嘴。它学他，也捻了一颗。连捏的角度都一样：拇指压下去，食指让开半寸，扔进嘴，嚼两下，咽。

他拿筷子的手顿了顿。

昨晚它拿筷子，是拿筷子，两根棍，凑合用。今天不是。今天它那双筷子，就是他的样子：右手两根，上头一根压在下两根之间，虎口那个角度都差不多。他吃面吃到碗底空了，会把碗往怀里转半圈，就着碗沿刮最后几根。它也跟着转半圈。转的角度跟他一样。

不像学。像抄。

它一口一个准。花生米小，圆，滑，它夹一个是一个，没失过手。就是哪儿不对。

他看了半碟，看出来了。人吃饭是连着来的：夹一筷子，扒两口，嘴里说着话，筷子不停，碗转来转去。它不是。它一下是一下。夹起来，停一下，送进嘴，嚼，咽，筷子放回碟边，再伸手。它把每一次夹取都做成了单件事，做完一件，才做下一件。

它还把一碟花生分成了两排。它从左边那排吃起，一颗一颗，一颗吃完再吃下一颗，排到碟子那头，才转过来吃右边那排。它不伸手去够。它先把左边这一排执行完。

他看它吃得慢，顺手给它演示了个掐花生尖的动作：拇指食指掐住花生尖，一拧，扔进嘴。它把这个也学了，掐得比他还准，一颗一颗，尖拧得干干净净。它把掐花生尖归到“热的”那一类里。花生不烫。它摆了一会儿，把它单归了一类。

它不是在吃饭。它在执行。

它停下来，把两根筷子并齐，竖在眼前，对着棚顶的灯看。它看长短，看粗细，看头上那道箍。然后它问：

“这器具，一手一根，是双手武器吗。”

他一口面呛在嗓子眼，咳了两下。

“不是。”他说，“吃饭用的。”

它把“吃饭用的”四个字收下了，但没有完。它接着问，问得很认真，一句是一句，跟昨晚问那口锅一个动静。

“哪根先动。”

“没什么先动后动，”他把嗓子里的面咽下去，“使得顺就行。”

它把“使得顺就行”记下了。它当场拿出来核。它夹了一颗花生，左手那根先动；又夹一颗，右手那根先动。它核了半天，核不出来这两回有什么不一样。它坐着，把这两颗花生在账上摆了摆，摆不平。

“执这两根的时候，”它又问，“嘴里要念什么吗。”

“念什么？”

“礼轨都有口诀。”它说。

“没有口诀。”他说。

它不信。它坐那儿想了一会儿，把他昨晚教的、今天教的，一样一样排了一遍，没排出一句能念的。它把“没有口诀”记下了。这条它核不了，可它记住了一条：他说没有，就是没有。

“碰碗沿，几声算一击。”

“不算击。没人计数。”

“双持的时候，有没有起手式。”

他被问住了。

“长短也不一样，”它把两根筷子并齐，举给他看，“长的这根，是攻的吗。”

“不是。”他说，“两根一样使。”

它把这个也记下了。它问的不是一双筷子的事，是这两根筷子背后的规矩。它心里那本账上，这两根该是一长一丝，长短配一对，一手一根，有先有后，有起有收。它今晚要把这本账重排一遍。它排账不说话，就是坐着，两根筷子在手里换过来换过去。

他想起小时候拿筷子，让他妈拿筷子头敲过手背。敲了小半年，才敲成现在这个样子。他妈还教了他一堆不许：不许敲碗，不许把筷子插在饭里，不许拿筷子指人。他问过为什么。他妈说不上来，就说老规矩。老规矩他记了二十多年，一条道理也讲不出来。他还想起他妈那句话：筷子拿远一点，拿近了夹菜使不上劲。他把这句也讲给它听了。它问，多远算远。他拿不准。他伸出手，在它那把筷子上比了个位置：离筷子头三寸上下。它用两根手指量了量，量出三寸，把三寸记下了。它今晚摆不平的那本账上，三寸是它唯一量得准的东西。

现在它问他哪根先动，他张着嘴，一个字都答不上。

“反正，”他憋出来一句，“不能插在饭里。”

“为什么。”它问。

“不好看。”他说。

它把“不好看”三个字记下了。它记东西的样子一向认真，可这三个字它核不了。它坐着，把“不好看”摆了摆，也摆不平。

老板拎着热水壶过来添水，看见它手里的筷子，笑了一句：“使得倒顺。就是别使太大劲儿，我们这筷子不经掰。”它把“不经掰”也记了。

他脑子里过了一遍：虫子一沾它就僵，钉子一见它就关探测，全银河没有一样东西近得了它的身。强得离谱。就这么个东西，现在坐在这儿，拿一双五毛钱的筷子，摆了一晚上摆不平。

这东西强得离谱，也确实不适合独自在人类社会吃饭。

他做了个动作。他把自己那双筷子从碗上拿下来，往它那边推了推。

“左手一根，”他说，“是叉。”

它左手拿起一根。

“右手一根，”他说，“是刀。”

它右手拿起一根。

“两根一块儿，”他说，“是手。”

它照做以前，先比划了一下。它左手那根当叉，右手那根当刀，两手在桌子上下比了个架势，问他：“这样对吗。”

“你把左手那根放下。”他说。

它不放。它问：“为什么只能一手。”

他说：“两只手都拿了，你就没手端碗了。”

它想了想，把左手那根放下了。它把“没手端碗”五个字记下。这回它核上了：碗在这儿，手得有一只是空的。它对了一遍，对上了，摆平了。

“叉是左手的，”它又问，“刀是右手的。为什么。”

“不为什么。”他说，“顺手就行。”

它把“顺手”记下了。它这本账重排到这儿，松了一条：左右没有定数。它拿着两根筷子换了个手，左手持刀，右手当叉，也做了一遍。两边都顺。它把两边都顺也记了。

然后它照做。它把左手的筷子伸向那碟花生，去叉；右手那把，去托。它做得极慢，一下是一下。第一颗花生被它叉起来，掉在桌面上，滚了半圈。它不动，看着那颗花生滚动，把它也记了：圆的，会滚。再叉，又掉了。它还是不动，看着。

它拿右手那根去切花生。切了三下，花生完好无损。它把“刀切不动花生”也记了。它摆不平的东西又多了一条，可它不急，它就是一条一条摆。

第三回以前，它停了很久。它把左手的叉和右手的刀并到一处，两根筷子尖对尖，试了一个没谁的份的角度。那角度是它自己摆了一晚上账，才摆出来的。

第三回，它夹起一颗花生没掉，手稳得吓人。

它看他。

他说：“你现在缺的不是稳，是常识。”然后把盘子往它那边推了推。

它捏着那颗花生，悬在碟子上头，手一下没晃。它捏花生比捏筷子稳得多。它什么都是一学就会，一学就准，练了三下就赶上他了。他练这个，练了小半辈子。

它把嘴里那颗花生吃了，把“常识”两个字收下，跟收“主宰”、收“八块”、收“叉”和“刀”一个样。然后它放下左手那根，右手一双，去夹第二颗。夹起来了。它想了想，又把左手那根拾起来，左右开弓，一边一根，把“叉”和“刀”又用了一遍。

老板在灶后头喊：“面好了！”两碗炒面一前一后上了桌，油亮，冒着气。它学着他，把碗往怀里转了半圈，转的角度跟他分毫不差。

他把筷子伸向自己那碗。它看着他那双手，也跟着伸。两张碗上头，四根筷子一般齐。

他把醋瓶往它那边推了推。它把瓶子按住，没动，先把眼前这半碟花生执行完。
