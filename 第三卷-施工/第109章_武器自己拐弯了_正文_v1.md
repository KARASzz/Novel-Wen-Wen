# 第109章：武器自己拐弯了

第二天一早，天刚亮。

泊位上的灯还亮着，亮了一夜，让天光压得发白。两条大船之间的水面上贴着雾，缆绳一紧一松地敲船帮。右边冻货船的制冷机比往常起得早，嗡嗡地响，化开的水顺着船舷往下滴。再过去，桥吊睡着，臂杆斜指着天。航道灯标红绿各一盏，还亮着，天一亮，它们就没用了。水面上过来一股柴油味，是左边那条运矿船的，它的轮机比冻货船起得晚。

他的船夹在当间，船首比两边都低，老样子。这个样子好。

他没洗脸，先在驾驶座上坐了一会儿。驾驶座头顶那盏灯还亮着，亮了一夜，灯罩上落着灰，光比夜里黄。驾驶座的老弹簧在他身子底下响了一声，他没动。后颈压着一股凉。风吹不出来，这是昨天留下来的。

昨天那个小点，从天上斜着下来，走得就不对。不是声音，天上掉东西，没有声音先到的；是影子，一个高速的小点，斜斜地压下来。近到能看清的时候，平白拐开，贴着船帮滑出去，落进远处海里，一声响就完了。他修船修了这些年，认的死理就一条：走直线的东西，撞上什么才拐弯。昨天那道，什么都没撞，平白就拐了。

他当时说了句：“打歪了。”

它没接。他等了它一句，没有。后颈那股凉，就是从那一刻落下的。

它上船这一夜，安安静静，跟它进大排档那张桌子一个样。它不问他，它看船。如今船也看完了，它该看的都看了，他倒想问它一句了。

他坐着，把昨天那一幕又过了一遍。上回在街上也是这么一出：一个乌黑的小东西，一声像拧断铁丝，直线过来，到它跟前拐了，扎进那人自己腰里。那回他懵了半宿，它坐着一动不动，报了四个字。他那会儿没有听懂。他这半年办的事，交钱，走流程，等通知，没有一样是被一下、一个拐弯办的。拐弯这件事，不在他的日子里头。

这回它在他船上了。它在这条破船上住了一夜，毯子没有掀，虫子没有出通风管，钉子没有亮。它就在半步外头。昨天那道弯，就是冲它来的。冲它来的，也就是冲他来的。它跟他之间，隔的就是半步。

他到舱外泼了把水，脸没擦干就进来了，在工作台边上坐下。这是他的位置，平常干活、吃饭、对着半废的控制台抽烟的位置。它从它常在的地方过来。它常在的，是舱里靠舱壁的那一处，不占他的座；这会儿它立在他对面，两手放回身侧，等他开口。

他把那句话在嘴里先过了一遍，才出来。不是质问，他就是想弄明白一句话。

“昨天那一下，”他说，“是不是打歪了。”

它把「打歪」两个字收了。它答得很平。

“不是打歪。”

他等着它往下说。它答话的规矩他知道：问一句，记一句，答完复述。它要是只答这三个字，后头就是空的，剩下的归他自个儿想。这回它没停。它把它知道的那部分，一样一样摆出来，摆在他面前的工作台上，像摆一笔陈年的旧账。那些字摆出来的时候，它脸上还是什么都没有，不高，不低，不压人。

“冲我来的东西，”它说，“凡被叫作「武器」的，到我跟前，就拐。”

它抬起一只手，停在半空。他盯着那只手看。那只手连抬都没抬过——它自己也知道他在看什么，把手放下了，放得很稳。

“我没拦过。”它说。“任何东西都没拦过。手没抬过。”

“是「进不来」。”

四个字，平得跟报账一样。它把「进不来」搁在它那本账里，搁得端端正正，跟收「八块」、收「麻烦」、收「拒绝」是一个收法。它见过这些东西进不来的样子，见过那么多回，回回如此。它把这叫作一条规矩。它见过的规矩。至于为什么进不来，凭什么进不来，它不知道。它也没有打算知道。

他坐在那儿，把「进不来」三个字掂了掂。拦住，跟进不来，在他这儿是两回事。拦住是有个东西挡在那儿，墙在那儿，盾在那儿，明明白白；进不来是那儿连门都没有。他补了三年船，舱壁挡着就是拦住，阀门拧死就是进不来。它这个是后者，比前者彻底。彻底到他连还手的地方都摸不着。

“规矩。”它复述了一遍，像怕他听漏了，“见过的。”

“不是道理。”

他听进去了。他往椅背上一靠，想了想，先问了一句别的。

“昨天那道，”他说，“是冲船来的。落点就在船帮外头。”

它答：“到我跟前，就是冲我。”

他想了想，是这么一个理。它跟他隔半步，冲船来的，先过它跟前。他又问：那什么算武器。

它这回答得谨慎。上回报「麻烦」那两个字，是挤出来的；这回它是挑着说，一个字一个字地挑。它把它认得的几样，一样一样报，报得短。

“打人的。”

“烧人的。”

“从远处扔过来的。”

三样。报完了，它等着，两手垂在身侧，等他问下一句。他等它报第四样。没有。他往下试。

“拳头呢。”他说。“拳头也打人。”

它说：“打人的。算。”

“火呢。放火。”

它说：“烧人的。算。”

他问：凭什么算。为什么是这几样。一个拳头跟一颗从远处扔过来的东西，隔着多少年的老账，怎么搁进一个筐里。

它说：不知道。

它说不知道的语气，跟说别的字一个样，没有高低。它见过的东西多，收过的字多，「为什么」这三个字，它问过别人，别人也问过它，它对不上账。它对不上账的，就不编。它把「为什么」收了，搁在对不上的那一栏，跟那笔陈账挂在一处。

他这半年问过太多人为什么。关口的人不说，总署的人不说，频道上那些隔着屏幕的人，说得最多，也最不算数。它跟他们不一样。那些人是不说，它是真没有。一个真没有的「不知道」，比半船装懂的答案都沉。它只知道它认得的这几样。认得，就进不来。认不得的呢。它想了想，说了八个字。

“认得的进不来。”

“认不得的，看情形。”

他还要问。看情形，谁来看，看到个什么程度。它没答。它把「看情形」三个字收了。收回去的样子，像收一笔它对不上的账：对不上，就不摆出来。摆在外头的只剩一句，它复述了一遍，一个字不错。

“认得的进不来。”

他听懂了。听懂以后，后颈那层凉就漫开了，漫到肩膀上，压在那儿，一动不动。

从今往后，冲着他来的东西，只要沾「武器」两个字，都会在船帮外头拐弯。不是它拦的，是进不来。而它在哪儿呢。它在他这条船上，在他半步外头，他走哪儿，它跟哪儿。它跟到哪儿，哪儿就是一个打不着的圈。他这辈子头一回有这么一个圈。这个圈不是他焊出来的。是他捡回来的。

昨天天上，那么多双眼睛，有多少正在过那道轨迹。他这半年走到哪儿都有人看：悬赏圈里蹲影像的，关口查他手续的，总署翻他档案的，频道上署着他名说话的。如今又多了一样。拿尺子量那道弯的人，量来量去，会量出一个数，会寻到一个因。因不在它身上。因会落在他头上。

他想想这笔账怎么记。外头的人不认得它，外头的人认得他。一个打不着的圈，加他这个名字，两行字并排放着，不用谁动手，自己就长到一起。长到后头，就是更多的人，更多的家伙，从更远的地方扔过来，一个一个试他这个圈。他想想那个场面：天上一天掉一个下来，个个到船帮外头自己拐。他后颈那层凉，又厚了一层。

他再想想它。它倒是踏实。它报完它的账，一页收了，明天还是它。它不怕这些。虫子怕它，钉子怕它，毯子怕它，它怕过什么。它什么都不怕，所以这些名目砸下来，砸的是他一个。

外界会得出一个结论。一句话，一个字不差：这条船，打不着。

这不是它厉害，是他的「绝对防御」。

他坐着，把这件事从头到尾想了一遍。舰长是别人安的，霸主是别人扣的，麻烦是别人嘴里滚出来的。那些名目落下来的时候，没有一个提前跟他打过招呼，落了他才晓得，晓得了也摘不掉。这一回，有人提前告诉他了。

主屏上，那三句还压着顶，亮着，关不掉；工作台上，翻译器屏幕朝上，没按灭；台子角那摞齐边纸，一眼带过。毯子没动。通风管里没声。角落那块废铁没亮。

它把今天这一页收了。它收工的样子他见过：收完了，手在桌沿上轻轻点一下，像往一本没有页数的本子上落最后一个字。今天这一页，它收得很稳，一页一页，比哪回都慢。临收完，它添了一句。

“他们会以为这是你的。”

舱里静下来。它说完就停在那儿，两手放回身侧，等他接话。它不要他一定答，它要的是这句话有个落处。落不落得下，它都收下。

他半天没言语。

他这半年背惯了别人的名目。头一回，有人把一个还没发生的名目替他点了，提前告诉他：这一笔，会记在你名下。他把这半年扣在他名下的那些话，在脑子里过了一遍：「收容」，「同行者」，「跟班」，如今又添一个「绝对防御」。一个个都是别人的嘴说出来的，个个都记在他头上。可这一回不一样。这一回是它说的，而它的嘴，就是账。账上说这是你的，那就是你的。

它不拦他，不保他，不安慰他，也不打算替他撇清。它只是报账。报完了，等他自个儿消化。

他把手从桌沿上收回来，在裤子上擦了一下。手心是潮的。他这半年练出来一样本事：天大的事儿，先坐一会儿，坐完了再办。可今天这事儿坐不住。它在他船上，赶不走，撵不掉，骂不得，也打不着。往后它就是他这条船上的一个常设衙门，他这个舰长，倒成了给它看门的。

他坐着，手在桌沿上放了很久。内袋里，那张超时收费条的角抵着指头。外头，缆绳一紧一松地敲着船帮，一声，隔一会儿，又一声。

末了，他没忍住，小声问了句：

“那……账单呢。”
