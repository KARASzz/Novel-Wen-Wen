# 第118章：缺了一块

他一夜没睡。

天没亮透，他就躺不住了。铺板硬，他翻过来，覆过去，把昨儿夜里它那句话在脑子里拧。拧到天亮，拧出来两个字：缺哪。

后半夜他爬起来过一回，摸黑坐到工作台边上，看着毯子。毯子在暗里也是一个鼓包，偏里，不在当间。他坐着看了一阵，它不动，他也不动。舱里静，只有外头的水声。坐了他就回去了，躺下，接着拧。

他把昨儿夜里那一幕又过了一遍。它从纸上抬起眼，越过台子，落到毯子上；它走过去，站定，半步。他跟它隔半步，从没敢越过去。它倒好，自己找了一样东西，跟那东西隔半步。它看他，看了半年，没看够；它看毯子，看了半晌。这个账他算不过来。

半年来他不是没对着这块鼓包发过愁。愁完了，该修修，该吃吃。愁这个东西，跟他修船一样：修不好的，先放着；放着放着，也就习惯了。今儿不一样。今儿有它那句话在头里压着，同一个鼓包，在暗里放着，跟他这半年里看过的每一回，都不一样了。

外头泊位上有了人声，桥吊开始动了。右边冻货船的轮机响起来，嗡嗡地，化开的水顺着船舷往下滴。天从舷窗上头透进来一点，灰白，泊位上的灯让这点亮压得没了脾气。缆绳一紧一松，敲着船帮。

舷窗上结着一层露水。他拿袖子抹了一道，凑上去看：泊位上雾没散尽，两条大船的影比夜里清楚了一点。他的船夹在当间，船首比两边都低，缆绳松松地搭着。老样子。

舱里那盏灯还亮着，亮了一夜。它立在老地方，一动不动，跟他躺下时一个样。它连睡的意思都没有。它站它的，他拧他的。

他爬起来，拿冷水抹了一把脸，走到工作台跟前。

毯子还在老地方，四边垂着角，起球的边磨得发白，鼓起来的形状偏向台子里侧。毯子边压着一块屏幕朝上的翻译器。旁边扣着的小屏翻着面，标红的一格朝里。台子角那摞合同齐着边。杂物堆边上，那团废铁还是老样子，不亮，不响，不探。通风管里没声。它立在半步外，看着他过来，不言不动。

“缺哪。”他问。

他修船修了这些年，认的死理就一条：东西喊疼，先问哪儿疼。焊缝裂了，问裂在哪儿；管子漏了，问漏在哪儿；阀不严了，问不严在哪儿。问出来了，心里才有数；有数了，才能下手。今儿它说这一块不完整，他头一个念头也是这个：缺哪。

修船的人眼里，没有“完整”这回事，只有“缺多少”。他这条船浑身补丁，哪儿新哪儿旧，他门儿清。它说这一块不完整，他听懂了，他也不信。听懂跟信，是两回事。这半年他就是这么过来的。

这一问，他憋了一宿。憋到天亮，绷不住了。它不睡觉，他知道；它立着，看他一夜没睡，也知道。它不问。它等他开口。它等一个问，等过多少回了，从没催过。

它答得比往常慢。一句，一顿，像一只手在厚厚的账页上找行。

“读不了。”

他愣了。他问的是缺哪，它答的是读不了。这两个中间隔着什么，他没摸着。

“啥读不了。”

“这一块的，”它说，“完整结构。”

他等着下头。

“读不了。”

它每顿一下，舱里就空一截。空得能听见灯罩上灰落的声。其实是他的耳朵在响。他等着，不敢催。它查账的样子他见过：翻到了，就报；没翻到，就不报。今儿它翻得慢，一页一页，比往常仔细。

第零舰队。这四个字，他这半年在屏上见过，在传闻里听过。这一块的完整结构，归第零舰队。它读不了。它只说到读不了，不说为什么。它不说的，问不出来。这半年他摸出来了：它那张嘴里，倒出来的都是它收过的；没收过的，一个字都不往外漏。

它能感知的只有一样。

“这一块的形状，不对。”

它顿了顿。

“像被人为切掉一部分。”

它答完，站着，不言不动，等他下一个问题。它不催他，也不问他听懂了没有。

他低头看毯子。那个鼓包还是老形状。他试着在心里头把它缺的那一块想出来：从哪儿切，切走多大，切口是齐的还是毛的。想不出来。那东西在毯子底下，他连摸都没摸过，全凭一个鼓包的形状去想。他想不出来，就不硬想。修船修了这些年，他懂一个理：看不见的缝，比看得见的难补。

人为。这两个字他咬了一遍。人为，就是有主。有主，就有处找。他刚冒出这个念头，就把它摁灭了。他上哪儿找去。银河里认识他的人不少，他认识的人不多，没一个能告诉他这一块的事儿。能告诉他的那个，就立在他面前，也只会说三个字：不知道。

他算了笔账。

修船的人算账，不用笔，用手比。他比了半天，先把这一块归了类。

如果这是钥匙。一把钥匙，缺了齿，开什么门。锁认齿，不认钥匙。缺了齿的钥匙，插得进锁眼，转不动；硬转，断在里头。断在里头的钥匙，比没有钥匙还坏。门再也开不了，锁眼也废了。这一条他见过。后舱那把锁就是，钥匙断在里头半截，他拿钳子拧，拿螺丝刀撬，撬了半个钟头，锁开了，门也锈住了。

如果这是机器。一台机器，少了件，转什么。转不动，空转，或者转到一半卡住。卡住比不转坏。不转，你知道它不转；转到一半卡住，你不知道它什么时候炸。他修过一台少了垫片的泵，外头看着好好的，一开机，水从缝里滋出来，滋了一地。从那以后他落下一个毛病：机器少没少件，他都要数一遍。

半年前他把船从废弃带里拖出来。船上原来那伙人的东西，他一样没动，就拿毯子把这一块盖上了。盖了半年。今儿它告诉他，这一块缺了一块。缺的那块，是钥匙上的齿，还是机器上的件，他不知道。

这把钥匙要开的门后头是什么，他不知道。这台机器转起来是干什么的，他不知道。他只知道一样：这门，这台机器，跟他这半年的日子，是连着的。连在哪儿，就在毯子底下压着。压了半年，他没敢动。今儿也动不了——缺了件，不是这么个动法。

他抬头看主屏。

主屏上那三句还压着顶，亮着，关不掉，搬不下来。「第零舰队已归位。」「缴纳文明观察保证金。」「否则，你们将在第二轮审判名单中被提前标记。」这三句他闭着眼都背得出来。半年来，它们压在他头上，比缆绳还沉。

那三句不是空的。三座城市交出来的东西，顶的就是这四个字。事都办过去了，令还在他屏上压着，一天不落地亮着。

如果那三句，是一个系统发出来的。

如果那个系统，少了一块——就是他毯子底下这一块。

那这三句，还算不算准。

一个缺了件的系统，照样发令。令发到他这儿，执行的时候，发现手里缺东西。那这令是吓唬人的，还是真能落下来。落下来，落到谁头上。

他想不下去。他没处想。他修船修了这些年，头一回碰上这么个东西：修不了。难吗？不难。缺的那件，他连见都没见过。没见过的件，没处画图，没处下料，没处补。

“能补吗。”他问。

它这回答得倒快。

“不知道。”

他搓了一把脸。它说不知道的时候，后头不跟任何东西。半年来他听它说过多少回不知道，每一回后头都是空的。它要编一个数儿糊弄他，后头不会这么空。它这个不知道，是真不知道。

“你见过的多。”他说，“你见过的那部分，长什么样。”

它没立刻答。半晌，它说：

“只认得见过的。”

“这一块缺的部分，”它说，“没见过。”

他听懂了。

它不是在修东西，是在认东西。它认得它见过的；认不出的，它不编。它手里没有那块的样子，答不了缺的那件。它不是不肯说。它那儿就没有。

它问过他：实物是什么。那回问的是罚款。那回他就知道，这东西不是什么都认得。它认得它经手的，认得它在场的。这一块缺的部分，它没经手。它连三个纪元以前的归位都在场。唯独缺的这一块，它没见过。

他捡回来的这一块，可能不是一把完整的钥匙，是一套大机器上缺的一块。钥匙缺了齿，还能另寻一把；机器缺了件，就得找那件原样的配。他没有第二块。他连第一块缺在哪儿，都是它看了半天才看出来的。

他在毯子跟前站着，看了半天。

然后他伸手，把毯子的边角掖了掖，压平。

他也不知道自己这是什么规矩。毯子盖着的东西，他碰都不敢多碰。头一回碰毯子边，是半年前头一晚，凉的，他当场把手收回来了，半天没敢再伸。今儿他伸手掖了它。指尖底下的毯子是温的，让灯烤了半天。鼓起的那个包在毯子底下，还是不动。

大概是修船工的习惯。东西破了，先把它盖好。盖严实了，里头的残缺先不叫人看见。等能修的那天，再说。修不好的日子，也得过。过日子的法子，他全会：盖着，压着，该干嘛干嘛。

八年了，这毯子盖过他多少回。街上那些冷夜，它裹着他睡；后来上了船，它盖这一块，一盖半年。他盖东西盖惯了：破的，缺的，舍不得扔又修不好的，都归它盖。盖上了，东西就还是他的，还是老的，还安安稳稳待在老地方。修要看图，要下料，要试；盖不用。今儿他能做的，也就是这一下。

它看着他把毯子掖平。

它把这个动作也收了。

它收他这套动作，收得惯了。他吃饭它收，他修船它收，他跟人递句好话它也算一笔。今儿它收的是这个：一个修船的，把破了的东西盖好。它收得跟别的一样，平平的，不问他为什么。

他收回手，在裤子上擦了一把。

毯子四平八稳，四边的角垂得齐整，压住了底下的那一块。鼓包还在毯子底下，偏着，不动。

他看了一阵，转身去收拾那只旧阀。今儿的活，还得干。
